## Comment utiliser

1. Lire l'overview [`../add-ons.md`](../add-ons.md).
2. Implémenter d'abord les **P0** puis **P1**.
3. Chaque spec contient: problème, marché (recherches), inputs/outputs, UX, data, API, monetization, KPIs, risques, sources.
4. Régénérer: `python scripts/generate_addon_specs.py`
