## Color palette

| Token | Hex | Role |
| --- | --- | --- |
| `bg` | `#F2F2F2` | Page background |
| `ink` | `#0F0F09` | Primary text, dark buttons |
| `sage` | `#C4CEB8` | Accent / Sign Up CTA |
| `muted` | `#585E5F` | Secondary text |
| `olive` | `#453F22` | Deep earth accent |
| `steel` | `#9EA9B2` | Borders, icons, chips |
| `bronze` | `#8D7658` | Warm secondary accent |

```css

  --color-sage: #c4ceb8;
  --color-muted: #585e5f;
  --color-olive: #453f22;
  --color-steel: #9ea9b2;
  --color-bronze: #8d7658;
}
```
