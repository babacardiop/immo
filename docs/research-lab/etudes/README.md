**Chiffres clés souvent cités (à toujours re-vérifier sur PDF source) :**

- Population ~18,1 M (2023) ; Dakar ~22 % pop. sur 0,3 % territoire ; densité Dakar ~7 485 hab/km²  
- Habitat : maisons basses 62,8 % ; verticalité marquée à Dakar (~60 % habitat vertical selon SES)  
- Locatif massif en urbain (~37,8 % ménages urbains locataires vs ~2 % rural)

## 9. Comment combiner études + lab

| Couche | Source | Output public |
| --- | --- | --- |
| Macro stock / tenure | RGPH + SES | “État du logement SN 20XX” |
| Coûts construire | ICC + IMC + crawl matériaux | Simu construction calibré |
| Activité secteur | ICAS agences + ICAC | Conjoncture “le marché ralentit/accélère” |
| Finance | CAHF + IFC Her Home + BHS | Guides crédit / diaspora femmes |
| Politique | Habitat III + 100k logements | Critique livraisons vs promesses |
| **Prix transactionnels / affichage** | **Notre crawl dédup** | Indice /m² quartier — **notre moat** |
| Loyers | Décret + CAHF + crawl location | Baromètre loyers Dakar |

**Règle éditoriale :** toute étude “Observatoire Immo” cite ≥1 source officielle + ≥1 série lab datée.
