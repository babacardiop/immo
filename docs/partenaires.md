# Partenaires & passerelles

**Fiches détaillées (1 fichier / type de partenaire):** [`docs/partenaires/`](./partenaires/README.md)

**Contexte :** agence full-service (`docs/positioning.md`) + add-ons (`docs/add-ons.md`).  
**Objectif :** monétiser l’écosystème autour de la transaction — **commission d’apport d’affaires** — sans devenir BTP, étude notariale, ni banque.

> On reste **l’agence**. Les partenaires exécutent. On **qualifie**, on **oriente**, on **touche une commission** (ou un forfait dossier) quand le client passe.

---

## 1. Principe

```
Client agence  →  besoin annexe (construire, papiers, financer, notariser…)
       ↓
Shortlist partenaire(s) validés  →  intro WhatsApp / RDV / lead form
       ↓
Partenaire signe / encaisse  →  nous reverse commission apporteur
```

| Rôle agence | Rôle partenaire | On n’est pas |
| --- | --- | --- |
| Qualifier le besoin, briefer, suivre le lead | Livrer le métier (plans, chantier, acte, financement…) | Constructeur, notaire, banque |
| Tenir le CRM des commissions | Facturer le client final | Garant de la qualité sans cadre contractuel |
| Protéger le client (séparation des rôles) | Exécuter dans son périmètre | « Tout faire soi-même » |

**Règle v1 :** marketplace **fermée** de partenaires (curated), pas un annuaire ouvert. Qualité > volume — aligné positionnement agence.

## 4. Modèle économique (commissions)

| Modèle | Quand l’utiliser | Exemple |
| --- | --- | --- |
| **% sur contrat signé** | Gros montants (BTP, finance) | 3 % de 80 M travaux = 2,4 M |
| **Forfait par lead qualifié** | Volume (formalités, notaire) | 75k FCFA / dossier notarié clos |
| **% sur honoraires partenaire** | Prestations libérales (archi, avocat) | 15 % des honoraires archi |
| **Success fee** | Closing investissement | 1 % du ticket financé |
| **Revenu récurrent partagé** | Assurances, syndic | % prime annuelle / mandat |

**Double filet :** commission agence classique (vente/location) **+** commission partenaire (add-on). Le client le vit comme « un seul interlocuteur » ; en back-office ce sont deux lignes de revenu.

### Cadre contractuel minimum (avant d’envoyer un lead)

1. **Convention d’apporteur d’affaires** (écrit) : taux, déclencheur (devis accepté / acompte / acte), délai de paiement, durée.
2. **Exclusivité ou non** (recommandé : non-exclusif, shortlist 2–3 par métier).
3. **Qualité / SLA** : délais de rappel client (ex. 24–48 h), droit de retirer le partenaire.
4. **Transparence client** : on dit qu’on travaille avec des partenaires ; on ne cache pas l’existence d’un apport (éthique + confiance).
5. **Séparation des rôles** (surtout diaspora) : le vérificateur ≠ le vendeur ≠ le notaire — voir MyAfric / notre blog.

## 5. Passerelles produit (où ça se branche)

| Moment parcours | CTA | Partenaire typique |
| --- | --- | --- |
| Fiche **terrain** + simu construction | « Obtenir un devis constructeur » | Constructeur, archi |
| Après offre acceptée | « Préparer l’acte chez le notaire » | Notaire |
| Lead « papiers manquants » | « Faire établir NICAD / CU / permis » | Formalités |
| Ticket > seuil (ex. 200–500 M+) | « Structurer le financement / club deal » | Financier |
| Signature bail | « Assurer le logement » | Assureur |
| Diaspora avant virement | « Inspection + séquestre » | Inspecteur + notaire/escrow |
| Bien sous mandat vente | « Shoot + staging » | Photo |

## 8. Risques

| Risque | Mitigation |
| --- | --- |
| Partenaire déçoit → image agence | Shortlist courte, SLA, clause de sortie, feedback client |
| Conflit d’intérêt (même personne vend + vérifie) | Règle séparation des rôles systématique |
| Commission non payée | Convention + facture à l’acompte / à l’acte ; CRM suivi |
| Responsabilité chantier / malfaçon | Contrat client **direct** avec le partenaire ; agence = apporteur |
| Notaire / professions réglementées | Respect déontologie ; forfaits intro plutôt que % agressifs |
