## 0. Synthèse — cadre hub

| Couche | Rôle | Obligation hub |
| --- | --- | --- |
| **RC professionnelle** | Couvre les **conséquences pécuniaires** de fautes / erreurs métier | **Oui** — décret art. 17 · police dès exercice |
| **Garantie financière** | Protège mandants sur **fonds / valeurs** reçus | **Oui** — loi 82-07 / décret ch. 3 |
| **Limites métier** | Ce qu’on **n’est pas** (notaire, constructeur, assureur immeuble…) | **Écrit** dans mandats & packs |
| **Asset-light** | Pas de stock foncier Y1 | Covenant gouvernance |

```
RC pro     → erreurs / omissions / responsabilité civile métier
Garantie   → défaillance restitution fonds clients (loyers, cautions…)
Limites    → partenaire exécute · hub apporte / orchestre
Séquestre  → notaire (pas le compte Wave de l’agence)
```

**Budget indicatif :** setup carte+garantie+RC **1,5–2,5 M** · opex lissé **~120 k/mois** (`05` prévisionnel) — **à recalibrer devis 2026**.

## 1. RC professionnelle (décret 83-423)

### 1.1 Obligation légale

| Article | Contenu |
| --- | --- |
| **Art. 17** | Tout titulaire de carte doit être couvert, **pour chaque établissement**, contre les conséquences pécuniaires de la **RC professionnelle** liée à ses activités, auprès d’un assureur **agréé** |
| **Art. 18** | Suspension / résiliation / non-reconduction → information **sans délai** (autorité carte) |
| **Art. 8** | Sans RC (ou garantie) valides → **restituer la carte** |

Pas de carte « en silence » sans attestation RC.

### 1.2 Ce que la RC pro vise (périmètre typique métier)

*Couverture exacte = police — négocier avec assureur SN.*

| Situations souvent couvertes (esprit métier) | |
| --- | --- |
| Erreur / omission dans l’exécution du **mandat** | |
| Manquement au devoir d’**information** / conseil dans le cadre du mandat | |
| Faute d’un **préposé** (agent) dans ses fonctions | |
| Dommages corporels / matériels / immatériels **consécutifs** causés à des tiers dans l’exercice | |

### 1.3 Ce que la RC pro **ne remplace pas**

| Hors / souvent exclu ou limité | Qui couvre / qui assume |
| --- | --- |
| **Garantie financière** (fonds clients) | Caution / Trésor / banque — §2 |
| Vice caché du bien / défaut construction | Vendeur · constructeur · assurances chantier |
| RC **propriétaire d’immeuble** | Police propriétaire / SCI (AXA, Sanlam…) |
| Multirisque locataire / MRH | Locataire / bailleur |
| Décennale / dommages-ouvrage | Constructeur / maître d’ouvrage |
| Fraude volontaire / acte illicite de l’assuré | En principe **exclu** |
| Dommages après paiement Wave vendeur **contre** conseil hub | Process anti-fraude · pas « on assure l’arnaque » |
| Résultat judiciaire / obtention TF | Jamais promis |

### 1.4 Paramètres à exiger auprès de l’assureur (checklist devis)

| Paramètre | Attendu hub |
| --- | --- |
| Activités déclarées | Transaction **et** gestion · digital / apport (si couvert) |
| Établissements | Siège + éventuels points |
| Plafond par sinistre / année | À dimensionner (gros tickets Almadies) |
| Franchise | Négocier · budgéter |
| Extension préposés / stagiaires | **Oui** |
| Defense / recours | Incluse si possible |
| Attestation pour dossier **carte** | Format Ministère |
| Délai déclaration sinistre | Connu de GER / OD |
| Territorialité | Sénégal (+ diaspora remote ?) |

**Owner :** GER · renouvellement **avant** échéance · copie OD.

## 2. Garantie financière (distincte de la RC)

### 2.1 Logique (décret ch. 3)

| Point | Texte (synthèse) |
| --- | --- |
| **Montant** | ≥ engagements envers mandants (art. 11) |
| **Apport perso** | ≥ **20 %** de la garantie · compte bloqué · **plancher 2 000 000 FCFA** (art. 12) |
| **Formes de caution** | Compte Trésor **ou** SCM agréée **ou** banque / établissement habilité (art. 13) |
| **Déclenchement** | Créance certaine, liquide, exigible · défaillance du professionnel (art. 14) |
| **Périmètre** | Versements / remises liés aux opérations art. 1 (transaction / gestion) |

### 2.2 Implications cash hub

| Effet | Pilotage |
| --- | --- |
| Fonds **bloqués** / caution | Cash libre &lt; apport 30 M nominal (`09`) |
| Montant suit l’encours mandants | Revoir à la montée **gestion** (loyers, cautions) |
| Arrêté de comptes au renouvellement carte | Max fonds détenus — EC / caution (art. 10) |

### 2.3 Règles ops « fonds clients »

| Règle | |
| --- | --- |
| Mandat **écrit** autorisant expressément à recevoir sommes (art. 19) | |
| **Registre des mandats** coté (art. 20) — conservation **5 ans** | |
| Comptes / flux **traçables** · pas de Wave perso agent | |
| Loyers gestion : encaissement société → reversement bailleur − honoraires | |
| **Séquestre vente** : privilégier **notaire** (hors bilan agence autant que possible) | |
| Cautions locatives : plafonds décret loyers (`03`) · conservation documentée | |

## 3. Limites métier — ce que le hub **n’est pas**

### 3.1 Matrice « on / on n’est pas »

| Rôle | Hub | Qui |
| --- | :---: | --- |
| Agence transaction / gestion (carte) | ● | — |
| Notaire / Conservation / rédacteur d’acte TF | — | Notaire · DGID |
| Constructeur / maître d’œuvre | — | Partenaire BTP |
| Architecte | — | Partenaire |
| Géomètre assermenté | — | Partenaire |
| Assureur immeuble / MRH | — | Courtier / assureur (lead) |
| Banque / prêteur | — | Courtier crédit |
| Avocat contentieux | — | Avocat |
| Marketplace open posting | — | Concurrent — **on refuse** |
| Promoteur / lotisseur Y1 | — | Hors objet |

### 3.2 Modèle **partner-led** (réduction de risque)

Règle BM :

> Client signe **avec le partenaire** pour l’exécution ; hub = **apporteur / orchestrateur**.

| Prestation | Facturation | Responsabilité exécution |
| --- | --- | --- |
| Construction / devis chantier | Partenaire | Partenaire |
| Bornage | Géomètre | Géomètre |
| Formalités / EDR | Formalités / Conservation | Partenaire + admin |
| Inspection diaspora | Inspecteur | Inspecteur (rapport) |
| Séquestre fonds vente | Notaire | Notaire |
| Pack Sécuriser / Secure | Forfait **hub** (orchestration) | Hub = organisation · pas résultat TF |

**Mention client type :**

```
Nous vous mettons en relation avec [Partenaire].
Il/elle facture sa prestation et s’engage sur son SLA.
[Agence] peut percevoir une commission d’apport.
Nous ne sommes pas le constructeur / notaire / géomètre.
```

### 3.3 Limites de **promesse** (éthique + RC)

| On peut dire | On ne dit pas |
| --- | --- |
| « On lit les papiers / on oriente la diligence » | « On vous garantit le TF » |
| « EDR recommandé avant paiement » | « Le notaire arrangera » (sans process) |
| « Délais admin souvent mois » | « TF / AC en 48 h » |
| « On filtre / on mandate » | « Bien sans risque » |
| « Séquestre notaire » | « Envoie sur mon Wave » |

Phrases interdites : [`06-culture`](../organisation/06-culture-et-sla.md) · anti-fraude [`02`](./02-politique-anti-fraude.md).

### 3.4 Limites **gestion locative**

| Hub fait | Hub ne fait pas (sauf mandat élargi écrit) |
| --- | --- |
| Encaissement · quittances · relances amiables | Contentieux judiciaire (avocat) |
| Coordination artisans 1er niveau | Gros travaux sans accord bailleur |
| Reporting | Garantie paiement loyers (sauf produit assurance caution) |
| Orientation assureur MRH/PNO | Souscription police à la place du client sans mandat |

### 3.5 Limites **catalogue / papiers**

| | |
| --- | --- |
| On **déclare** le type de droit vendeur + disclaimer | On n’**écrit** pas au Livre foncier |
| Verdict diligence GO/NO-GO | Pas une décision de justice |
| Pastille TF | Sous réserve EDR à jour |

Voir [`04-politique-papiers.md`](./04-politique-papiers.md).

## 6. Sinistres & déclaration

| Étape | Action |
| --- | --- |
| 1 | Signaler GER **&lt; 24 h** (même si doute) |
| 2 | Ne pas reconnaître faute / indemnité sans assureur + avocat |
| 3 | Conserver mails, mandats, CRM, photos |
| 4 | Déclarer à l’assureur dans les délais police |
| 5 | Log incident registre risques |
| 6 | Si fonds clients : informer caution / process art. 14+ |

**Interdit :** « arranger » en cash perso · détruire preuves · mentir à l’assureur.

## 7. Clauses & supports (à faire valider avocat)

### 7.1 Mandat — clause limite (trame)

```
Le Mandataire agit en qualité d’intermédiaire immobilier dans les limites
du présent mandat. Il n’est ni notaire, ni géomètre, ni constructeur.
Les prestations d’exécution technique ou juridique sont le cas échéant
confiées à des professionnels indépendants choisis avec le Mandant.
Les informations sur le régime juridique du bien sont déclaratives /
issues des pièces fournies, sous réserve de vérifications (EDR, etc.).
```

### 7.2 Pack Secure / Sécuriser

```
Le forfait couvre l’orchestration et le suivi des diligences convenues.
Il ne constitue pas une assurance tous risques ni une garantie d’obtention
d’un titre foncier ou d’un résultat contentieux.
```

### 7.3 Site — mentions

- RC / carte (n° quand attribué)  
- Lien partenaires = mise en relation  
- Disclaimer papiers (`04`)
