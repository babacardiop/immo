## 0. Synthèse — position hub

| Sujet | Décision |
| --- | --- |
| **Cadre métier** | Loi **82-07** + décret **83-423** (transaction & gestion) |
| **Stratégie** | **Se conformer** (carte + garantie + RC) = différenciant vs informel |
| **Honoraires vente** | **Libres** — transparence **écrite** dans le mandat (pas de barème légal unique type FR) |
| **Location habitation** | Encadrement **décret 2023-382** (+ héritage loi **2014-03** / surface corrigée) — **revalider texte** avant print |
| **Owner conformité** | **Gérant** (A) — RACI `07` |
| **Budget setup** | Inclus **~1,5–2,5 M** (carte + garantie + RC) dans capex M0–M1 |

**Avertissement :** document de **pilotage business**. Montants de garantie, pièces exactes et portée du décret loyers = **à confirmer avocat / Ministère du Commerce / assureur** au fil de l’eau. Le secteur a connu des périodes de **faible enforcement** de la carte — cela **n’autorise pas** l’informalité hub.

### 1.2 Activités couvertes (décret art. 1 — résumé)

| Activité | Hub Y1 |
| --- | --- |
| Achat / vente / échange / location (nu ou meublé) | **Oui** — transaction |
| Administration d’immeubles (gestion) | **Oui** — Vague 3+ |
| Promotion / lotissement | **Non** Y1 (objet social restreint) |

Exercice **à titre professionnel** → **autorisation** matérialisée par **carte professionnelle** (décret art. 2) — délivrance théorique **Ministre chargé du Commerce**.

### 1.3 Réalité marché vs posture hub

| Observation (presse / secteur) | Posture hub |
| --- | --- |
| Nombreuses structures sans carte visible | On **demande** la carte · on l’affiche |
| Appels à re-régulation (ex. ANAIS / Ministère) | Anticiper renforcement |
| Informel = risque client + concurrence déloyale | Conformité = **argument commercial** Fatou / Marième |

## 2. Carte professionnelle

### 2.1 Principes (décret 83-423)

| Point | Contenu |
| --- | --- |
| **Qui** | Personne physique **ou** représentant légal de la personne morale |
| **Portée** | Opérations sollicitées (transaction / gestion — préciser) |
| **Validité** | **2 ans** · renouvellement avec pièces |
| **Délai admin** | Ministres : **3 mois** après récépissé pour octroi/refus (art. 7) |
| **Présentation** | Toute personne intéressée peut **exiger** la carte (art. 9) |
| **Restitution** | Si fin garantie / RC / interdiction (art. 8) |

### 2.2 Conditions d’accès (art. 3 — synthèse)

| Volet | Exigence typique (texte 1983) |
| --- | --- |
| **Diplôme** | Maîtrise droit/éco **ou** diplôme équivalent **ou** DEUG + 5 ans emploi qualifié |
| **Stage** | **2 ans** chez titulaire de carte (sauf dispenses agents publics listés) |
| **Probité** | Pas d’incapacité / interdiction (casier n°2) |

→ **Vérifier avec avocat** les équivalences 2026 et la pratique réelle du Ministère (dossiers souvent sensibles).

### 2.3 Dossier de demande (art. 5 — checklist hub)

| # | Pièce | Statut |
| --- | --- | --- |
| 1 | Justificatifs aptitude (diplômes / stage / dispenses) | ☐ |
| 2 | **Attestation garantie financière** | ☐ |
| 3 | **Attestation RC professionnelle** | ☐ |
| 4 | Extrait / attestation **RCCM** | ☐ |
| 5 | Certificat patente (2ᵉ classe min. — texte) | ☐ |
| 6 | Certificat de nationalité (PP) | ☐ |
| 7 | **Statuts** SARL | ☐ |
| 8 | Casier / bulletin n°2 (via admin) | ☐ |
| 9 | Liste établissements / adresses | ☐ |
| 10 | Identité gérant / représentants | ☐ |

**Renouvellement (art. 10) :** garantie + RC + **quitus fiscal** + **arrêté de comptes** (max fonds détenus) certifié EC / caution.

### 2.4 Planning hub

| Jalon | Action |
| --- | --- |
| **J-60** | Lancer dossier + devis garantie / RC |
| **J-30** | Path actif · pièces complètes |
| **Jour J** | Idéalement carte **ou** récépissé + com prudente |
| **M+3** | Suivi si délai 3 mois admin |
| **M+22** | Prep renouvellement J-24 mois |

Si carte **en cours** : pas de mensonge « on a la carte » ; formulation avocat (« agrément en cours / dossier déposé »).

### 2.5 Affichage & preuve commerciale

## 3. Garantie financière & RC (aperçu — détail `05`)

| Obligation | Logique décret | Hub Y1 |
| --- | --- | --- |
| **Garantie financière** | ≥ engagements envers mandants (loyers, fonds gérés…) | Budget **1,5–2,2 M** ordre (`08`) · forme caution / dépôt — **chiffrer assureur** |
| **RC pro** | Conséquences pécuniaires responsabilité | Police dès exercice |
| **Fonds clients** | Gestion : loyers, cautions, avances — traçabilité | Comptes **séparés** / process OD |

**Alerte trésorerie :** partie de la garantie peut être **bloquée** → cash libre &lt; apport nominal (`09`).

Sans garantie / RC valides → **restituer carte** (art. 8) — risque C01 critique.

## 5. Décret loyers & honoraires de mise en location

### 5.1 Périmètre

| Concerné | Non / vigilance |
| --- | --- |
| Baux à **usage d’habitation** | Commercial / professionnel (autres règles) |
| Loyers **non** fixés en **surface corrigée** (logique 2014/2023) | Baux déjà conformes surface corrigée / baisses déjà appliquées — **cas par cas** |
| Régulateur | **CONAREL** (décret 2023-446) |

### 5.2 Mesures citées — décret **2023-382** (entrées en vigueur ~1er mars 2023)

*Synthèse presse / Mag Immo / Keur City / Sud Quotidien — **revalider JO / texte consolidé**.*

| Sujet | Mesure rapportée |
| --- | --- |
| **Baisse loyers** (hors surface corrigée) | ≤ 300 k : **−15 %** · 300–500 k : **−10 %** · &gt; 500 k : **−5 %** |
| **Caution** (loyer ≤ 500 k) | Max **2 mois** · 1 mois à l’entrée · 2ᵉ étalé /12 |
| **Honoraires agence / courtage** (loyer ≤ 500 k) | **½ mois** de loyer |
| **Paiement loyer** | Fin de mois (pas d’avance) — selon mesures citées |
| **Résiliation bailleur** | Cadre restrictif (impayés + préavis ; motifs famille / démolition…) |

**Loi 2014-03** (historique) : baisses différentes (ex. −29 % / −14 % / −4 % selon tranches) — ne pas mélanger avec 2023 sans avocat.

### 5.3 Application **politique commerciale hub**

| Situation | Politique `02` grille (alignée) |
| --- | --- |
| Loyer habitation **≤ 500 000** FCFA | Honoraires mise en loc côté **locataire** : viser **≤ ½ mois** si décret applicable · reste / complément **bailleur** à écrire |
| Loyer **&gt; 500 000** | **1 mois** — répartition bailleur/locataire **écrite** (défaut souvent bailleur ou 50/50 marché) |
| Gestion | **8 %** encaissés (hors sujet « ½ mois ») — mandat gestion distinct |
| Standing / expat | Vérifier si habitation + décret ; transparence totale |

```
AVANT signature bail habitation :
  1) Loyer mensuel ? ≤ ou > 500 k ?
  2) Surface corrigée déjà appliquée / baisse 2014 ou 2023 ?
  3) Calcul honoraires + caution conformes
  4) Écrire qui paie quoi dans le mandat / bail
```

### 5.4 Ce qu’on ne fait pas

| Interdit | |
| --- | --- |
| Facturer **1 mois plein** au locataire sur loyer ≤ 500 k si le décret limite à **½** | |
| Caution &gt; 2 mois (si plafond applicable) | |
| Cacher les honoraires « inclus mystère » | |
| Appliquer baisses 2023 sur dossier déjà régularisé sans analyse | |

### 5.5 Contenu & formation

- Pilier blog / FAQ locataire : caution, honoraires, fin de mois  
- Script Aïssatou (`05`) : total d’entrée **annoncé avant visite**  
- Veille CONAREL / Ministère Commerce — OD + GER trimestriel

## 10. Argumentaire commercial (conformité = vente)

```
Nous opérons en société immatriculée, avec path carte professionnelle,
garantie financière et RC — ce n’est pas un courtier WhatsApp anonyme.
Honoraires et FAI sont écrits avant la presta.
Sur la location habitation, on respecte le cadre des plafonds
d’honoraires / caution quand il s’applique.
```
