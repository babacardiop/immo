## 0. Synthèse — définition du Jour J

| | |
| --- | --- |
| **Jour J** | Site catalogue **live** + WhatsApp Business société **actif** + **≥ 1** bien curated publié + équipe joignable (GER + AC1) |
| **Ce n’est pas** | Inauguration champagne · ads massifs · « écosystème complet » · 80 mandats magiques |
| **Thèse** | *Signed agreements first* — pipeline mandats **avant** ou pendant l’ouverture (FinancialModelsLab / PulseRevOps) |
| **Zone** | **Z1 only** (Mermoz / Sacré-Cœur / Almadies / Ngor) — `02` |
| **Paid** | **0** jusqu’à M3 (sauf exception gérant) |

```
J-60 … conformité chemin critique (si pas déjà lancé)
J-30 … sprint commercial + produit
Jour J … go-live soft
J+30 … Gate Vague 0 Done
J+90 … Vague 1 Done + 1er apport
```

**Prérequis cash :** apport / buffer **~30 M** en banque **avant** capex Vague 0 (`05`/`07` trésorerie) — sinon **pas** de Jour J.
