## 1. Cadence multicanale type (21 jours)

*Adapté Maline / Paradial — WA remplace SMS/courrier Y1.*

| Jour | Canal | Action |
| --- | --- | --- |
| **J0** | Appel **ou** WA | 1ʳᵉ prise de contact / qualif |
| **J0** | Vocale si no answer | Message &lt; 20 s + WA |
| **J+1** | WA | Relance courte + raison |
| **J+3** | E-mail *ou* WA doc | Estimation / checklist / lien simu |
| **J+7** | Appel | 2ᵉ tentative · proposer créneaux RDV |

**Stop cadence si :** « stop » / refus clair / no-go zone / hors persona.

## 2. Playbook A — Prospection vendeur (appel)

### 2.1 Objectif

Obtenir un **RDV estimation** (pas vendre le mandat au téléphone).

### 2.2 Trame appel (~3–5 min) — CROC adapté

| Étape | Script |
| --- | --- |
| **C — Contact** | « Bonjour [Prénom], [Prénom Agent] de [Agence] à Dakar. Je vous dérange 30 secondes ? » |
| **R — Raison** | « On aide des propriétaires à Mermoz / Almadies / Ngor à vendre avec un seul discours prix et un filtrage des visites — pas une marketplace. » |
| **O — Ouverture** | « Vous avez un projet de vente dans les 6 mois, ou je vous rappelle plus tard ? » |
| **C — Closing RDV** | « Je peux passer [jour] 10h ou [jour] 17h pour une estimation écrite — lequel vous arrange ? » |

### 2.3 Si répondeur (≤ 20 s)

```
Bonjour [Prénom], [Agent] de [Agence].
Je vous appelle au sujet d’une éventuelle vente sur [quartier].
Je vous envoie un WhatsApp — vous me dites si une estimation vous intéresse.
Bonne journée.
```

### 2.4 WA J0 post-appel / no answer

```
Bonjour [Prénom], [Agent] — [Agence].
Je viens d’essayer de vous joindre.
On fait des estimations écrites sur [quartier] + mise en marché curated
(un prix, filtrage visites). Ça vous parle pour les semaines à venir ?
```

### 2.5 CRM après appel

`statut` · `objection` · `créneau proposé` · `source=soi/farming` · `prochaine_action`

## 3. Playbook B — Estimation → mandat exclusif

### 3.1 Ordre canaux

1. RDV terrain / bureau  
2. Envoi fourchette **écrite** (WA PDF ou e-mail) **J0**  
3. Relance signature **J+1 / J+3 / J+7**  

### 3.2 Script closing RDV (rappel `05`)

Voir argumentaire Marième §3.2 — exclusif 3 mois + reporting + un prix.

**Phrase de verrouillage (Realtys adapté SN) :**

```
Je vous propose un mandat exclusif de 90 jours.
Pendant cette période : photos, fiche catalogue avec type de papier,
diffusion contrôlée, filtrage, compte-rendu [bi-mensuel] sur WhatsApp.
À mi-parcours on fait le point sur les visites qualifiées.
On signe [jour] et on shoot les photos le même jour — OK ?
```

### 3.3 E-mail / WA doc — envoi estimation (J0)

**Objet (e-mail) :** `Estimation [adresse/quartier] — fourchette et plan d’actions`

```
Bonjour [Prénom],

Suite à notre échange, voici :
• Fourchette indicative : [X–Y] FCFA (comparables [quartier])
• Hypothèses et points de vigilance (papier / travaux)
• Plan d’actions en mandat exclusif 90 j (1 page)

Prochaine étape : signature + photos.
Je vous propose [créneau A] ou [créneau B].

Cordialement,
[Agent] — [Agence] — WA [numéro]
```

### 3.4 Relances post-estimation

| Jour | Canal | Message |
| --- | --- | --- |
| **J+1** | WA | « Vous avez pu regarder la fourchette ? Je bloque [jour] pour le mandat. » |
| **J+3** | WA/mail | « Sans exclusif on diffuse moins — je préfère être clair. On avance ou on pause ? » |
| **J+7** | Appel | « Je finalise mon planning photos — on maintient [jour] ? » |
| **J+14** | WA | « Je clos le dossier estimation pour l’instant — vous me dites si ça se réactive. » |

### 3.5 Si « je réfléchis »

```
Normal. Je vous laisse la fourchette écrite.
Qu’est-ce qui vous ferait vous sentir à l’aise pour signer : durée plus courte,
reporting plus fréquent, ou point à 45 jours ?
On ajuste dans le mandat — pas oral.
```

## 4. Playbook C — Acquéreur terrain (Mamadou)

### 4.1 WA qualification (J0)

```
Pour vous orienter :
1) Budget max (FCFA) ?
2) Zone(s) ?
3) Terrain ou bâti ?
4) Délai (ce mois / 3 mois / +6 mois) ?
5) Sur place ou diaspora ?
```

### 4.2 Appel post-simu

| Étape | Script |
| --- | --- |
| Accroche | « J’ai vu votre simu — mensualité ≈ [X], total ≈ [Z]. » |
| Diagnostic | « Le point critique chez nous, c’est le **papier** avant l’acompte. » |
| Offre | « Je vous propose la checklist diligence / Pack Sécuriser, puis notaire. » |
| CTA | « On lance la diligence cette semaine, ou vous voulez d’abord revisiter le terrain [réf] ? » |

### 4.3 E-mail diaspora-light / formalisation

**Objet :** `Suite simu terrain — prochaines étapes sécurisées`

```
Bonjour [Prénom],

Résumé simu : [mensualité] · [construction] · [total].
Bien [réf] : statut déclaré [TF/bail/délibération].

Important : une délibération n’est pas un TF.
Avant paiement : vérification (EDR / régime) avec nos partenaires.

Lien checklist / prise de RDV : [lien]
WhatsApp : [numéro]

[Agent]
```

### 4.4 Relance Mamadou

| Jour | Message WA |
| --- | --- |
| J+2 | « Toujours sur le projet terrain [zone] ? Je peux caler visite [jour]. » |
| J+7 | « Rappel : pas de Wave vendeur. On passe par vérif → séquestre/notaire. » |
| J+14 | « Je pause le dossier — répondez GO si vous voulez relancer. » |

## 5. Playbook D — Diaspora Fatou (WA + e-mail)

### 5.1 E-mail bienvenue (J0 lead SEO / form)

**Objet :** `Avant de payer au Sénégal — notre protocole`

```
Bonjour [Prénom],

Merci pour votre message. [Agence] est une agence curated à Dakar
(pas un site d’annonces).

Pour votre sécurité : aucun paiement Wave/OM direct au vendeur sur notre conseil.
Parcours type : shortlist → diligence/inspection → séquestre notaire → (gestion).

Pour démarrer, répondez avec :
budget · zone · usage (famille / locatif / retraite) · délai voyage SN.

WhatsApp Business : [numéro] (souvent plus rapide).

Cordialement,
[Nom] — [Agence]
```

### 5.2 WA protocole Secure

```
Fatou, voici le protocole en 5 points (PDF aussi par mail si vous voulez).
Pack Diaspora Secure : forfait [X] FCFA — inspection + orchestration.
On démarre sur quel bien / quelle zone ?
```

### 5.3 Cadence Fatou (décalage horaire)

| Jour | Canal | Note |
| --- | --- | --- |
| J0 | E-mail + WA | Doubler les canaux |
| J+1 | WA | Créneaux Visio (soir EU / matin SN) |
| J+3 | E-mail | Checklist + disclaimer papier |
| J+7 | WA | Shortlist 2–3 biens **ou** pause |
| J+14 | E-mail | Soft — « projet toujours actif ? » |

### 5.4 Relance « frère gère »

```
On peut travailler avec la famille sur place.
Nous : vérification papiers + circuit des fonds.
Eux : visite physique.
Présentateur ≠ vérificateur ≠ détenteur des fonds — c’est non négociable.
```

## 6. Playbook E — Bailleur (Ousmane / Ibrahima)

### 6.1 Appel / WA accroche gestion

```
Bonjour [Prénom], [Agent] — [Agence].
Vous avez un bien en location à [quartier] ?
On propose mise en loc (1 mois d’honoraires) et/ou gestion 8 %
avec encaissement Wave/OM + quittances + reporting.
Vous gérez seul aujourd’hui, ou vous voulez qu’on vous fasse une proposition écrite ?
```

### 6.2 E-mail proposition gestion

**Objet :** `Proposition gestion locative — [adresse]`

```
Bonjour [Prénom],

Proposition :
• Mise en location : 1 mois de loyer
• Gestion : 8 % des loyers encaissés (7 % si ≥ 5 lots / 24 mois — sur accord)
• Inclus : encaissement, relances amiables, quittances, reporting mensuel
• Hors : contentieux judiciaire, gros travaux (devis)

Prochaine étape : mandat + état des lieux.
Créneaux : [A] / [B].

[Agent] — WA [numéro]
```

### 6.3 Relance attach post-mise en loc

| Timing | WA |
| --- | --- |
| Jour signature bail | « Locataire placé. On active la gestion maintenant pour l’encaissement ? » |
| J+3 | « Sans gestion, les impayés restent chez vous. Mandat 1 page — je l’envoie ? » |
| J+7 | « Dernière relance gestion pour [adresse] — OK ou vous gardez en solo ? » |

## 7. Playbook F — Post-visite acquéreur

### 7.1 WA J0 soir de visite

```
Merci pour la visite de [bien].
En 2 mots : points + et points − ?
Je ajuste la shortlist demain matin.
```

### 7.2 Si silence J+1

```
Petit suivi visite [bien] — toujours intéressé(e), offre à préparer, ou on écarte ?
```

### 7.3 E-mail offre / suite (si diaspora ou formalisation)

**Objet :** `Suite visite [réf] — options`

```
Bonjour [Prénom],

Bien visité : [réf], [prix], papier [type].
Options :
1) Offre écrite sous conditions diligence
2) 2ᵉ visite / inspection
3) Biens alternatifs [A] [B]

Dites-moi 1, 2 ou 3.

[Agent]
```

## 8. Playbook G — Nurturing long (60 j) post-estimation

*Si pas prêt à signer — séquence Realtys / mon-crm-immo adaptée (WA + e-mail mensuel).*

| Jour | Contenu | Canal |
| --- | --- | --- |
| **0** | Estimation + plan d’actions | WA/mail |
| **3** | Contexte quartier (sans hype) | WA |
| **7** | Conseil actionnable (photos, papier, prix) | WA/mail |
| **14** | Soft CTA mandat / RDV | WA |
| **30** | « Toujours d’actualité ? » | WA/mail |
| **60** | Dernière relance → newsletter mensuelle ou clos | Mail/WA |

**Newsletter mensuelle (1× / mois max) :** 1 info marché Z1 + 1 CTA estimation/gestion — **≤ 4 e-mails / mois** / contact.

### Break-up (J+60 ou J+21 cycle froid)

```
Sans nouvelles, je classe votre dossier en pause pour ne pas vous solliciter inutilement.
Répondez OUI si vous voulez rester dans la boucle (actu mensuelle).
Sinon, bonne continuation — on est là si besoin.
```
