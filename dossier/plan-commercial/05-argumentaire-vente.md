## 0. Cadre — comment on parle

| Règle | Application |
| --- | --- |
| **Ton** | Expert, calme, daté — jamais clickbait / « deal unique » |
| **Canal #1** | WhatsApp (phrases courtes, 1 CTA) |
| **Preuve avant promesse** | Chiffres FCFA, type papier, reporting |
| **Exclusif d’abord** | Pitch Marième / Fatou vendeuse |
| **Jamais** | Wave vendeur · « délibération = TF » · dump sous plancher sans gérant |

**Promesses marque (à coller mentalement) :**

- *Pas une marketplace. Une agence.*  
- *Avant de signer ou de payer, on sécurise.*  
- *On publie (pas vous). On filtre les curieux.*

## 1. Pitch elevator (15 secondes)

```
On est une agence immobilière à Dakar — pas un site d’annonces.
On mandate des biens qu’on a lus (TF, bail, délibération),
on filtre les visites, et on accompagne jusqu’au notaire / à la gestion.
WhatsApp + preuves. Qu’est-ce que vous cherchez : vendre, acheter, louer ou faire gérer ?
```

## 2. Structure d’entretien (tous personas)

| Étape | Durée | Objectif |
| --- | --- | --- |
| **1. Accueil** | 1 min | SLA · qualifier ACHAT/VENTE/LOC/GESTION |
| **2. Découverte** | 5–10 min | Budget · zone · délai · sur place / diaspora · papier |
| **3. Diagnostic** | 3 min | Reformuler douleur + job-to-be-done |
| **4. Offre** | 5 min | 1 parcours hub (pas catalogue de 20 options) |
| **5. Preuve** | 2 min | Exemple process · checklist · reporting |
| **6. Closing soft** | 2 min | Prochaine étape datée (RDV / mandat / simu / Secure) |
| **7. CRM** | — | Tag source · notes · relance |

**Question magique (fin découverte) :**  
*« Si on règle [douleur], qu’est-ce qui vous empêcherait d’avancer cette semaine ? »*

## 3. Persona Marième — Vendeuse (P1 supply)

### 3.1 Job & message

| | |
| --- | --- |
| **JTBD** | Prix correct, délai court, moins de curieux |
| **Message** | *On met ton bien en marché proprement et on filtre.* |
| **Offre** | Estimation → **mandat exclusif 5–7 %** (cible 6 %) · catalogue curated |

### 3.2 Script estimation → exclusif

```
Marième, je vous propose une estimation écrite basée sur des biens comparables
[quartier], pas un chiffre pour vous faire plaisir.

Ensuite, en mandat exclusif [3 mois], on s’engage sur :
• une seule annonce, un seul prix
• photos / fiche catalogue avec type de papier
• filtrage des visites
• un compte-rendu [bi-mensuel] sur WhatsApp

En multi-agence, le bien sort souvent à des prix différents —
les acheteurs se méfient et négocient plus fort.
Est-ce qu’on verrouille l’exclusif pour [durée] avec ce plan d’actions ?
```

*(Inspiré Realtys : stratégie unique · reporting · défense du prix — adapté SN, sans promesse DVF.)*

### 3.3 Objections Marième

| Objection | Réponse |
| --- | --- |
| « Je veux plusieurs agences » | Multi = multi-prix + moins d’effort chacun. Chez nous exclusif = marketing + suivi. Essai **3 mois** mesurable ; on réévalue si pas de visite qualifiée. |
| « C’est trop cher 6 % » | Contrepartie : durée + reporting. Plancher **5 %** si exclusif **≥ 6 mois** ou 2ᵉ bien — **écrit**, pas oral (`04` politique). |
| « L’autre fait 3 % » | On ne match pas le dump. On match **preuve**, filtrage, closing. Un mandat à 3 % mal suivi coûte plus cher qu’un closing propre. |
| « Mon cousin vend sans agence » | OK — mais pas de diffusion curated, pas de filtre curieux, pas de dossier notaire packagé. |
| « Je suis pressée » | Exclusif accélère souvent (un discours, un interlocuteur). Simple dilue l’énergie. |
| « Laissez-moi réfléchir » | Normal. Je vous envoie le plan d’actions + fourchette écrite aujourd’hui. On se rappelle **[jour]** ? |

### 3.4 Closing

```
Prochaine étape : signature mandat exclusif + photos [date].
Je bloque le créneau. OK pour vous ?
```

**Si refuse exclusif :** fiche motif CRM → gérant valide simple **seulement** si GO politique (CAC≈0 ou bien stratégique). Lead **paid** → exclusif ou abandon.

## 4. Persona Mamadou — Primo terrain (P0)

### 4.1 Job & message

| | |
| --- | --- |
| **JTBD** | Savoir si je peux payer, et combien coûtera la maison |
| **Message** | *Chiffres avant engagement — et on lit tes papiers.* |
| **Offre** | Fiche + **3 simus** → diligence / notaire / constructeur |

### 4.2 Script 1ʳᵉ conversation WA

```
Mamadou, avant de parler prix “coup de cœur”, on clarifie 3 choses :
1) Budget max + mensualité supportable
2) Zone (et type de papier : TF / bail / délibération)
3) Vous voulez juste le terrain, ou terrain + construire ?

Je vous envoie le simulateur [lien]. Vous le remplissez,
je vous rappelle avec une lecture honnête — y compris si c’est no-go.
```

### 4.3 Script post-simu

```
D’après la simu : mensualité ≈ [X] · construction ≈ [Y] · total ≈ [Z].
Le terrain [réf] est en [TF/bail/délibération].

Prochaine étape recommandée : checklist diligence (EDR / régime)
avant tout acompte. Je vous oriente vers [partenaire] sous 48 h —
je reste sur le dossier. On lance ?
```

### 4.4 Objections Mamadou

| Objection | Réponse |
| --- | --- |
| « La délibération c’est bon, tout le monde achète comme ça » | Délibération = **usage**, pas TF. Discount prix = souvent discount sécurité. On vérifie avant de payer. |
| « Je paie Wave maintenant pour bloquer » | Non — parcours vérif → mandat → séquestre/notaire. Protocole écrit. |
| « C’est trop long la diligence » | Moins long qu’un litige / Arrêt Dscos. On cadre le délai avec le partenaire. |
| « Le constructeur du coin est moins cher » | OK — comparez devis. Notre shortlist : SLA rappel 48 h + suivi. Vous choisissez. |
| « Je compare encore sur Expat » | Normal. Vérifiez que le **même prix** et le **même papier** sont affichés partout. Chez nous : un discours. |
| « Les frais d’agence… » | Sur vente, souvent côté vendeur / FAI selon mandat. On clarifie **avant**. Sur terrain étalé : frais dossier **25–50 k** = filtre sérieux. |

### 4.5 Upsell

Simu OK → Pack **Sécuriser** (V2) → apport BTP (V1) → plus tard gestion si locatif.

## 5. Persona Fatou — Diaspora investisseur (P0)

### 5.1 Job & message

| | |
| --- | --- |
| **JTBD** | Acheter / construire / gérer sans être sur place, avec preuves |
| **Message** | *Avant de payer, on vérifie. Ensuite on gère.* |
| **Offre** | Diligence · inspection · séquestre · Pack **Secure 300–800 k** · gestion |

### 5.2 Script 1ʳᵉ prise de contact

```
Fatou, bien reçu. Pour votre sécurité on ne conseille jamais un paiement
Wave/OM direct au vendeur.

Parcours type :
1) Qualification budget / zone / usage (famille / locatif / retraite)
2) Sélection curated + type de papier
3) Inspection / diligence
4) Séquestre notaire
5) Si locatif : mandat gestion + reporting

Vous êtes plutôt achat terrain, maison, ou reprise d’un bien déjà acheté ?
```

### 5.3 Script Pack Secure

```
Le Pack Diaspora Secure couvre l’orchestration : inspection, points de contrôle,
orientation notaire/séquestre — forfait [X] FCFA.
Ce n’est pas “magique” : c’est un protocole écrit pour éviter le cousin + Wave.

On démarre par l’inspection du bien [réf] cette semaine ?
```

### 5.4 Objections Fatou

| Objection | Réponse |
| --- | --- |
| « Mon frère s’occupe de tout » | Fréquent — et fréquent source de loyers / travaux opaques. On peut coexister : **nous** vérifions papiers + fonds ; la famille visite. Rôles séparés : présentateur ≠ vérificateur ≠ détenteur des fonds. |
| « Trop cher le pack » | Remise max **−15 %** si Secure + gestion. Sinon on **ajoute de la preuve** (photos datées) plutôt que −30 %. |
| « Je veux payer vite pour pas le perdre » | Paiement rapide sans vérif = risque max. Séquestre = engagement sérieux **sans** exposer le cash au vendeur. |
| « J’ai vu moins cher sur Facebook » | Prix −50 % sans explication = red flag. On lit le papier d’abord. |
| « Vous êtes où ? Je ne vous connais pas » | Licence / bureau [quartier] / process écrit / notaire nommé. Visio + docs avant tout transfert. |
| « Décalage horaire / signature » | WhatsApp + docs ; procuration cadrée avec notaire (Vague 4). |

### 5.5 Closing

```
Prochaine étape : [inspection / Secure / shortlist 3 biens] avant le [date].
Je vous envoie le protocole PDF aujourd’hui.
```

## 6. Persona Ousmane — Bailleur local (P0 gestion)

### 6.1 Job & message

| | |
| --- | --- |
| **JTBD** | Encaisse pour moi et montre-moi les comptes |
| **Message** | *On encaisse, on reverse, tu vois tout.* |
| **Offre** | Mise en loc (**1 mois**) → gestion **8 %** (7 % si ≥ 5 lots) |

### 6.2 Script attach loc → gestion

```
Ousmane, on peut juste placer le locataire — honoraires 1 mois.
Mais si vous voulez qu’on encaissement, quittances, relances, Wave/OM,
reporting mensuel : mandat de gestion à 8 % des loyers encaissés.

La plupart des bailleurs qui passent chez nous après un impayé
auraient préféré démarrer en gestion. On active les deux maintenant ?
```

### 6.3 Objections Ousmane

| Objection | Réponse |
| --- | --- |
| « 8 % c’est trop » | Cible marché. **7 %** si **≥ 5 lots** ou engagement 24 mois — gérant. Sous 7 % = non (`04`). |
| « Je gère avec mon cousin » | OK tant que ça marche. Quand impayé / travaux : on reprend avec audit. |
| « Montrez-moi d’abord » | On commence par **mise en loc** + proposition gestion écrite. Portail / quittances dès V3. |
| « Et si le bien est vide ? » | Honoraires gestion sur **loyers encaissés** — transparence vacance. On bosse le placement. |
| « Je veux plusieurs agences en loc » | Pour la gestion : **un** mandataire. Multi = chaos quittances / locataire. |

### 6.4 Closing

```
Je vous prépare le mandat gestion + grille : encaissement, reversement, seuil travaux.
Signature [jour] au bureau / par doc. OK ?
```

## 7. Persona Ibrahima — Bailleur diaspora (P0)

### 7.1 Douleur & pitch

```
Ibrahima, souvent le schéma c’est : cousin qui gérait, loyers flous, travaux chers.
On reprend avec : mandat écrit, compte traçable, reporting mensuel,
visite / inspection périodique, et vous validez les gros travaux à distance.

Pack reporting diaspora : 9–10 % ou forfait — selon besoin de preuves.
Par où on commence : audit du locataire actuel, ou remise en loc ?
```

### 7.2 Objections clés

| Objection | Réponse |
| --- | --- |
| « Je ne veux pas vexer la famille » | On positionne l’agence comme **tiers neutre** — pas comme guerre familiale. |
| « Les loyers sont déjà bas » | On optimise vacance + qualité locataire ; pas de miracle sur le marché. Honnêteté. |
| « Signature depuis la France » | Parcours doc + notaire / POA selon dossier (V4). |

## 10. Argumentaire exclusif — aide-mémoire (tous vendeurs)

| Argument | Phrase type |
| --- | --- |
| **Stratégie unique** | Un prix, une annonce, un plan com — pas de doublons portails. |
| **Effort max** | En exclusif on investit photos, SEO, filtrage ; en simple on diffuse moins. |
| **Défense du prix** | Pas de course au rabais entre agences. |
| **Reporting** | Compte-rendu périodique écrit sur WA. |
| **Durée limitée** | 3 mois + engagements ; reconduction écrite. |
| **Estimation honnête** | Fourchette argumentée — pas flattery concurrente. |

---

## 11. Phrases interdites (rappel culture)

1. « La délibération, c’est bon pour vendre. »  
2. « Envoie sur mon Wave, je gère. »  
3. « Le notaire arrangera » (sans process).  
4. « Personne ne regarde les EDR. »  
5. « On s’aligne sur les 3 % de l’autre. » (sans gérant)

## 12. Matrice objection → escalate

| Situation | Agent | Gérant |
| --- | --- | --- |
| Remise dans fourchette | Propose + CRM | Informé |
| Plancher soft (5 % / 7 %) | Demande | **A** |
| Sous plancher / dump | Stop | Décide ou refuse |
| Red flag papier | Freine + OD | Si litige |
| Client menace / harcèle | Cut | RH / juridique |

## 13. Mini-scripts relance (transverse)

**J+2 silence**

```
Bonjour [Prénom], petit suivi sur [sujet].
On avance ou je clos le dossier pour le moment ?
```

**J+7 post-estimation**

```
Marième, vous avez pu regarder la fourchette et le plan d’actions ?
Je peux passer [jour] pour le mandat exclusif — 20 minutes.
```

**Post-visite sans feedback**

```
Suite à la visite de [bien], qu’avez-vous retenu (points + / −) ?
Je ajuste la shortlist en conséquence.
```
