## 0. Synthèse — théâtre d’opération Y1

| Tier | Zone | Rôle Y1 | Intensité |
| --- | --- | --- | ---: |
| **Z1 — Cœur** | Dakar **ouest** (Almadies → Mermoz) | Mandats exclusifs + loc standing + gestion | ★★★ |
| **Z2 — Volume** | Dakar **intermédiaire** + **couronne proche** | Terrains / accession + loc milieu | ★★ |
| **Z3 — Satellite** | **Petite Côte** (Saly / Somone / Ngaparou) | Diaspora + secondaire (V4+) | ★ → ★★ |
| **Z4 — Watch** | Diamniadio, Thiès, secondaires | Opportuniste / Y2 | ★ |
| **No-go** | Zones contentieuses / hors capacité | Refus ou go conditionnel strict | — |

```
        ATLANTIQUE
            │
   Ngor · Almadies · Ouakam · Yoff
            │
   Point E · Fann · Mermoz · Sacré-Cœur   ← Z1 (bureau ancré ici)
            │
   Liberté · Sicap · Parcelles…           ← Z2 proche
            │
   Keur Massar · Rufisque · Diamniadio    ← Z2 / watch
            │
   ──────── autoroute / TER ────────
            │
   Saly · Somone · Ngaparou · Mbour       ← Z3 Petite Côte
```

**Règle :** on ne « couvre pas le Sénégal ». On **farm** Z1 d’abord ; Z3 seulement avec partenaire / journée dédiée ; no-go = réputation &gt; commission.

| Critère | Poids | Lecture hub |

## 6. No-go & go conditionnel

### 6.1 No-go commercial (ne pas mandate / ne pas publier)

| Cas | Motif |
| --- | --- |
| Zone sous **opération / contentieux DGSCOS** active connue | Réputation + litige client |
| Bien présenté avec **délibération = TF** | Fraude typique |
| Prix **aberrant −50 %** sans raison documentée | Suspect |
| Vendeur exige paiement **Wave immédiat** hors séquestre | Culture anti-arnaque |
| Hors Z1–Z3 **et** pas de partenaire local **et** ticket &lt; seuil rentable | CAC visite &gt; marge |
| Programme promoteur sans TF / sans quitus | Risque VEFA / occupation |
| Zone inondable chronique **sans** mitigation / assurance / info claire | Litige post-vente |

**Zones fréquemment signalées contentieuses / plaintes** (`06` parcours foncier — à croiser veille presse) :

- Axe **Mbour / Saly / Sindia / Diass / Malicounda** (densité plaintes)  
- **Tivaouane Peulh, Sangalkam**  
- **Rufisque / Kounoune**, **Dougar / Diamniadio** (faux titres signalés)  
- Périphéries **Keur Massar** à risque  

→ **Pas un interdit géographique absolu** : un bien **TF + EDR + géomètre + notaire** peut passer en **go conditionnel**. Sans ça = **no-go catalogue**.

### 6.2 Go conditionnel (publier seulement si…)

| Condition | Exigence mini |
| --- | --- |
| Terrain couronne / PC | Type papier renseigné · EDR ou équiv. si &gt; seuil Vague 2 |
| Littoral | Check DPM / constructibilité |
| Diaspora remote | Inspection ou Pack Secure |
| Diamniadio | TF + info équipements / délais revente dans fiche |
| Multi-agence concurrent | Uniquement mandat **simple** validé gérant (`04`) |

### 6.3 Matrice décision rapide

```
Bien proposé
  ├─ Hors Z1–Z3 sans partenaire ? ──► NO-GO
  ├─ Red flag §6.1 ? ──► NO-GO
  ├─ Zone watch / contentieux ? ──► Diligence → GO conditionnel ou NO-GO
  ├─ Z1 standing / Mermoz ? ──► GO prioritaire (exclusif)
  ├─ Z2 terrain Mamadou ? ──► GO si papier clair + simu
  └─ Z3 Saly ? ──► GO si exclusif + journée PC ou partenaire
```
