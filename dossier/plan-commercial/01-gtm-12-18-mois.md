## 0. Synthèse — thèse GTM

```
Supply (mandats exclusifs)  →  Demand (catalogue + simus + SEO)
        →  Closing (WA + bureau + notaire)
        →  After-sale (apports + gestion)
        →  Preuve sociale  →  plus de mandats
```

| Principe | Application Y1 |
| --- | --- |
| **Signed agreements first** | 1ʳᵉ victoire = mandat exclusif, pas « awareness » |
| **1 parcours / vague** | V0→V4 = 5 boucles fermées, pas 20 features |
| **Vendeur-first digital** | Site + estimation = supply ; classifieds = syndication sélective |
| **Paid = accélérateur, pas base** | Ads dès M3, plafonnés LTV:CAC ≥ 3:1 |
| **Gestion = ancre LTV** | ON à M6 ; attach loc→gestion ≥ 50 % |

**Cible BASE Y1 (prévisionnel `05`) :** CA **55,9 M** · **14** closings vente · **18** mises en loc · **20** lots gestion fin d’année · **≥ 60 %** exclusifs.

Bench GTM brokerages (PulseRevOps / FinancialModelsLab) : pipeline **avant** ouverture ; 1ʳᵉ métrique = *signed representation* ; réponse lead &lt; minutes (nous : SLA WA **&lt; 24 h** Y1, cible progressive &lt; 1 h). Adapté lean SN : **pas** 8–25 agents Y1 — **1–2 agents + gérant**.

## 5. Funnel commercial cible (Y1)

```
Lead (WA / SEO / partenaire / ads)
  → Qualification &lt; 24 h
  → RDV / visite / simu
  → Mandat exclusif (vendeur)  OU  diligence (acquéreur)  OU  gestion (bailleur)
  → Closing / encaissement
  → Upsell (apport BTP · Secure · gestion)
  → Preuve (avis / CRG) → referral
```

| Étape | Taux ordre de grandeur | Source logique |
| --- | ---: | --- |
| Lead → RDV qualifié | 25–40 % | Discipline WA |
| RDV vendeur → mandat | 30–50 % | Pitch exclusif `04` offre |
| Mandat exclusif → closing 12 mois | **50–70 %** | UE `04` |
| Mise en loc → gestion | **≥ 50 %** | Politique attach |
| Simu → lead partenaire | Tracké V1 | Analytics |
