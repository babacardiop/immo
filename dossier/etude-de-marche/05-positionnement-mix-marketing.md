## 1. Positionnement

### 1.1 Déclaration

> **Agence immobilière full-service au Sénégal**, outillée PropTech : catalogue **curated**, parcours **sécurisés** (titre → closing → chantier / gestion), pas une marketplace d’annonces.

### 1.2 Contre-positionnement

| On est | On n’est pas |
| --- | --- |
| Agence qui opère (mandats, visites, encaissements) | Expat-Dakar « en plus joli » |
| Digital au service du métier | SaaS pur (Noflaye) sans terrain |
| Biens vérifiés que **nous** publions | Open posting |
| Hub parcours (décider → closer → construire / gérer) | Blog conseil isolé |
| Confiance diaspora industrialisée | Courtier WhatsApp familial |

### 1.3 Proposition de valeur (par persona)

| Persona | Promesse en une ligne |
| --- | --- |
| Fatou (diaspora) | *On vérifie avant que tu paies. On te prouve ensuite.* |
| Mamadou (primo terrain) | *Tu vois ta mensualité et le coût de ta maison avant de t’engager — et on lit tes papiers (TF / bail / délibération).* |
| Ousmane / Ibrahima (bailleurs) | *On encaisse, on reverse, tu vois tout en ligne.* |
| Aïssatou (locataire) | *Bail clair, logement réel, pas de surprise à l’entrée.* |
| Marième (vendeuse) | *On met ton bien en marché proprement et on filtre les curieux.* |

### 1.4 Messages marque (dossier)

- *Votre agence — vendre, louer, gérer.*  
- *Pas une marketplace. Une agence.*  
- *Avant de signer ou de payer, on sécurise.*

## 2. Mix marketing (7P — services)

### 2.1 Product (Offre)

**Cœur :**

| Ligne | Contenu | Priorité vague |
| --- | --- | --- |
| Catalogue curated | Terrains, maisons, appartements — TF/bail affiché | V0 |
| Vente classique | Mandat + closing notaire | V0–1 |
| Vente étalée | Mensualités terrain + dashboard | V1 |
| Location-vente | Accession bâti (structuration) | V1+ |
| Location + **gestion** | Bail, quittances, Wave/OM, portails | V3 |
| Outils | Simus mensualité / construction / budget / frais | V1–2 |
| Diligence | Checklist + géomètre + notaire + EDR/NICAD | V2 |
| Contenu | Guides anti-arnaque, TF vs bail vs délibération, AC/délais | Continu |
| Formalités / régularisation | Orientation Yastal / bail (lead partenaire) | V2 |

**Règle produit :** backlog large (52 add-ons) ≠ scope vague. Max ~8–12 ouvertures / vague (`hub-roadmap`).

### 2.2 Price (Tarification)

| Prestation | Prix cible (indicatif marché) | Notes |
| --- | --- | --- |
| Commission vente | **5 %** TTC négociable (fourchette marché 5–10 %) | Afficher clairement FAI / hors frais |
| Mise en location | **1 mois** de loyer (respect plafond décret côté locataire si ≤500k) | Transparence honoraires |
| Gestion locative | **8 %** des loyers encaissés (entrée 7–10 %) | Pack diaspora +1–2 pts si reporting renforcé |
| Frais dossier étalé | **25–50k FCFA** | Filtre tire-au-flanc |
| Estimation / conseil | Lead gratuit → mandat ; ou forfait | |
| Commission apport partenaires | Selon fiches `partenaires/` (archi, BTP, notaire…) | Révélé en convention |

**Principes pricing :**

1. **Transparence** écrite dans le mandat (avantage vs informel).  
2. Prix **aligné marché** au début — se démarquer par la valeur, pas le discount.  
3. Gestion = **ancre LTV** ; accepter un rate compétitif pour gagner le stock sous mandat.  
4. Outils digitaux **gratuits** (lead magnets) ; monétisation = closing / gestion / apport.

### 2.3 Place (Distribution / canaux)

| Canal | Rôle | Priorité |
| --- | --- | --- |
| **Site Next.js** (catalogue, carte, outils, blog) | Hub discovery + SEO | P0 |
| **WhatsApp Business** | Closing & nurture | P0 |
| Agence / points physiques | Confiance locale, signatures | P0 (au moins 1 ancrage Dakar) |
| Partenaires (notaire, BTP, archi) | Apport croisé | P0 Vague 1 |
| SEO / guides | Diaspora & décisions | P0 |
| Classifieds (Expat…) | **Syndication sélective** des mandats (pas open) | P1 |
| Facebook / IG / TikTok | Reach + share cards | P1 |
| Google Ads / Meta Ads | Boost piliers + zones | P2 |
| Banques / BHS / Kajom | Orientation financement | P2 |

**Anti-pattern :** disperser le stock sur 20 sites sans tracking.

### 2.4 Promotion (Communication)

**Territoires de message :**

1. Anti-arnaque / diligence (EDR, NICAD, « délibération ≠ TF »)  
2. Terrain → construire (chiffres FCFA)  
3. Gestion diaspora (reporting)  
4. Preuves d’agence (mandats, licence, SLA)  
5. Zones & délais réels (AC, bail, « Arrêt Dscos » — pédagogie honnête)  

**Mix com (12 mois) :**

| Levier | Intensité | Contenu type |
| --- | --- | --- |
| SEO piliers | Forte | TF vs bail vs délibération, coûts construction, guide diaspora, checklist diligence |
| Organic social + WA Status | Forte | Biens curated, checklists, red flags |
| Relations partenaires | Moyenne | Co-brand dossiers (notaire, géomètre) |
| PR / LinkedIn études | Moyenne | Observatoire / ICAS commentés |
| Ads payants | Légère au début | Retargeting simulateurs |

**Ton :** expert, calme, daté, jamais clickbait (`docs/blog/strategie.md`).

### 2.5 People (Équipe & expérience humaine)

- Agents formés script diligence + WhatsApp SLA &lt; 24 h  
- Visage local obligatoire (photo équipe, bureau)  
- Séparation des rôles diaspora : *présentateur ≠ vérificateur ≠ détenteur des fonds*  
- Partenaires contractualisés (SLA rappel 48 h)

### 2.6 Process (Parcours)

Parcours phares (alignés roadmap) :

1. **Acheteur terrain :** fiche → simu → diligence → notaire → (chantier)  
2. **Diaspora investisseur :** lead → vérif → mandat → reporting  
3. **Bailleur :** mandat gestion → encaissement → reversement → CRG mensuel  
4. **Locataire :** recherche → visite → bail conforme → portail  

Chaque parcours = **1 CTA mesurable** (sim_complete, partner_lead, mandat_signé…).

### 2.7 Physical evidence (Preuves)

| Preuve | Usage |
| --- | --- |
| Mentions TF/bail/NICAD sur fiches | Trust catalogue |
| Photos datées / inspection | Diaspora |
| Quittances & portail | Bailleurs |
| Mandats & carte pro | Légalité |
| Design EverGreen + share cards | Perception premium |
| Études / observatoire | Autorité |

## 3. Stratégie go-to-market (18 mois)

| Phase | Focus | Objectif commercial |
| --- | --- | --- |
| **Vague 0** | Site + 30–80 mandats curated | Preuve « l’agence existe » |
| **Vague 1** | Acheteur terrain + 3 simus + 3 partenaires | Premières commissions apport + réservations étalé |
| **Vague 2** | Diligence / formalités | Taux de closing ↑ ; marque anti-arnaque |
| **Vague 3** | Location + gestion | **MRR** loyers (métrique santé) |
| **Vague 4+** | Diaspora densifiée, chantier, data publique | Scale LTV |

**Règle anti-dispersion :** ≤ 3–5 add-ons + 2–3 partenaires + 1–2 contenus / vague.

## 6. Risques mix & parades

| Risque | Parade |
| --- | --- |
