## A — Papiers & droits

| Terme | Définition courte |
| --- | --- |
| **TF — Titre foncier** | Propriété pleine immatriculée au Livre foncier (Conservation / DGID). |
| **Bail ordinaire** | Occupation domaine privé État ≤ 18 ans (loi 76-66 art. 38). |
| **Bail emphytéotique** | 18–50 ans ; **droit réel** souvent hypothécable (art. 39). |
| **Délibération** | Acte communal d’**affectation** sur domaine national = droit d’**usage** (non cessible, non vendeable). |
| **Délibération exécutoire** | Délibération + **approbation tutelle** (seuils 10/50 ha). Sinon fragile. |
| **AOO** | Autorisation d’occuper — titre précaire. |
| **EDR** | État des droits réels — charges, hypothèques, propriétaire inscrit. |
| **NICAD** | N° identification cadastrale (16 car., décret 2012-396) — obligatoire sur actes. |
| **CIC** | Certificat d’identification cadastrale portant le NICAD. |
| **Livre foncier** | Registre de foi de la propriété immatriculée. |
| **Domaine national (DN)** | Terres non classées domaine public / non immatriculées (loi 64-46) — zones urbaines, classées, terroirs, pionnières. |
| **Domaine public / privé de l’État** | Loi 76-66 — voies, emprises vs patrimoine cessible / bailable. |
| **Mise en valeur** | Obligation liée à l’affectation / bail — non-respect → désaffectation / sanctions. |
| **Canon** | Redevance due au titre du bail Domaines. |
| **Bornage** | Délimitation géomètre — caler plan ↔ terrain. |

## B — Institutions

| Terme | Rôle |
| --- | --- |
| **DGID** | Impôts & Domaines — Conservation, Cadastre, Domaines. |
| **Conservation** | Livre foncier, EDR, mutations, hypothèques. |
| **Cadastre** | Plans, NICAD, extraits. |
| **CSF / Receveur Domaines** | Guichet local baux / instruction. |
| **DEDT** | Direction Enregistrement Domaines Timbre — saisit CCOD. |
| **CCOD** | Commission contrôle opérations domaniales — avis baux ; **DGSCOS membre**. |
| **DGSCOS** (ex-DSCOS) | Surveillance occupation sols ; plaintes ; arrêt chantier ; démolitions (cadre 2026-366). |
| **DRC / DPO** | Directions contentieux / opérations de la DGSCOS. |
| **Brigade zonale** | Porte d’entrée plainte DGSCOS (ressort cour d’appel). |
| **MUCTAT / Urbanisme** | Politique urbaine, codes, AC (ministre pour projets État). |
| **Maire / ASCOM** | Délibérations, AC communale, registres locaux. |
| **Tutelle** | Sous-préfet / préfet / gouverneur selon superficie. |
| **ANAT** | Cartographie / aménagement — **pas** titulaire de titres. |
| **SAFRU** | Aménagement foncier / rénovation urbaine (programmes logement). |
| **PROCASEF** | Projet BM cadastre & sécurisation foncière. |
| **APIX** | Promotion investissements — circuits accélérés. |
| **Primature** | Tutelle DGSCOS depuis 2025. |

## C — Systèmes & programmes digitaux

| Terme | Statut / sens |
| --- | --- |
| **SGF** | Système Gestion Foncière DGID — dématérialisation Domaines/Cadastre/Conservation (montée en charge 2026). |
| **eNICAD** | Outil NICAD numérique (PROCASEF). |
| **SIFCOM** | SI foncier communal — délibérations / droits d’usage (déploiement partiel). |
| **Yastal** | Programme DGID accélération régularisation par **bail**. |
| **TeleDAc** | Télé-demande AC — **non effectif** comme guichet de masse (2026). |
| **PNGCF** | Plateforme Nationale Gestion Contentieux Fonciers (DGSCOS) — backlog plaintes. |
| **TRA-COS** | Plateforme traçabilité occupation / futurs **quitus**. |
| **Quitus DGSCOS** | Attestation / levée de restriction (visée ventes, construire, hypothèque…) — **après base légale**. |
| **DGID-digitale** | Portails services (EDR, fiscalité) — couverture partielle. |

## D — Urbanisme & construction

| Terme | Sens |
| --- | --- |
| **AC** | Autorisation de construire (permis) — arrêté du **maire**. |
| **PLU / PDU / SDAU / POAS** | Documents de planification / occupation des sols. |
| **Code urbanisme 2023-20** | Refonte ; Livre VII = sanctions / contrôles occupation. |
| **Code construction 2023-21** | Normes bâti. |

| **ERP / IGH** | Établissement public / immeuble grande hauteur — dossiers complexes. |
| **VEFA** | Vente en l’état futur d’achèvement (promoteurs). |

## E — Transaction & agence (vocabulaire hub)

| Terme | Sens |
| --- | --- |
| **Mandat curated** | Bien publié **par l’agence** après contrôle pièces — pas open posting. |
| **Vente étalée** | Paiement terrain par mensualités (TF/bail). |
| **Location-vente** | Accession bâti via redevances. |
| **Diligence** | Vérifications pré-paiement (EDR, NICAD, visite, notaire). |
| **Séquestre / escrow** | Fonds bloqués jusqu’à conditions (closing). |
| **FAI** | Frais d’agence inclus (dans le prix affiché). |

## F — Phrases à ne jamais dire au client

| Phrase trompeuse | Correction |
| --- | --- |
| « La délibération c’est comme un titre » | Non — droit d’usage seulement. |
| « TeleDAc a déjà validé, tu peux construire » | Vérifier **arrêté du maire** papier. |
| « Paie d’abord, on régularise après » | Diligence **avant** paiement. |
| « Mon cousin a vérifié » | Séparer rôles ; notaire + EDR. |
| « La DGSCOS te donne le permis » | AC = mairie ; DGSCOS = contrôle. |
