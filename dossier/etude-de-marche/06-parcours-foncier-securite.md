# Parcours foncier & sécurité transactionnelle — Guide hub

**Document :** Dossier · Étude de marché · 06  
**Origine :** enrichi depuis l’étude gouvernementale TRA-COS / PNGCF / DGSCOS (`Tracos/docs`)  
**Usage :** agents, diligence, contenu blog, specs Vague 2  
**Statut :** v1.0 — sept. 2026

> **Règle d’or :** la délibération **n’est pas** un titre de propriété et **n’autorise pas** la vente.  
> Le hub doit l’expliquer **avant** toute mise en mandat.

---

## 1. Les trois coffres (architecture mentale)

Toute transaction immobilière au Sénégal touche (au moins) un de ces registres :

| Coffre | Qui détient | Ce qu’il dit | Ce qu’il ne dit pas |
| --- | --- | --- | --- |
| **TITRE** | DGID — Conservation / Cadastre / Domaines (+ SGF, PROCASEF) | TF, bail inscrit, EDR, NICAD, délibérations (SIFCOM) | Litiges DGSCOS, occupation réelle du jour |
| **OCCUPATION** | DGSCOS → futur TRA-COS (quitus) | Qui occupe / construit / arrête chantier | Propriété juridique |
| **CONTENTIEUX** | DGSCOS → PNGCF | Plaintes, PV, sommations, démolitions | Création de titres |

**Implication hub :** on **lit** le coffre TITRE (EDR, NICAD, notaire) ; on **surveille** le risque OCCUPATION/CONTENTIEUX (zones chaudes, « Arrêt Dscos ») ; on **n’écrit jamais** dans le Livre foncier.

## 2. Hiérarchie des papiers (à enseigner au client)

```
Titre foncier (TF)          ← propriété pleine (Livre foncier)
        ▲
Bail emphytéotique          ← droit réel 18–50 ans (hypothécable)
        ▲
Bail ordinaire              ← ≤ 18 ans ; occupation opposable
        ▲
Délibération exécutoire     ← droit d’USAGE seulement (non cessible)
        ▲
Occupation de fait / « vente » WhatsApp  ← risque maximal
```

| Papier | Ce qu’on peut faire | Risque vendeur→acheteur |
| --- | --- | --- |
| **TF** | Vendre chez notaire ; hypothéquer | Faible si EDR propre |
| **Bail emphytéotique** | Céder / hypothéquer selon clauses | Moyen — vérifier inscription + canon |
| **Bail ordinaire** | Occupant protégé ; cession limitée | Moyen–élevé |
| **Délibération (+ tutelle)** | Usage personnel ; **pas** une vente légale | **Élevé** — « ventes » = pratique à risque |
| **Sans papier / faux** | Rien de sûr | Critique — arnaque / double vente |

**Discount marché typique :** délibération ~**−30 à −40 %** vs TF (observé terrain) — le prix bas **achète le risque**.

## 3. Parcours A → B (affectation → bail)

Synthèse opérationnelle de `Tracos/docs/parcours-complet.md`.

### Phase A — Domaine national (collectivité)

```
Demande maire → ASCOM (reçu) → Commission domaniale (enquête)
→ Délibération conseil → Approbation tutelle (seuils ha)
→ Installation + extrait → droit d’USAGE
```

| Seuil superficie | Tutelle qui approuve |
| --- | --- |
| **≤ 10 ha** | Sous-préfet ou préfet |
| **> 10 et ≤ 50 ha** | Préfet |
| **> 50 ha** | Gouverneur (acte SGG) |

**Sans approbation exécutoire :** délibération fragile ; bail ultérieur compromis.

### Phase B — Domaine privé de l’État (bail)

```
Dossier (Yastal / CSF) → Receveur Domaines
→ Avis Domaines + Cadastre + Urbanisme (bordereaux)
→ DEDT → CCOD (dont DGSCOS) → Notification → Signature bail
→ Inscription Livre foncier
```

| Étape | Délai indicatif |
| --- | --- |
| Phase B (bail) | **3–6 mois** (souvent + si litige / CCOD) |
| Conversion bail → TF | **6–18 mois** |
| Jalons investisseur types | Dispo J+15–30 → CCOD J+30–60 → acte J+60–90 → inscription ~30 j |

**Canal Yastal (DGID) :** accélération régularisation par bail — encore largement guichet.

## 4. Parcours autorisation de construire (après titre)

| Étape | Réalité terrain |
| --- | --- |
| Prérequis | Titre d’occupation légal (TF / bail…) + NICAD / plan |
| Dépôt | **Papier en mairie** (voie réelle) |
| Délais légaux | 28 j (simple) / 40 j (complexe) si dossier **complet** |
| Délais réels | Souvent **3 mois → > 1 an** |
| TeleDAc | **Non effectif** comme guichet de masse (2026) — ne pas promettre |
| Silence | Réputé accordé sous conditions (décret 2020-1463) |
| Sans AC | Exposition **Arrêt DGSCOS**, contentieux, démolition |

**Qui délivre :** le **maire** (instruction Urbanisme communal) — **pas** la DGSCOS.  
**Qui contrôle :** DGSCOS (occupation / arrêt / démolition).

## 5. DGSCOS — ce que le client (et l’agence) doivent savoir

| Fait | Détail |
| --- | --- |
| Institution | **DGSCOS** (ex-DSCOS) — décret **2026-366** ; tutelle **Primature** |
| Mission | Surveillance / contrôle occupation ; lutte occupations irrégulières |
| Volume | **Milliers** de plaintes 2024–2025 ; DG : **+1 000** en 3 mois début 2025 ; flux évoqué **30–100 / jour** |
| Zones chaudes | Tivaouane Peulh, Sangalkam ; axe Mbour / Saly / Sindia / Diass / Malicounda |
| Saisine | Brigade zonale ; pièces : titre, EDR, plan cadastral ; **gratuit** ; n° dossier ≤ **48 h** |
| « Arrêt Dscos » | Suspension chantier — anxiogène pour promoteurs / acquéreurs |
| Démolitions | Controversées (ex. Tivaouane Peulh déc. 2025) ; Me Ndoye : pas de démolition sur titre privé sans juge |

**Pour le hub :** avant chantier / VEFA / terrain périphérie — **check litige / zone / quitus futur**. Ne jamais présenter un bien en zone d’opération DGSCOS sans disclaimer.

## 6. Checklist diligence (Vague 2 — produit)

### 6.1 Avant tout paiement (ordre obligatoire)

1. **Identifier le régime** : TF / bail / délibération / domaine public / DN  
2. **EDR** (Conservation / dgid.sn) — hypothèques, saisies, propriétaire inscrit  
3. **NICAD** + extrait plan Cadastre  
4. **Visite terrain** indépendante (bornes, occupation réelle, riverains)  
5. **Notaire choisi par l’acheteur** (jamais imposé par le vendeur seul)  
6. **Séparer les rôles** diaspora : présentateur ≠ vérificateur ≠ détenteur des fonds  
7. **Procuration** limitée (parcelle, prix plafond, durée)  
8. Paiement **traçable** (virement / séquestre) — jamais cash WhatsApp  

### 6.2 Red flags (refuser ou surprixer le risque)

| Signal | Action |
| --- | --- |
| « Délibération = titre » | **Éduquer** ; pas de mandat vente classique sans disclaimer |
| Pression paiement immédiat | Stop |
| Photos vendeur seules (diaspora) | Inspection tierce photos datées |
| Prix −50 % vs quartier sans explication | Suspect |
| Double affichage même parcelle | Relier NICAD / tél ; abandon |
| Zone « Arrêt Dscos » / contentieux ouvert | Diligence renforcée / no-go |
| Tutelle non prouvée sur délibération | Inopposable |
| TeleDAc « déjà OK » sans arrêté maire | Vérifier papier |

### 6.3 Pièces minimales par type de mandat

| Mandat | Pièces P0 |
| --- | --- |
| Vente TF | Copie TF, EDR récent, NICAD, pièce identité vendeur |
| Vente bail | Bail inscrit, EDR, preuve canon, NICAD |
| Terrain délibération | Extrait + **preuve tutelle**, PV installation, disclaimer risque, orientation régularisation bail |
| Location bâti | Titre d’occupation bailleur, conformité décret loyers |
