# Analyse de la demande — Immobilier Sénégal

**Document :** Dossier · Étude de marché · 02  
**Lié à :** [`01-analyse-sectorielle.md`](./01-analyse-sectorielle.md) · [`docs/positioning.md`](../../docs/positioning.md)  
**Horizon :** 2023 – sept. 2026  
**Statut :** v1.0

## Synthèse

La demande immobilière au Sénégal est **abondante, fragmentée et sous-servie**. Elle se structure autour de **trois tensions** :

1. **Habiter Dakar coûte trop cher** — jusqu’à ~50 %+ des revenus en loyer pour beaucoup de ménages urbains ; ~56 % des ménages dakarois sont locataires.
2. **Devenir propriétaire est un parcours d’obstacles** — crédit rare (~4 % d’adultes avec hypothèque), foncier opaque, arnaques fréquentes (surtout diaspora).
3. **Investir à distance est un besoin massif non industrialisé** — ~2 200 Mds FCFA/an de transferts diaspora, encore peu canalysés vers un parcours confiant.

Pour le hub, la demande utile n’est pas « tout le monde qui veut un toit » (278k+ demandes sociales) — c’est les segments **solvables ou monétisables** via commission, gestion ou apport partenaires.

## 1. Taille & intensité de la demande

| Signal | Ordre de grandeur | Lecture |
| --- | --- | --- |
| Déficit logements | 320k → 500k unités | Demande non satisfaite structurelle |
| Demandes logement social enregistrées | **278 653** (Dakar 197k) | File d’attente politique ; peu adressable en commission classique |
| Locataires Dakar | **~56 %** des ménages | Pool gestion + mise en location |
| Propriétaires nationaux | **67,4 %** | Pool potentiel vendeurs / bailleurs |
| Auto-construction | **~62 %** | Forte demande « terrain → construire » |
| Transferts diaspora | **~10 % PIB** | Demande remote + patrimoine |
| CA agences (ICAS 2025) | **−15 %** | Demande existe ; **friction / attentisme** sur le closing formel |

**Funnel réel du marché :**

```
Besoin habitat (très large)
    → Intention chercher (WhatsApp, FB, classifieds)
        → Visite / négociation (souvent informelle)
            → Closing sécurisé (notaire, TF) ← GOULOT
                → Après-vente (construire / louer / gérer) ← SOUS-SERVI
```

Le hub monétise surtout **du goulot vers l’aval**.

## 2. Segmentation stratégique

### 2.1 Par rôle dans la transaction

| Segment | Qui | Ce qu’ils cherchent | Revenu hub |
| --- | --- | --- | --- |
| **A. Acquéreurs** | Locaux, diaspora, expat | Terrain / bâti / étalé / loc-vente | Commission vente + apport partenaires |
| **B. Locataires** | Actifs, familles, étudiants, expat | Bail clair, quartier, budget | Honoraires mise en location |
| **C. Vendeurs** | Proprios, héritiers, lotisseurs | Liquidité, mandat, prix juste | Commission vente |
| **D. Bailleurs** | Locaux + diaspora | Encaissement, zéro stress | **Gestion 5–10 % récurrent** |
| **E. Promoteurs / coopératives** | B2B léger | Commercialisation, leads | Mandats / co-marketing (vague ultérieure) |

### 2.2 Par solvabilité & mode d’accès

| Couche | Budget typique (indicatif) | Mode adapté | Priorité hub |
| --- | --- | --- | --- |
| **Social / précaire** | Loyer &lt; 100–150k ; logement &lt; 15–20 M | Programmes publics, coopératives | Faible (contenu / orientation) |
| **Classe moyenne urbaine** | Loyer 150–400k ; terrain 8–40 M étalé | Étalé, loc-vente, périphérie | **Haute** |
| **Cadres / professions libérales** | Loyer 400k–1 M+ ; achat 50–200 M | Vente classique, crédit BHS | Haute |
| **Standing / expatriés** | Loyer 800k–2 M+ ; Almadies / Ngor | Vente / location premium | Moyenne–haute (marge) |
| **Diaspora investisseur** | Ticket 10–150 M+ ; remote | TF vérifié + gestion | **Haute (différenciation)** |

### 2.3 Par géographie d’intention

| Zone | Intention dominante | Persona clé |
| --- | --- | --- |
| Dakar centre / ouest | Location standing, investissement | Expat, cadre, diaspora premium |
| Couronne (Keur Massar, Rufisque, Diamniadio) | Accession, terrain, construire | Primaire local, diaspora « premier bien » |
| Petite Côte | Secondaire, locatif saisonnier | Diaspora, dakarois aisés |
| Thiès / secondaires | Décote, terrain, villa | Locaux + report Dakar |

## 4. Comportements d’achat & parcours

### 4.1 Canaux de découverte (ordre d’importance terrain)

1. **WhatsApp** (statuts, groupes, transfert de contacts)  
2. **Facebook** (groupes immo, Marketplace)  
3. **Classifieds** (Expat-Dakar, CoinAfrique)  
4. **Bouche-à-oreille / famille**  
5. **Google** (surtout diaspora : « acheter terrain Sénégal TF »)  
6. **Agences physiques** / panneaux  

**Implication :** presence WhatsApp + SEO diaspora + catalogue curated > pub display pure.

### 4.2 Critères de décision (par ordre de poids)

| Rang | Acquéreur terrain | Locataire | Diaspora |
| --- | --- | --- | --- |
| 1 | Nature du **papier** (TF/bail) | Prix + quartier | **Confiance / preuves** |
| 2 | Prix / mensualité | État du bien | Titre vérifié |
| 3 | Viabilisation / accessibilité | Caution / avance | Reporting / gestion |
| 4 | Possibilité construire | Proximité travail | Traçabilité paiements |
| 5 | Réputation vendeur/agence | Meublé ou non | Procuration cadrée |

### 4.3 Moments de vérité (où on gagne ou on perd)

| Moment | Risque | Réponse hub |
| --- | --- | --- |
| Premier contact WhatsApp | Ghosting / spam | SLA &lt; 24 h, script diligence |
| Demande de paiement anticipé | Arnaque | Jamais avant vérif titre / séquestre |
| Visite terrain | Décalage photos / réalité | Agent + géoloc / inspection |
| Signature | Pression vendeur | Notaire partenaire, checklist |
| Après achat | Chantier / locatif | Pack construction / mandat gestion |

### 4.4 Freins psychologiques récurrents

- « Les agences sont chères / inutiles »  
- « Mon frère s’occupe de tout » (diaspora)  
- « Si c’est sur internet c’est fake »  
- « Je paie cash pour aller plus vite »  
- Attentisme 2025–2026 (ICAS en baisse, incertitude macro/foncier)  
- **Peur DGSCOS** : « On va me démolir / Arrêt Dscos » (périphérie, lotissements litigieux)  
- Confusion **délibération = titre** (entretien vendeurs / Facebook)

### 4.5 Douleurs foncières (depuis étude TRA-COS / DGSCOS)

| Douleur citoyenne | Intensité | Persona touchée |
| --- | --- | --- |
| Plaintes sans suite (backlog État) | ★★★ | Tous ; particulièrement occupants / riverains |
| Double vente / faux titre / multi-affectation | ★★★ | Fatou, Mamadou |
| Achat sur délibération puis litige | ★★★ | Mamadou, diaspora « premier bien » |
| Chantier stoppé sans motif clair | ★★ | Promoteurs, Jean-Pierre, VEFA |
| Délais bail / AC (mois → année) | ★★★ | Mamadou (construire), promoteurs |
| Opacité « où en est mon dossier Domaines / mairie » | ★★ | Tous les régularisants |

**Insight :** une partie de la demande solvable **n’achète plus** (ou paie moins) faute de **preuve et de parcours lisible** — exactement ce que le hub industrialise.

## 8. Insights pour le mix & le produit

1. **Parler confiance avant catalogue** — surtout diaspora.  
2. **Montrer des chiffres FCFA** (mensualité, construction, frais) — réduit l’anxiété.  
3. **WhatsApp n’est pas un canal secondaire** — c’est le CRM.  
4. **Le locataire d’aujourd’hui est l’accédant de demain** — portail + scoring.  
5. **Ne pas cibler les 278k demandes sociales** comme clients directs — trop peu solvables pour le modèle agence privé, sauf orientation politique / B2G plus tard.
