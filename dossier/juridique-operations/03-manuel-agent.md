## 2. Scripts WhatsApp (réponses rapides)

*Coller dans WA Business. Adapter prénom / réf. Ton : clair, honnête, pro (`06` culture).*

### 2.1 Accueil auto

```
Bonjour et bienvenue chez [Agence] 🏠
Vous cherchez à acheter, vendre, louer, ou une question dossier ?
Répondez : ACHAT / VENTE / LOCATION / GESTION / AUTRE
Réponse sous 24 h (lun–sam 9h–19h), souvent plus vite.
```

### 2.2 Accusé humain + qualif achat

```
Bonjour [Prénom], bien reçu. Je reviens avant [heure/jour].
Pour bien orienter :
1) Budget max (FCFA) ?
2) Zone(s) ?
3) Terrain ou bâti ?
4) Délai (ce mois / 3 mois / +6 mois) ?
5) Sur place ou diaspora ?
```

### 2.3 Qualif vente (vendeur)

```
Bonjour [Prénom], pour l’estimation :
1) Adresse / quartier ?
2) Type (appart / maison / terrain) ?
3) Timing de vente (urgent / 3–6 mois / exploratoire) ?
4) Type de papier connu (TF / bail / délibération / ? ) ?
Je propose 2 créneaux visite : [A] ou [B] ?
```

### 2.4 Qualif location

```
Bonjour [Prénom],
1) Budget loyer max HC ?
2) Zone · chambres · meublé/nu ?
3) Date d’entrée souhaitée ?
4) Locataire ou bailleur ?
Je vous envoie 1–2 options curated + créneaux visite.
```

### 2.5 Confirmation visite (J−1)

```
Rappel visite [réf] — [jour] [heure]
Lieu RDV : [adresse / landmark]
Durée ≈ 30–45 min. Pièce d’identité appréciée.
Merci de confirmer OUI / reporter.
```

### 2.6 Post-visite acquéreur (J0 soir)

```
Merci pour la visite de [bien].
En 2 mots : points + et points − ?
Je ajuste la shortlist demain matin.
```

### 2.7 Relance post-visite (J+1)

```
Petit suivi visite [bien] — toujours intéressé(e),
offre à préparer (sous conditions diligence), 2ᵉ visite, ou on écarte ?
```

### 2.8 Éthique papiers (terrain)

```
Important : une délibération n’est pas un titre foncier.
Avant tout engagement, on lit les papiers (EDR / régime) avec nos partenaires.
Je vous envoie la checklist — on démarre ?
```

### 2.9 Anti-Wave / diaspora

```
Pour votre sécurité : aucun paiement Wave/OM direct au vendeur sur notre conseil.
Parcours : vérification → (mandat) → séquestre / notaire.
Je vous envoie le protocole écrit.
```

### 2.10 Handoff partenaire

```
Je vous mets en relation avec [Nom] — [métier].
Il/elle rappelle sous 48 h. Réf. dossier : [ID].
Je reste en copie pour le suivi.
Le devis / l’acte est à son nom ; on orchestre.
```

### 2.11 Closing soft exclusif (post-estimation)

```
Je vous propose un mandat exclusif 90 jours :
photos, fiche avec type de papier, un seul prix, filtrage visites,
compte-rendu bi-mensuel WA.
On signe [jour] + shoot photos le même jour — OK ?
```

### 2.12 Break-up (silence long)

```
Sans nouvelles, je classe le dossier en pause.
Répondez OUI pour rester en boucle mensuelle, sinon bonne continuation.
```

## 3. SOP Visite

### 3.1 Types de visite

| Type | Objectif | Durée | Livrable CRM |
| --- | --- | --- | --- |
| **Estimation vendeur** | Mesurer · photos · pitch exclusif | 45–60 min | Fourchette écrite J0 |
| **Acquéreur / locataire** | Filtrer · qualifier · feedback | 30–45 min | Fiche visite + score |
| **Vidéo diaspora** | Live WA/Meet · questions temps réel | 20–40 min | Replay / notes |
| **Inspection partenaire** | Constat pro (Pack Secure) | Selon devis | Rapport partenaire |

### 3.2 Avant la visite (T−24 h)

- [ ] Confirmer créneau WA (§2.5)  
- [ ] Fiche bien : prix · type papier · disclaimer si ≠ TF  
- [ ] Clés / accès / contact gardien  
- [ ] Comparables ou shortlist alternatives (acquéreur)  
- [ ] Si terrain : GPS / plan si dispo · red flags connus  
- [ ] Tenue pro · charge téléphone · mètre / notes  

### 3.3 Pendant — estimation vendeur

| Étape | Action |
| --- | --- |
| 1 | Présentation + rappel : estimation **écrite**, pas engagement oral prix magique |
| 2 | Tour bien · notes état · photos (lumière, façades, défauts) |
| 3 | Questions papier : TF / bail / délibération · copies ? |
| 4 | Timing vendeur · occupants · travaux en cours |
| 5 | Pitch exclusif 3 mois (§2.11) — **pas** signer sous pression si doute papier |
| 6 | Next step daté : envoi fourchette **aujourd’hui** · signature [jour] |

### 3.4 Pendant — acquéreur / locataire

| Étape | Action |
| --- | --- |
| 1 | Accueil · rappeler **prix + type papier** avant d’entrer |
| 2 | Laisser le client observer · questions ouvertes |
| 3 | Points techniques factuels (pas « c’est parfait ») |
| 4 | Loc : annoncer **total d’entrée** avant visite (loyer + caution + honoraires) |
| 5 | Noter feedback à chaud · proposer suite (offre / autre bien / diligence) |
| 6 | **Jamais** accepter acompte Wave sur place |

### 3.5 Fiche visite (min. à remplir)

| Champ | |
| --- | --- |
| Date / heure / agent | |
| Bien réf / adresse | |
| Visiteur (ID CRM) | |
| Présenté par hub ? (preuve anti-contournement) | Oui |
| Intérêt 1–5 | |
| Points + / − | |
| Suite | Offre / 2ᵉ visite / écarté / diligence |
| Signature visiteur (si mandat exclusif vendeur) | Option |

### 3.6 Après la visite (T+2 h)

- [ ] WA J0 soir (§2.6)  
- [ ] CRM + photos légendées  
- [ ] Vendeur informé si exclusif (« 1 visite qualifiée aujourd’hui ») — sans inventer d’offre  
- [ ] Si intérêt fort terrain : lancer script diligence (§4)  

### 3.7 Visite vidéo diaspora (Locadakar / Kolonell adapté)

```
Checklist vidéo :
- Connexion test 5 min avant
- Tour lent pièces + façades + accès
- Montrer compteurs / défauts (honnêteté)
- Zoom sur pièces papier si demandées (pas « validation »)
- Fin : « prochaine étape = diligence / inspection pro si GO »
```

## 4. Diligence (terrain agent)

*Réf. complète : `02-politique-anti-fraude` · `06-parcours-foncier`. L’agent **spotte** et **collecte** ; OD/partenaires **exécutent** EDR.*

### 4.1 Quand freiner

| Moment | Action agent |
| --- | --- |
| Client veut payer **maintenant** | Script anti-Wave · stop |
| 1 rouge **ou** ≥ 2 orange | Suspendre · escalade OD/GER |
| Terrain &gt; seuil / délibération | CTA checklist · pas de boost solo |
| Avant offre écrite sérieuse | Mentions « sous conditions diligence » |

### 4.2 Checklist agent (pré-paiement) — ordre

```
1. Identité vendeur / capacité (indivision ?)
2. Type de droit déclaré ≠ improvisé
3. Réfs titre / NICAD / bail si dispo
4. Demande EDR (via OD / partenaire) — ne pas « garantir » soi-même
5. Concordance visite / plan / GPS
6. Occupation réelle (qui habite ?)
7. Notaire : proposer étude hub ou choix client éclairé
8. Circuit fonds = séquestre (écrire le protocole)
9. POA diaspora : limitée · datée · prix plafond → voir doc 06
10. Verdict CRM : GO / GO conditionnel / NO-GO (GER si sensible)
```

### 4.3 Scripts red flags

**Pression Wave :**
```
Je ne peux pas accompagner un paiement Wave au vendeur.
C’est une règle agence pour votre sécurité.
On passe par séquestre notaire après vérification — sinon je dois me retirer du dossier.
```

**Délibération = TF :**
```
Attention : ce que vous décrivez est une délibération (droit d’usage),
pas un titre foncier. On peut avancer seulement avec diligence / régularisation claire.
```

**« Le notaire arrangera » :**
```
Le notaire sécurise l’acte ; il ne transforme pas magiquement un mauvais papier.
On fait la checklist avant l’acompte.
```

### 4.4 Hiérarchie à connaître par cœur

```
TF  >  Bail emphytéotique  >  Bail ordinaire  >  Délibération  >  Rien / WhatsApp
```

### 4.5 Phrases **interdites** (faute grave)

1. « La délibération, c’est bon pour vendre. »  
2. « Le notaire arrangera. » (sans process)  
3. « Envoie sur mon Wave, je gère. »  
4. « Personne ne regarde les EDR ici. »  
5. « TF en 48 h » / « TeleDAc magique »  
6. « On construit pour vous » (si partenaire BTP)  
7. Promettre rappel partenaire **&lt; 2 h** (SLA = **48 h**)

## 5. Closing

### 5.1 Closing **mandat** (vendeur / bailleur)

| Étape | |
| --- | --- |
| 1 | Fourchette / plan d’actions **écrit** envoyé |
| 2 | Relance J+1 / J+3 / J+7 (`07` playbooks) |
| 3 | Vérifier type mandat (exclusif prioritaire) + % grille |
| 4 | Remplir mandat `01` · n° registre · 2 originaux |
| 5 | Photos + fiche catalogue **même jour** si possible |
| 6 | CRM : mandat actif · échéance 90 j · reporting bi-mensuel |

**Si refuse exclusif :** motif CRM → GER avant simple (surtout lead **paid**).

### 5.2 Closing **offre acquéreur**

```
Parcours proposé :
1) Offre écrite sous conditions diligence (EDR, etc.)
2) Acceptation vendeur
3) Diligence / Pack Sécuriser si besoin
4) Notaire + séquestre
5) Acte

Je rédige l’offre avec conditions suspensives claires — OK ?
```

**Ne pas :** faire signer une offre « ferme » sans diligence sur terrain sensible.

### 5.3 Tunnel closing (acte)

| Étape | Agent | OD / Partenaire |
| --- | :---: | :---: |
| Pièces vendeur / acquéreur | R collecte | C |
| Intro notaire (convention live) | C | R |
| EDR / formalités | I | R |
| Séquestre ouvert | I | Notaire |
| Date acte | C | R |
| Commission hub | I | EC après encaissement |
| Archive 5 ans | — | R |

**WA J−2 acte :**
```
Rappel signature [étude] — [date heure]
Pièces : [liste]. Fonds : séquestre confirmé ?
Je reste joignable ce jour-là.
```

**WA post-acte :**
```
Félicitations pour la signature.
Prochaines étapes admin : [mutation / clés / …].
Besoin constructeur / gestion / assurance ? Je peux introduire un partenaire.
```

### 5.4 Closing **location**

| Avant visite | Annoncer total d’entrée (loyer + caution plafonds + honoraires) |
| --- | --- |
| Honoraires | 1 mois · ≤ ½ mois si habitation ≤ 500 k (décret) — vérifier `03` conformité |
| Signature | Bail + EDL entrée · quittances traçables |
| Attach | Proposer gestion **le jour du bail** (§ playbook E) |

```
Locataire placé sur [adresse].
Pour l’encaissement et les relances, on active la gestion 8 % ?
Mandat 1 page — je l’envoie ?
```

### 5.5 Closing **apport partenaire**

- Convention `02` signée **avant** intro  
- PartnerLead CRM  
- Ne pas promettre délai devis inventé  
- Commission = déclencheur Annexe A (pas avant encaissement partenaire)
