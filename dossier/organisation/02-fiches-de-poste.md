## 1. Agent commercial (AC)

### 1.1 Identité du poste

| | |
| --- | --- |
| **Intitulé** | Agent commercial / Négociateur immobilier |
| **Pôle** | Commercial |
| **N+1** | Gérant |
| **Lieu** | Dakar (terrain + bureau) · mobilité quartiers cibles |
| **Horaires** | Flexibles ; soirs/week-ends selon visites |

### 1.2 Mission

Développer et convertir un portefeuille de **mandats exclusifs** (vente / location), accompagner clients jusqu’au **closing**, alimenter le **CRM société**, et respecter les SLA WhatsApp — dans le cadre curated hub (pas d’open posting).

### 1.3 Missions détaillées

**Prospection & mandats**
- Prospecter propriétaires (réseau, terrain, leads site/SEO, WhatsApp)
- Obtenir des **mandats exclusifs** en priorité (≥ 60 % cible `04`)
- Réaliser estimations alignées marché local (pas de surpromesse)
- Saisir / mettre à jour annonces dans le **portail agent** (catalogue curated)

**Commercialisation**
- Organiser et conduire les visites
- Qualifier besoins acquéreurs / locataires
- Négocier offres et contre-offres
- Coordonner notaire, diagnostics, partenaires (sans promettre papiers magiques)

**Closing & admin commercial**
- Monter le dossier jusqu’à signature / encaissement commission
- Pousser **upsell gestion** après toute mise en location
- Orienter leads simulateurs vers partenaires (trackés) — ne pas « garder » le lead

**Qualité & conformité**
- Réponse WhatsApp / leads : **&lt; 24 h** (cible &lt; 5 h si possible)
- Aucun mandat « livre perso » — tout dans le CRM
- Escalade diligence foncière à Ops / gérant avant engagement client sur terrain sensible

### 1.4 KPI & objectifs

| KPI | Cible BASE |
| --- | --- |
| Closings / an (par agent) | **≥ 6** (sinon plan 90 j) |
| Closings / mois équipe | Contribuer à **≥ 2** moy. |
| % mandats exclusifs | **≥ 60 %** |
| SLA 1ʳᵉ réponse lead | **&lt; 24 h** |
| Taux visite → offre | Suivi mensuel |
| Upsell gestion post-location | **≥ 50 %** des mises en loc |

### 1.5 Profil

| | Attendu |
| --- | --- |
| Expérience | 1–3 ans transaction immo SN **ou** commercial terrain excellent |
| Savoirs | Marché Dakar (quartiers), bases droit / mandats, négociation |
| Savoir-faire | WhatsApp pro, CRM, estimation, closing |
| Savoir-être | Persuasion, éthique papiers, résilience, mobilité |
| Langues | Français + wolof fortement souhaité ; anglais diaspora = plus |
| Permis | Souhaité |

*Réf. métier : négociateur immobilier (prospection → estimation → visites → closing) — Achil / Apec / IMSI, adapté SN.*

### 1.6 Rémunération (indicatif `05`)

| | Agent 1 | Agent 2 |
| --- | ---: | ---: |
| Fixe mensuel | **250 k** | **220 k** |
| Split | **40 %** de la commission **agence** sur ses deals | Idem |
| Charges sociales | +~22 % sur fixe (employeur) | Idem |

Exemple : closing commission agence 3 M → split agent **1,2 M** (COGS) + fixe.

### 1.7 Ne fait pas

- Décider seul d’un mandat simple « pour faire du volume » si CAC payant
- Promettre un TF / NICAD sans partenaire diligence
- Emporter le fichier clients hors CRM
- Négocier le % agence sous 5 % exclusif sans accord gérant

## 2. Gestionnaire locatif (GL)

### 2.1 Identité du poste

| | |
| --- | --- |
| **Intitulé** | Gestionnaire locatif / Chargé(e) de gestion |
| **Pôle** | Back-office |
| **N+1** | Gérant (Y2 : éventuellement Ops lead) |
| **Entrée** | **Y2** quand stock **≥ 40–50 lots** ; avant = missions portées par **OD** |
| **Portefeuille cible** | 40–80 lots / ETP en montée (pas 300 dès J1) |

### 2.2 Mission

Assurer le cycle complet de la **gestion locative** pour compte de bailleurs : bail → encaissement → relation → sortie — honoraires cibles **~8 %**, traçabilité Wave/OM, faible vacance et churn.

### 2.3 Missions détaillées

**Cycle locatif**
- Prise de mandat de gestion (avec agent / gérant)
- Sélection dossiers locataires, états des lieux E/S
- Rédaction / suivi baux (cadre SN — pas copier-coller loi FR)
- Quittancement, relances amiables, précontentieux
- Révision loyers / charges selon contrat
- Restitution dépôts de garantie

**Relation & technique**
- Interface bailleur ↔ locataire (diplomatie)
- Coordination artisans / sinistres (premier niveau)
- Reporting mensuel bailleur (loyers, vacance, incidents)
- Alerte vacance &gt; X jours → agent location

**Digital & cash**
- Suivi encaissements Wave / Orange Money
- Séparation claire : flux proprio vs **honoraires agence**
- Alim CRM / outil gestion (dès dispo Vague 3)

### 2.4 KPI & objectifs

| KPI | Cible |
| --- | --- |
| Taux de vacance | Minimiser ; relocation rapide |
| Churn bailleurs / an | **&lt; 15–20 %** |
| Délai quittance / reporting | Mensuel J+5 max |
| Impayés &gt; 30 j | Process relance documenté |
| Honoraires moyens | Tenir **≥ 7–8 %** (pas bradé) |

### 2.5 Profil

| | Attendu |
| --- | --- |
| Expérience | 1–2 ans gestion locative ou admin immo |
| Savoirs | Baux, quittances, bases comptables, relation conflictuelle |
| Outils | Excel + WhatsApp ; logiciel gestion = formation interne |
| Soft | Rigueur, diplomatie, résistance stress |
| Formation | BTS/licence immo ou droit = plus ; expérience SN prioritaire |

*Réf. : gestionnaire locatif (Voluntae / France Travail C1502 / Apec) — cycle bail→quittance→contentieux, adapté Sénégal.*

### 2.6 Rémunération (indicatif)

| | Y2 hyp. |
| --- | ---: |
| Fixe | **280–350 k**/mois |
| Variable optionnel | Bonus sur rétention lots / baisse vacance |

### 2.7 Ne fait pas

- Syndic de copropriété (hors scope early)
- Closing vente (renvoi agent)
- Diligence foncière terrain (renvoi OD / partenaire)
- Décider seul d’une baisse d’honoraires sous 7 %

## 3. Ops / diligence (OD)

### 3.1 Identité du poste

| | |
| --- | --- |
| **Intitulé** | Ops admin · Coordinateur diligence & dossiers |
| **Pôle** | Back-office |
| **N+1** | Gérant |
| **Entrée BASE** | **M7** (`05`) — polyvalent Y1 |
| **Évolution** | Y2 : recentrage diligence / partenaires **ou** lead ops si GL embauché |

### 3.2 Mission

Tenir le **back-office** de l’agence : CRM, dossiers transaction, **orchestration diligence foncière** (Vague 2) avec partenaires formalités/géomètre/notaire, tracking **apports** (SLA 48 h), et **gestion locative de démarrage** jusqu’à embauche GL.

### 3.3 Missions détaillées

**Ops & admin**
- Qualité données CRM (mandats, contacts, statuts)
- Préparation dossiers vente / location pour agents
- Agenda, relances internes, facturation commissions agence
- Appui conformité (check-list carte pro / pièces dossiers)

**Diligence (Vague 2 — cœur différenciant)**
- Appliquer checklist parcours foncier (`etude-de-marche/06`–`07`)
- Briefer client : délibération ≠ TF ; pas de « TeleDAc magique »
- Orienter vers partenaires **formalités / géomètre / notaire** selon besoin (NICAD, EDR, CU, bornage…)
- Suivre statut dossier diligence jusqu’à livrable partenaire
- Bloquer commercialisation terrain &gt; seuil sans diligence mini (policy Vague 2)

**Partenaires & apports**
- Logger chaque lead envoyé (constructeur, archi, notaire…)
- Exiger / tracker rappel partenaire **&lt; 48 h**
- Remonter retards au gérant (clause sortie partenaire)
- Préparer éléments de facturation commission d’apport

**Gestion early (Y1)**
- Jusqu’à ~20 lots : quittances, baux simples, Wave/OM avec gérant
- Passation propre au GL en Y2

### 3.4 KPI & objectifs

| KPI | Cible |
| --- | --- |
| Complétude CRM (champs critiques) | **≥ 95 %** |
| Délai montage dossier closing | Suivi ; zéro perte pièce |
| Taux leads partenaires rappelés &lt; 48 h | **&gt; 80 %** (`partenaires.md`) |
| Dossiers diligence ouverts → clos / mois | Selon volume Vague 2 |
| Incidents « client mal informé papiers » | **0** grave / trimestre |

### 3.5 Profil

| | Attendu |
| --- | --- |
| Expérience | Admin, ops startup, assistant immo, ou formalités |
| Savoirs | Organisation dossiers ; bases foncier SN (formation interne OK) |
| Soft | Rigueur extrême, pédagogie client, pas de vente agressive |
| Outils | Excel, Drive, WhatsApp Business, CRM |
| Plus | Expérience cabinet formalités / notaire / géomètre |

### 3.6 Rémunération (indicatif `05`)

| | |
| --- | ---: |
| Fixe M7+ | **280 k**/mois |
| Charges | +~22 % |

### 3.7 Ne fait pas

- Signer des conventions partenaires (gérant)
- Promettre un résultat juridique (seul le partenaire habilité)
- Prendre des mandats exclusifs à la place des agents
- Scaler le Lab crawl / data (`research-lab`) — hors scope poste

## 4. Contenu / SEO (CT)

### 4.1 Identité du poste

| | |
| --- | --- |
| **Intitulé** | Chargé(e) de contenu & SEO hub |
| **Pôle** | Content / Digital |
| **N+1** | Gérant (PO produit) |
| **Entrée** | **M1** |
| **Statut Y1** | **Freelance ou mi-temps** (0,5–1 ETP) |

### 4.2 Mission

Produire le **contenu haute valeur** du hub (blog, guides, fiches SEO) qui attire vendeurs / acquéreurs / diaspora, avec **CTA** vers outils ou partenaires de la vague — jamais du contenu orphelin type « magazine sans produit ».

### 4.3 Missions détaillées

**Éditorial**
- Calendrier éditorial aligné `docs/blog/` + vagues `hub-roadmap`
- Rédiger guides (papiers fonciers, diaspora, estimation, location…)
- Optimiser fiches biens (titres, alt, maillage interne)
- Templates share agents (WhatsApp / social)

**SEO & measure**
- Mots-clés SN (Dakar, terrain, TF, NICAD, diaspora…)
- Suivi Search Console / analytics basique
- Relier chaque article à un **CTA** : simu, diligence, WA conseiller

**Collab**
- Brief photo/vidéo presta
- Relecture métier avec gérant / OD (éthique papiers)
- Pas de claims juridiques non validés

### 4.4 KPI & objectifs

| KPI | Cible |
| --- | --- |
| Articles / guides publiés | Selon calendrier (ex. 2–4 / mois Y1) |
| Trafic organique | Croissance MoM |
| Leads attribués SEO / contenu | CAC organique **150–500 k** / closing (`04`) |
| % contenus avec CTA outil/partenaire | **100 %** |
| Temps de relecture métier | Avant publish |

### 4.5 Profil

| | Attendu |
| --- | --- |
| Expérience | Rédaction web / SEO 1 an+ |
| Savoirs | SEO on-page, WordPress ou MD/CMS, bases immo = plus |
| Soft | Curiosité terrain SN, rigueur factuelle |
| Langues | Français impeccable ; anglais diaspora = plus |
| Portfolio | Obligatoire (3–5 URLs) |

### 4.6 Rémunération (indicatif `05`)

| | |
| --- | ---: |
| Budget Y1 | **300 k**/mois (freelance ou mi-temps) |
| Y2 | → **400 k** si full / volume ↑ |

### 4.7 Ne fait pas

- Paid ads media buying (gérant / budget marketing séparé)
- Dev Next.js (presta tech)
- Closing commercial
- Publier sans validation sur sujets juridiques fonciers sensibles
