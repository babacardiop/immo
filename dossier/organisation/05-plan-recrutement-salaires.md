## 1. Cadre légal & charges (Sénégal)

### 1.1 SMIG & plancher

| Réf. | Valeur |
| --- | --- |
| SMIG non agricole (depuis juil. 2023) | **371 FCFA / h** |
| ≈ mensuel 40 h/sem. | **~64 200** brut |
| Tous nos fixes salariés | **≫ SMIG** (×3,4 à ×11) |

### 1.2 Charges patronales — forfait modèle

Réf. CLEISS cotisations **au 1ᵉʳ janv. 2026** (IPRES, CSS, AT/MP, maladie…) + plafonds. Pour le prévisionnel :

| Hypothèse EverGreen | Taux |
| --- | ---: |
| **Charges patronales sur fixe** | **+22 %** |
| Part salariale (retenue fiche de paie) | ~IPRES 5,6 % + maladie (selon IPM) — gérée par EC |
| Split / commissions agents | Traités en **COGS** (`05`) — régime exact (salarié vs note d’honoraires) à figer avec EC |

**Important :** le split **40 %** n’est **pas** inclus dans la masse « fixe + 22 % » du tableau opex lean ; il sort quand le CA commission rentre.

### 1.3 CFCE / autres

CFCE et taxes sur salaires : incluses **approximativement** dans le forfait 22 % du modèle. Recalage exact = expert-comptable à l’immatriculation.

**Exemples de revenu agent (hors charges salariales) :**

| Deal | Commission agence | Split 40 % | + fixe mois | **Total mois agent*** |
| --- | ---: | ---: | ---: | ---: |
| 1 closing médian | 2,8 M | **1 120 000** | 250 k | **~1,37 M** |
| 1 mise en loc | 0,32 M | **128 000** | 250 k | **~0,38 M** |
| Mois sans closing | 0 | 0 | 250 k | **0,25 M** |

\*Avant retenues salariales. Objectif **≥ 6 closings / an** (`02`/`04` UE).

**Règles split :**
- Attribution CRM obligatoire avant paiement  
- Co-deal : split négocié (ex. 20/20) — validation gérant  
- Mandat simple : même % sauf dérogation  
- Plafond : pas de hausse split &gt; 45 % sans AGO (`03`)

*Bench marché : commissions immo SN souvent 20–100 % selon statut ; fixe agence 75–250 k+ selon structure. Notre mix fixe correct + 40 % = compétitif vs 100 % commission précaire.*

## 6. Grille d’évolution (augmentations)

| Moment | Règle |
| --- | --- |
| Y1 | **Gel** des fixes (sauf promotion de poste) |
| Fin Y1 revue | ±0–10 % selon perf + inflation + cash |
| Agent → senior | Fixe peut monter **250 → 300 k** si ≥ 8 closings / an |
| Contenu Y2 | **300 → 400 k** si canal SEO prouvé |
| Split | Reste **40 %** ; pas d’inflation du % |

Révision salariale collective = décision **gérant** sous budget ; hausse masse &gt; 15 % an = informer associés (`03`).
