## 0. En une phrase

Le lab avance en **voie parallèle** : design + PDF **maintenant** · spike crawl **après Vague 0** · Observatoire public **quand L2 prouvé** — le blog consomme d’abord les études officielles, puis les indices OWN.

```
Hub Vague N (produit)  ║  Lab L* (data)  ║  Blog (preuve + CTA)
         ↓ sync KPI / Done gates — jamais l’inverse
```

## 4. Alignement blog — ce que le lab nourrit (et quand)

### 4.1 Cadence éditoriale (rappel)

| Rythme | Contenu | Source data |
| --- | --- | --- |
| **2 piliers / mois** | Guides décision | Officiel + terrain · lab soft dès L1 notes |
| **2 satellites / mois** | Checklists / maj | Contenu + CHK `04` |
| **1 digest / mois** | Newsletter | Snapshot marché **si** bundle soft |
| **1 Observatoire / trim.** | Héros data | **L4** · ANSD + IX-OWN |
| **Revue annuelle** | Piliers chiffrés | `06` SLA · re-cite |

### 4.2 Mapping calendrier M1–M6 × lab

| Mois blog | Piliers | Input lab minimal | Input lab idéal |
| --- | --- | --- | --- |
| **M1** | TF vs bail · Coût construction | ICC/IMC citation · barème simu | — |
| **M2** | Arnaques · Diaspora FR | Notes WEB-NOTE · zéro crawl public | — |
| **M3** | Achat terrain · Paiement étalé | — | L1 fourchettes internes agents |
| **M4** | Frais notaire · Budget total | — | Soft médiane terrains si L1 Done |
| **M5** | Louer Dakar · Pas Wave | CAHF loyers + caveat | Proto IX-RENT Excel |
| **M6** | Autorisation construire · Gestion | IMC refresh | — |
| **M7+** | Viabilisation · diaspora deep · argent | L2 soft indices | Citations OWN + disclaimer |

### 4.3 Formats « data-first » (post-L2)

| Format | Fréquence | Contenu | CTA |
| --- | --- | --- | --- |
| **Observatoire trim.** | L4+ | IX-SALE · IX-RENT · ICC contexte · n · méthodo | Carte / estimation / WA |
| **Snapshot quartier** | Mensuel soft | 1 zone Z1 · médiane · DOM | Fiches catalogue zone |
| **Note matériaux** | Post-IMC | MoM IMC → impact simu | PUB-02 |
| **LinkedIn chiffre** | Hebdo soft | 1 claim bundle only | Lien guide / outil |

**Anti Keur City mort :** chaque héros data → **outil live** ou **mandat** — pas étude orpheline.

### 4.4 Moat éditorial (cible)

> Profondeur Keur City × fraîcheur ImmoConnexion × **simulateurs hub** × **Observatoire (études + lab)**.

Sans L4, on bat déjà sur **outils + agence** ; avec L4, on ajoute la **fraîcheur chiffrée** que les blogs SN peinent à tenir.
