### 3.2 Angles pitch (ready)

1. *« Agence curated vs classifieds — pourquoi le type de papier sur chaque fiche »*  
2. *« Diaspora : protocole anti-Wave et rôles séparés »*  
3. *« Soft launch Dakar ouest — estimation écrite + exclusif »*

### 3.3 Process PR

```
Angle validé GER
  → Media kit + draft citations
  → Contact rédac (LinkedIn / mail)
  → Relecture article (papiers !)
  → Publish + UTM + partage WA Status / NL
  → CRM `source=pr`
```

**Budget Y1 :** 0 cash prioritaire · temps GER · éventuellement 1 article sponsorisé **si** média de niche immo (plafond **150–200 k**).

## 4. Influenceurs — playbook lean

### 4.1 Quand activer

| Condition GO | |
| --- | --- |
| Catalogue live + SLA WA OK | |
| Brief brand + disclaimer papiers signé créateur | |
| CTA trackable (WA / landing) | |
| Budget collab ≤ **300 k** ou **barter** (visite filmée / estimation) | |

### 4.2 Formats préférés

| Format | Pourquoi |
| --- | --- |
| Walkthrough quartier / bien **curated** | Preuve réelle |
| Explainer « TF vs délibération » | Align cluster A |
| Témoignage diaspora (process) | Fatou |
| Lives WA/IG Q&A GER | Confiance |

**Éviter :** unboxing « deal secret » · stories sans disclosure.

### 4.3 Brief créateur (min.)

```
Objectif: [notoriété / leads WA]
Message ancre: Avant de payer, on vérifie…
Interdits: Wave vendeur · délibération=TF · rendement garanti
Livrables: [1 Reel + 3 Stories] · date
Disclosure: #partenariat / « collaboration EverGreen » (1ʳᵉ ligne)
Usage droits: hub peut reposter 90 j · paid whitelist = avenant
CTA: WA [numéro] · code/UTM [ ]
Validation: draft → CT 48 h
```

### 4.4 Contrat (clauses P0)

*Détail modèles → `16`. Minimum :*

| Clause | |
| --- | --- |
| Deliverables · dates · plateformes | |
| Rémunération / barter | |
| Disclosure obligatoire | |
| Droits usage (organic / paid séparés) | |
| Brand safety + droit de retrait | |
| Pas d’affiliation « vente » sans carte / mandat | |

Réf. pratiques : accords influence (disclosure · usage ladder · whitelist payant séparé).

### 4.5 Mesure collab

| Métrique | Usage |
| --- | --- |
| Vues / ER | Vanity — secondaire |
| Clics UTM · WA `influencer` | **Primaire** |
| Leads qualifiés · RDV | Scorecard |
| Sentiment / erreurs papier | Kill si faute |

## 5. Syndicats & associations

### 5.1 Posture ANAIS / pairs

| Faire | Ne pas faire |
| --- | --- |
| Veille régulation (carte, LCB-FT) | Promettre « membre = garantie TF » |
| Networking événements | Déléguer la com produit à l’asso |
| Aligner conformité `03` | Polémique publique sans GER |
| Cotiser **si** accès formation / crédibilité | Cotiser pour badge vide |

**Décision adhésion :** GER M3–M6 — ROI = contacts + signal confiance vs coût + temps.

## 6. Co-branding

### 6.1 Avec partenaires **métier** (P0)

| Partenaire | Co-brand | Livrable | Qui paie |
| --- | --- | --- | --- |
| Notaire | « Séquestre expliqué » | Article / carousel dual logo | Temps + CTA apport |
| Constructeur | Post-simu « devis type » | Vidéo / post | Barter lead |
| Archi | Seuil 30 M / plans | Tip LinkedIn | Barter |
| Formalités | Checklist EDR | PDF co-signé | Hub CT |

**Règles :**

- Convention apporteur **déjà signée** avant co-brand  
- Logos : EverGreen primary · partenaire secondary  
- Disclaimer : hub ≠ exécutant  
- Lead → PartnerLead CRM  

### 6.2 Avec médias / newsletters

| Format | Exemple |
| --- | --- |
| Guest post | Tribune Magazine Immo |
| Citation cross | Lien mutuel guide A1 ↔ SenPages-style |
| Sponsored newsletter tierce | Différé (coût) |

### 6.3 Interdits co-brand

| | |
| --- | --- |
| Marketplace / classified open | Contredit positionnement |
| Influenceur « vendeur de terrains » informel | Risque fraude |
| Banque / fintech sans diligence claim | Surpromesse crédit |
| White-label jeton sans contrôle éditorial | |
