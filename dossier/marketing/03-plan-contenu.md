## 3. Cadence & formats

### 3.1 Rythme mensuel (tenable lean)

| Format | / mois | Longueur | Owner |
| --- | ---: | --- | --- |
| **Guide pilier** | **2** | 2 000–4 000+ mots | CT + relecture métier |
| **Satellite** | **2** | 800–1 200 mots | CT |
| **Page / about** | 0–1 (M1) | Court | CT |
| **WA Status** | 5–6 / sem | 1 bien ou 1 tip | AC/CT |
| **FB/LinkedIn** | 2–4 / sem | Recycle pilier | CT |
| **Newsletter** | 0–1 / mois | Max 1 insight + CTA | CT (option J60+) |

### 3.2 Barème qualité (rappel — non négociable)

1. Décision go/no-go  
2. Checklist ou arbre  
3. FCFA datés (ou « devis »)  
4. TF / bail / délibération distingués  
5. CTA utile (pas « achetez maintenant »)  
6. FAQ 5–8  
7. Relecture métier  
8. Date de maj  
9. Maillage 2–4 guides + outil  
10. Ton `01` brand  

### 3.3 Pipeline production (par pilier)

```
Brief (canevas docs/blog/briefs)
  → Outline H2
  → Rédaction
  → Relecture métier (AC/OD)
  → CTA / embed branchés
  → Publish + OG + JSON-LD
  → Déclinaison WA/FB (J0–J3)
  → MAJ Search Console
```

**Lead time :** brief J−21 · draft J−10 · review J−3 · pub jour J.
