## 0. Deux lancements (ne pas confondre)

| | **Soft launch** (= Jour J GTM) | **Public launch** (amplify) |
| --- | --- | --- |
| **Quand** | Site + WA + ≥1 fiche live | Après **7–30 j** soft stable (idéal J+14 → J+30) |
| **Audience** | SOI · farming Z1 · Status | Réseau élargi · FB/IG · LinkedIn · option presse |
| **Ads** | **0** | Toujours **0** jusqu’à M3 (sauf GER) |
| **Objectif** | Bugs · SLA · 1ʳᵉs leads · mandats | Notoriété contrôlée · pipeline |
| **Risque** | Faible (Impact Media / Veeber) | Moyen — site doit être « bedded in » |

```
J-30 ── assets & copy prêts
J-7  ── soft technical live (option « dark » équipe only)
Jour J ── Soft launch réseau
J+7–14 ── Stabilize (fixes, tracking, SLA)
J+14–30 ── Public soft-amp (organique)
M3    ── Paid ON si gates (`04`)
```

**Thèse :** *Signed agreements first* — pas de big bang « écosystème ».

## 3. Messages par phase

### Soft (SOI)

```
Aujourd’hui on ouvre EverGreen — agence immobilière curated à Dakar
(pas une marketplace).
On mandate, on filtre, on affiche le type de papier.
WhatsApp : [n°] · Site : [url]
Écrivez VENTE / LOCATION / ACHAT.
```

### Public amp (J+14)

```
EverGreen est live sur [zones Z1].
Catalogue curated · estimation écrite · WhatsApp &lt; 24 h.
Avant de payer, on vérifie.
[lien] · WA [n°]
```

### Interdits lancement

- « N°1 Sénégal » · « 98 % satisfaits »  
- « Écosystème complet » (partenaires pas live)  
- Ads Meta Jour J  
- Open posting tiers

## 5. Checklist **assets** (P0 → P2)

### 5.1 Identité & legal com (P0)

- [ ] Logo / wordmark EverGreen (PNG/SVG)

- [ ] Favicon  
- [ ] Signature e-mail / WA  
- [ ] Mentions légales page (RCCM/NINEA si dispo)  
- [ ] Politique confidentialité / cookies (si forms)  

### 5.2 Site & conversion (P0)

- [ ] Home mobile  
- [ ] Catalogue + fiche (pastille papier)  
- [ ] CTA WhatsApp sticky / bouton  
- [ ] Page Comment on travaille  
- [ ] `/estimation` ou form WA équivalent  
- [ ] 404 / pages vides gérées  
- [ ] HTTPS · domaine final (pas staging noindex oublié)  

### 5.3 Contenu & SEO (P0/P1)

- [ ] ≥ 1–3 fiches curated copy + photos  
- [ ] Disclaimers TF / bail / délibération  
- [ ] Sitemap + Search Console propriété  
- [ ] Title/meta home + fiches  
- [ ] OG image défaut  
- [ ] Outline ou draft **A1**  

### 5.4 WhatsApp & social (P0)

- [ ] Profil Business (horaires, lien site)  
- [ ] Accusé auto + réponses rapides  
- [ ] Labels CRM  
- [ ] Queue Status S1 (7 jours)  
- [ ] Message SOI texte  
- [ ] Share cards 3 crops (WA / FB / IG) — `social-share-cards`  
- [ ] Captions J0–J7  

### 5.5 Tracking (P0)

- [ ] GA4 / plausible / équivalent  
- [ ] Events : `wa_click`, `estimation_request` (min.)  
- [ ] UTM convention documentée  
- [ ] CRM tags `soi` / `wa_status` / `seo`  
- [ ] Pixel Meta installé **sans** campagne (warm audiences)  

### 5.6 Ads creatives (P1 — avant M3)

- [ ] 2 croquis estimation  
- [ ] 2 croquis simu / terrain  
- [ ] Landing mobile testée  

### 5.7 Presse / PR (P2)

- [ ] Media kit one-pager  
- [ ] Bio + photo GER  
- [ ] 3 angles pitch (`07`)  

### 5.8 Ops marketing pack (P0)

- [ ] Grille tarifs / FAI résumé agent
