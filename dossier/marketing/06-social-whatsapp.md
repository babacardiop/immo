## 2. WhatsApp **Status** (Stories 24 h)

### 2.1 Rôle

Découverte **non intrusive** : les contacts qui ont le numéro voient · swipe-up / réponse = lead chaud. Pas un substitut au catalogue.

### 2.2 Mix hebdo (grille)

| Jour | Type | Exemple |
| --- | --- | --- |
| Lun | Bien curated Z1 | Photo + prix + quartier + **type papier** + « WA pour visite » |
| Mar | Tip / preuve | « Délibération ≠ TF » · 1 slide |
| Mer | Bien ou vidéo 15–20 s | Visite courte |
| Jeu | Social proof soft | Reporting vendeur anonymisé · process |
| Ven | Bien + CTA week-end | Créneaux visite samedi |
| Sam | Optionnel tip / 1 bien | Léger |
| Dim | Off ou 1 tip diaspora | Fuseau |

**Plafond :** max **1 bien / jour** équipe (playbooks) · pas 8 Status spam.

### 2.3 Template caption Status

```
[Quartier] · [type] · [prix]
Papier : TF / bail / délibération (+ disclaimer court si ≠ TF)
Visite ? Réponds VISITE
```

### 2.4 Do / Don’t Status

| Do | Don’t |
| --- | --- |
| Pastille papier lisible | « Affaire du siècle » |
| Photo réelle / lumière | 15 photos non légendées |
| 1 CTA | Lien Wave vendeur |
| Heures pic | Status à 1h du matin |

## 3. **Broadcast** lists (opt-in 1:1)

### 3.1 Listes Y1

| Liste | Qui | Contenu | Fréquence max |
| --- | --- | --- | --- |
| **VIP Exclusivités** | Acquéreurs actifs opt-in | Bien **24 h avant** classifieds | ≤ 1 / sem |
| **Vendeurs nurture** | Post-estimation non signés | Tip + soft CTA exclusif | 2 / mois |
| **Diaspora** | Fatou / Ibrahima taggés | Protocole · Secure · anti-Wave | 2–4 / mois |
| **Bailleurs** | Ousmane gestion | Reporting type · attach | 1–2 / mois |
| **Primo terrain** | Mamadou simu | Nouveau terrain + simu | ≤ 1 / sem si stock |

**Opt-in explicite :** « Je peux vous envoyer les nouveautés [segment] sur WhatsApp ? Répondez OUI. »  
**Opt-out :** « STOP » → retrait immédiat · CRM `broadcast=off`.

### 3.2 Message Broadcast type

```
[Prénom], nouveauté [quartier] — [1 ligne].
Papier : [type]. Prix : [X].
Répondez VISITE ou NON MERCI.
[Agent] — EverGreen
```

≤ 5 lignes · 1 question · pas de PDF lourd en 1ʳᵉ rafale.

### 3.3 Insight marché (Whakup)

Listes VIP exclusivités → 5–8× plus de contacts qualifiés que portails seuls ; avant-première **24 h** avant publish sites.

## 4. **Groupes** WhatsApp

### 4.1 Types autorisés

| Groupe | Membres | Rythme | Règles |
| --- | --- | --- | --- |
| **Interne équipe** | GER + AC + OD | Quotidien ops | Pas clients |
| **Buyer circle** (opt-in) | 6–15 acheteurs même bande prix/zone | **1–2 listings / sem** + 1 pulse mensuel | Demande avant ajout · mute OK |
| **Famille client** (deal) | Client + proches + AC | Selon deal | Factuel · pas débat prix infini |
| **Partenaire** | Hub + 1 partenaire | Lead handoff | SLA 48 h |

### 4.2 Interdits groupes

- Ajouter un lead froid sans OUI  
- Groupe « 200 investisseurs » spam  
- Promo tontine / rendement garanti  
- Agent qui dump 10 biens / jour  

### 4.3 Post groupe type (Dunphy adapté)

```
Nouveau · [quartier] · [prix] · papier [type]
Lien fiche : [url]
Questions en DM ou ici — je réponds sous 24 h.
```

Si &gt; 3 posts / sem → le groupe mute (rhythm &gt; volume).

## 5. **Newsletter** e-mail

### 5.1 Rôle vs WA

| | WhatsApp | E-mail |
| --- | --- | --- |
| Job | Chaud · court · action | Lent · long · référence |
| Fréquence | Status / Broadcast | **1× / mois** |
| Contenu | Bien · tip · RDV | Guide + 3 annonces + 1 CTA |
| Persona | Tous actifs | Diaspora + nurture froid |

**Ne pas** remplacer la newsletter par du Broadcast WA (fatigue + limites Meta).

### 5.2 Structure digest mensuel (J60+)

| Bloc | Contenu |
| --- | --- |
| 1 | Sujet : `[Mois] · 1 insight + 1 action` |
| 2 | Meilleur pilier du mois (extrait + lien) |
| 3 | **3 biens** curated (prix · quartier · papier) |
| 4 | 1 CTA : estimation / simu / Secure / gestion |
| 5 | Pied : désabo · adresse · marque |

**Plafond :** ≤ **4 e-mails / mois / contact** (playbook G) — digest = 1, le reste = transactionnel.

### 5.3 Listes e-mail

| Liste | Source |
| --- | --- |
| `nl_general` | Opt-in site / footer |
| `nl_diaspora` | Tag Fatou / Secure |
| `nl_vendeurs` | Post-estimation |
| `nl_bailleurs` | Gestion / loc |

Outil Y1 : Brevo / Mailchimp free · UTM `utm_source=newsletter`.
