| Élément | Contenu |

## 2. Fatou — Diaspora investisseur (P0)

| | |
| --- | --- |
| **Profil** | 30–55 ans · FR/EU/US · patrimoine au pays |
| **JTBD** | Acheter / construire / gérer **sans être sur place**, avec **preuves** |
| **Douleurs** | Distance · cousin unique · Wave avant vérif · POA floue · loyers disparus |
| **Value claim** | *On vérifie avant que tu paies. On te prouve ensuite.* |
| **Offre** | Diligence · inspection · séquestre · POA cadrée · gestion |
| **Canaux** | Google · YouTube · FB groupes · WA · e-mail formalisation |
| **Langue** | FR soigné · EN si besoin · vouvoiement défaut |

**Hooks**

- « Acheter un terrain au Sénégal depuis [Paris] sans Wave au vendeur »  
- « Délibération ≠ titre foncier — checklist diaspora »  
- « 5 rôles à séparer quand vous achetez à distance »

**Preuves** : protocole anti-Wave · pastille papier · Pack Secure · reporting photo datée · notaire choisi par vous.

**CTA par stade**

| Stade | CTA |
| --- | --- |
| Aware | Guide TF vs bail / arnaques |
| Consider | Checklist diligence PDF + WA |
| Decide | Pack Diaspora Secure / intro notaire |
| Retain | Mandat gestion + reporting |

**Éviter :** « Envoyez l’argent, on s’occupe » · photos seules = preuve · promesse TF magique.

**Objections (riposte courte)**

| Objection | Riposte |
| --- | --- |
| « Mon frère gère » | OK pour le lien — pas pour présenter + vérifier + encaisser. On sépare. |
| « Trop long la diligence » | Moins long qu’un litige / Arrêt Dscos. |
| « Je paie Wave pour bloquer » | Non accompagné. Séquestre après vérif — non négociable. |

## 3. Mamadou — Primo terrain / construction (P0)

| | |
| --- | --- |
| **Profil** | 32–45 ans · local · épargne irrégulière · week-end visites |
| **JTBD** | Savoir **si je peux payer** et **combien coûtera la maison** |
| **Douleurs** | Titre douteux · coût construction opaque · pas de crédit long · confusion délibération |
| **Value claim** | *Chiffres avant engagement — et on lit tes papiers.* |
| **Offre** | Fiche + 3 simus → diligence → notaire → BTP/archi |
| **Canaux** | WA · FB · classifieds · Status · SEO « terrain [zone] » |
| **Langue** | Tutoiement OK si client à l’aise · FCFA partout |

**Hooks**

- « Tu peux payer ce terrain ? Simule ta mensualité »  
- « Terrain + maison : budget total avant de signer »  
- « TF / bail / délibération — laquelle tu as vraiment ? »

**Preuves** : simus sur fiche · type papier visible · CTA diligence · devis partenaire &lt; 48 h rappel.

**CTA par stade**

| Stade | CTA |
| --- | --- |
| Aware | Simu mensualité (gratuit) |
| Consider | Visite + lecture papier |
| Decide | Pack Sécuriser / offre sous conditions |
| Expand | Intro constructeur / archi |

**Éviter :** dump prix sans papier · « paie maintenant sinon perdu » · TeleDAc en 48 h.

**Objections**

| Objection | Riposte |
| --- | --- |
| « L’autre est moins cher » | Souvent discount = discount sécurité. On compare le **papier**. |
| « Je paie Wave pour bloquer » | On n’accompagne pas. Vérif → séquestre. |
| « C’est trop long » | 1 simu aujourd’hui &gt; 1 litige demain. |

## 4. Ousmane — Bailleur local (P0 gestion)

| | |
| --- | --- |
| **Profil** | 1–5 biens · manque de temps · Excel / cousin |
| **JTBD** | Encaisse pour moi et **montre-moi les comptes** |
| **Douleurs** | Impayés · vacance · opacité · « commission trop chère » |
| **Value claim** | *On encaisse, on reverse, tu vois tout.* |
| **Offre** | Gestion **8 %** · quittances · Wave/OM société · relances |
| **Canaux** | WA · SOI · LinkedIn soft · post-mise en loc attach |
| **Langue** | Direct · chiffres · vouvoiement pro |

**Hooks**

- « Locataire placé — et les loyers ? Activez la gestion »  
- « Reporting mensuel : encaissé / dû / incidents »  
- « Un seul gestionnaire, pas trois cousins »

**Preuves** : extrait reporting type · délai reversement · EDL systématique.

**CTA** : audit gratuit 1 bien → mandat MG 12 mois.

**Objections**

| Objection | Riposte |
| --- | --- |
| « 8 % c’est cher » | Sans gestion = ton temps + impayés. Plancher 7 % si ≥ 5 lots / 24 mois. |
| « Je gère seul » | OK — on propose l’attach le jour du bail. Relance J+3/J+7. |
| « Et si vacance ? » | Pas d’honoraires sur mois sans encaissement (règle hub). |

## 5. Ibrahima — Bailleur diaspora (P0)

| | |
| --- | --- |
| **Profil** | Bien déjà acquis · cousin a mal géré |
| **JTBD** | Professionnaliser à distance — **loyers visibles** |
| **Douleurs** | Loyers disparus · travaux surfacturés · locataire « ami » |
| **Value claim** | *Reprise pro du mandat — reporting diaspora, plus d’opacité.* |
| **Offre** | Audit reprise · gestion 8 % ou **9–10 %** reporting renforcé |
| **Canaux** | Google anti-arnaque · WA · e-mail · témoignages |
| **Langue** | FR soigné · preuves &gt; promesse |

**Hooks**

- « Votre cousin gère encore les loyers ? Checklist reprise »  
- « Gestion depuis [France] : quittances + photos + virement »

**CTA** : appel audit (bail / locataire / fonds) → mandat.

**Objections**

| Objection | Riposte |
| --- | --- |
| « Le cousin va se vexer » | Rôles séparés = protection de **votre** patrimoine. |
| « Trop cher vs famille » | Famille gratuite a déjà coûté X mois. On chiffre. |

## 6. Marième — Vendeuse (P1 supply)

| | |
| --- | --- |
| **Profil** | Succession / liquidité / projet — multi-poste classifieds |
| **JTBD** | Prix correct · délai · **moins de curieux** |
| **Douleurs** | Agences qui ne rappellent pas · multi-prix · tireurs au flanc |
| **Value claim** | *On met ton bien en marché proprement et on filtre.* |
| **Offre** | Estimation écrite → **exclusif 3 mois** · reporting bi-mensuel |
| **Canaux** | Farming · WA · panneau · SEO vendeur · Status |
| **Langue** | Calme · exclusif d’abord · pas de dump |

**Hooks**

- « Estimation écrite [quartier] — un prix, pas cinq annonces »  
- « On publie (pas vous). On filtre les curieux. »  
- « Mandat exclusif 90 jours + compte-rendu WhatsApp »

**CTA** : RDV estimation → signature exclusif + photos J0.

**Objections**

| Objection | Riposte |
| --- | --- |
| « Plusieurs agences » | Multi = multi-prix. Essai 3 mois mesurable. |
| « L’autre fait 3 % » | On ne match pas le dump — on match closing + preuve. |
| « Trop cher 6 % » | Contrepartie durée/reporting ; plancher politique écrite. |

| **JTBD** | Bail clair **sans se faire plumer** |
| **Douleurs** | Cash d’entrée · bail verbal · arnaques caution |
| **Value claim** | *Bail clair, logement réel, total d’entrée annoncé avant visite.* |
| **Offre** | Catalogue loc curated · EDL · honoraires conformes · upsell étalé |
| **Canaux** | WA · FB · classifieds · Status |
| **Langue** | Empathique · transparent sur le total |

**Hooks**

- « Total d’entrée annoncé **avant** la visite »  
- « Pas de bail verbal — EDL + quittance »  
- « Louer aujourd’hui, viser un terrain demain » (soft upsell)

**CTA** : shortlist 1–2 biens + créneau visite.

**Objections**

| Objection | Riposte |
| --- | --- |
| « Trop d’avance » | On annonce le total ; plafonds légaux rappelés ; options caution partenaire si live. |
| « J’ai vu moins cher sur Expat » | Moins cher ≠ vérifié. On mandate ce qu’on a vu. |
