## 1. Positionnement éditorial

### 1.1 On est / on n’est pas

| On est | On n’est pas |
| --- | --- |
| Guides d’**agence de terrain** (vérifié, actionnable, daté) | Blog lifestyle générique |
| Checklists · FCFA datés · pièges réels | Listicles 600 mots sans source |
| Contenu qui **réduit le risque** | Contenu qui pousse à payer vite |
| FR clair (SN + diaspora) | Jargon notarial indigeste |
| Recycle multi-canal d’un pilier | 20 posts/jour hors stratégie |

### 1.2 Objectifs business du contenu

| Objectif | Comment le contenu sert |

| Confiance / anti-arnaque | Hub A + D · pastilles |
| Supply (vendeurs) | Tips estimation · exclusif · Status biens |
| Demand tools | Hub B/E → `sim_complete` |
| Diaspora | Hub D · Secure · anti-Wave |
| SEO | Piliers long → leads `seo` |
| Nurture | Newsletter · Status · retarget |

## 3. Formats & barème

### 3.1 Formats canoniques

| Format | Longueur | Rôle | Fréquence Y1 |
| --- | --- | --- | --- |
| **Guide pilier** | 2 000–4 000+ mots | SEO + décision | **2 / mois** |
| **Satellite** | 800–1 200 | Actu / alerte / FAQ courte | **2 / mois** |
| **Page outil / about** | Court | Conversion | Selon vague |
| **WA Status** | 1 écran | Reach quotidien | **5–6 / sem** |
| **Post FB/IG** | Carrousel / tip | Recycle | **2–4 / sem** |
| **LinkedIn** | Insight 1§ | Soft B2B / GER | **1–2 / sem** |
| **Newsletter** | 1 insight + CTA | Nurture opt-in | **0–1 / mois** |

### 3.2 Barème qualité pilier (non négociable)

1. Décision go / no-go / prochaine étape  
2. Checklist ou arbre  
3. FCFA datés (ou « devis »)  
4. TF / bail / délibération distingués  
5. CTA utile (pas « achetez maintenant »)  
6. FAQ 5–8  
7. Relecture métier  
8. Date de maj  
9. Maillage 2–4 guides + outil  
10. Ton Brand Book / `01`

## 4. Rôles par canal (ligne éditoriale)

### 4.1 Blog / guides

| | |
| --- | --- |
| **Job** | Autorité SEO + aide à la décision |
| **Voix** | Pédagogique · calme · datée |
| **CTA** | Outil · diligence · WA |
| **Interdit** | Clickbait · « rêve villa » sans process |

Architecture : `/blog` · `/guides` · embeds simus (`docs/blog/strategie`).

### 4.2 WhatsApp Status (+ Broadcast plus tard)

| | |
| --- | --- |
| **Job** | Canal **cœur social** SN — biens + tips |
| **Mix Status** | ~50 % biens curated · ~30 % tip papier/process · ~20 % preuve / coulisses soft |
| **Ton** | Conversationnel soigné · ≤ 5 lignes si caption |
| **Règle** | 0 Broadcast froid · opt-out &lt; 3 % |

Détail grille → `06`.

### 4.3 Facebook / Instagram

| | |
| --- | --- |
| **Job** | Découverte locale + diaspora groupes (FB) |
| **Formats** | Share cards · carrousels checklists · extrait pilier |
| **Mix** | **≤ 40 % biens** · ≥ 60 % expertise / local / process (IACREA / IA Lab 40/30/30 adapté) |
| **Rythme** | 2–4 / sem — régulier |
| **Groupes** | Valeur d’abord · lire chartes · pas spam annonces |

*IG : optionnel Y1 si ressource ; sinon FB + Status suffisent.*

### 4.4 LinkedIn

| | |
| --- | --- |
| **Job** | Soft network · prescripteurs · thought leadership GER |
| **Formats** | 1 insight marché / process / papier |
| **Pas** | Catalogue multi-biens spam |

### 4.5 Newsletter

| | |
| --- | --- |
| **Job** | Nurture opt-in (vendeurs chauds · diaspora · bailleurs) |
| **Cadence** | **Mensuelle** max dès liste ≥ ~30–50 · pas avant M2 |
| **Structure** | 1 sujet fort · 1 checklist/lien pilier · 1 CTA WA · footer STOP |
| **Objets** | Factuels (« Délibération ≠ TF — 5 checks ») — pas « Opportunité !!! » |
| **Open cible** | &gt; 25 % (bench digests `06`) |

**Non-objectif Y1 :** digest hebdo biens (charge &gt; valeur lean).

### 4.6 Canaux hors ligne Y1

YouTube série · TikTok · Threads · podcast — **non** (sauf opportunité ponctuelle GER). Reels : seulement si recycle Status/FB sans cadence séparée.

## 5. Mix éditorial social (grille type)

Adaptation EverGreen (WA-first) vs 40/30/30 FR :

| Type | Poids | Exemples |
| --- | ---: | --- |
| **Biens curated** | **35–40 %** | Fiche · share card · « type papier » |
| **Expertise / éducation** | **30 %** | Tip TF · caution · anti-Wave |
| **Local / preuve** | **15–20 %** | Quartier Z1 · process visite · reporting anonymisé |
| **Marque / coulisses soft** | **10–15 %** | Comment on travaille · SLA · équipe |

Jamais &gt; **50 %** biens sur une fenêtre 30 j (IACREA).

## 6. Modèle de recycle (1 pilier → N touches)

```
Pilier blog (J0)
  → Status tip (J0 / J+1)
  → Carrousel FB (J+1)
  → LinkedIn insight (J+2)
  → Satellite FAQ si besoin (J+7)
  → Newsletter excerpt (fin de mois)
  → Retarget créa (M3+ si paid)
```

**Règle :** zéro pilier sans **≥ 3** déclinaisons planifiées (`03` § recycle).

  → Outline H2
  → Rédaction CT
