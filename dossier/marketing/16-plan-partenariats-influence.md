## 2. Typologie & sélection

### 2.1 Tiers

| Tier | Followers | Fit EverGreen | Deal type |
| --- | ---: | --- | --- |
| Nano | &lt; 10 k | Quartier / WA groups | Barter · produit |
| Micro | 10–100 k | **Priorité** lifestyle Dakar · invest diaspora | Forfait 50–300 k |
| Mid | 100–500 k | Rare Y1 | Devis |
| Macro | &gt; 500 k | Y2 | — |
| Expert | Variable | Papiers / droit | Barter + CTA |

### 2.2 Scorecard sélection (GO ≥ 7/10)

| Critère | Poids | Notes |
| --- | ---: | --- |
| Audience SN ou diaspora FR | 2 | Geo analytique |
| Ton sérieux / pas get-rich | 2 | Scroll 20 posts |
| Engagement réel (pas bots) | 1 | |
| Acceptation brief papiers / anti-Wave | **2** | Deal-breaker |
| Dispo relecture GER/CT | 1 | |
| Prix vs reach | 1 | |
| Références / collabs clean | 1 | |

**Kill immédiat :** TF magique · Wave vendeur · tontine · terrain sans papier · dénigrement concurrent nommé · politique.

### 2.3 Shortlist process

```
Longlist 10 (CT)
  → Scorecard ≥ 7
  → Appel fit 15 min + brief brand
  → Proposition deal (barter / forfait / affil)
  → Contrat + facture
  → Contenu draft → validation → publish + UTM
  → Reco 14 j → Scale / Kill
```

## 3. Modèles économiques

### 3.1 Influence (contenu)

| Modèle | Quand | Ordre FCFA |
| --- | --- | ---: |
| **Barter** | Nano / expert | 0 cash · lead / visibilité |
| **Forfait / post** | Micro 1–3 contenus | **50–200 k** |
| **Package** (3 posts + story) | Test M4+ | **150–300 k** |
| **Hybride** forfait + bonus lead quali | Si tracking fiable | +20–50 k / RDV |
| **Gifting** (visite / estimation) | Soft | Valoriser en nature |

### 3.2 Affiliation / apporteur soft

*≠ commission métier BTP (`02`). Ici = intro client → agence.*

| Modèle | Assiette | Taux / montant indicatif | Déclencheur paiement |
| --- | --- | --- | --- |
| **Lead quali** | Lead WA tagué + RDV tenu | **10–25 k** / RDV | RDV honoré |
| **Mandat signé** | Mandat exclusif | **25–75 k** | Signature |
| **Closing** | Commission agence nette | **10–20 %** de la com agence | Encaissement com |
| **Code / lien** | Closing attribué UTM | Idem % | Encaissement |

**Règles anti-double :**

| Cas | Décision |
| --- | --- |
| Lead déjà CRM &lt; 90 j | Pas de com affiliation |
| Lead ads Meta même fenêtre | Source primaire ads — pas double |
| Self-referral / faux lead | Kill + blacklist |
| Client open market sans intro prouvable | 0 |

Usage marché co-agence SN souvent **20–30 %** com — affiliation soft **sous** ce plafond.

### 3.3 Disclosure (transparence)

| Contexte | Mention obligatoire |
| --- | --- |
| Post sponsorisé | `#Publicité` · `#CollaborationCommerciale` ou équivalent visible |
| Story / Reel | Mention claire dès le début |
| Affiliation lien | « Lien partenaire » / « collab EverGreen » |
| FR (loi influence) | Intention commerciale claire si pas évidente au contexte |

## 4. Cadre juridique (attention)

### 4.1 Créateurs basés / opérant en **France**

Depuis **01/01/2026** (décret 2025-1137 / loi 9 juin 2023) :

- Contrat **écrit** obligatoire si rémunérations + avantages en nature ≥ **1 000 € HT** / an / annonceur / même objectif promo  
- Mentions légales article 8 (identité, missions, rémunération, PI, droit applicable…) — **nullité** si manquantes  
- Même un « petit » package + voyage / gift peut franchir le seuil  

→ **Toujours écrit** dès qu’il y a cash ou gift valorisé (bonne pratique même &lt; 1 000 €).

### 4.2 Créateurs **Sénégal** / OHADA

- Pas le même texte FR — **liberté contractuelle** : écrit indispensable pour preuve paiement & brief  
- Pas confondre avec **carte d’agent immo** : l’influenceur **n’est pas** agent ; il n’intermédie pas la vente  
- Facture / reçu · conformité fiscale locale (NINEA si pro)

### 4.3 Ce que le contrat doit toujours dire (tous pays)

| Clause | Pourquoi |
| --- | --- |
| Brief claims interdits | Brand + fraude |
| Droit de validation pré-publish | Papiers |
| Usage image / durée | PI |
| Disclosure | Transparence |
| Résiliation / non-conformité | Kill content |
| Pas de mandat immo implicite | Loi 82-07 |

## 5. Modèles de contrats (cadres)

> **Brouillons opérationnels** — faire valider avocat. Remplir `[…]`.

### Annexe A — Convention collaboration influence (forfait / barter)

```
CONVENTION DE COLLABORATION INFLUENCE — EverGreen

1. Parties
   Annonceur : [SARL EverGreen / raison sociale], RCCM […], NINEA […]
   Créateur : [Nom], [pseudo], [plateforme], [adresse / pays fiscal]

2. Objet
   Prestations d’influence commerciale pour promouvoir EverGreen
   (agence immobilière curated — pas marketplace).
   Objectif promo : [notoriété / leads WA estimation / diaspora Secure].

3. Prestations (livrables)
   - [ ] 1 post feed  - [ ] 1–3 stories  - [ ] 1 Reel ≤ 60 s
   - [ ] Lien / sticker WA  - [ ] Autre : […]
   Date(s) de publication : […]
   Plateformes : […]

4. Brief non négociable
   - Promesse : « Avant de payer, on vérifie. Ensuite on gère. »
   - Interdits : Wave vendeur · délibération = TF · rendement garanti ·
     « N°1 Sénégal » · open posting · TeleDAc magique
   - Mentions transparence : Publicité / Collaboration commerciale
   - Validation écrite CT/GER avant mise en ligne (délai relecture 48–72 h)

5. Rémunération
   Option : [ ] Forfait [___] FCFA HT  [ ] Barter [description valorisée ___]
            [ ] Hybride forfait + bonus RDV [___] FCFA
   Paiement : sous [15] j après publish conforme + facture
   Avantages en nature (valeur) : [___] — inclus dans le total annuel

6. Propriété intellectuelle
   Licence EverGreen : usage organique + ads [30/90] j sur les contenus livrés
   [ ] Oui repost ads  [ ] Non — organique only
   Créateur conserve droits morale ; pas de revente à concurrent immo SN [12] mois

7. Données & tracking
   Lien / code UTM fourni par EverGreen · source=influencer · campaign=[…]
   Pas de collecte PII hors plateforme sans base légale

8. Responsabilité
   Créateur : conformité plateforme + disclosure + exactitude claims validés
   EverGreen : exactitude brief · conformité métier agence
   Créateur n’est pas agent immobilier ni mandataire de vente

9. Résiliation
   Non-respect brief / disclosure → retrait sous 24 h + pas de solde
   Force majeure plateforme (ban) : report ou avoir

10. Droit applicable / litiges
    [Droit sénégalais / OHADA] ou [droit français si créateur FR] — siège […]
    Médiation puis juridictions de […]

11. Annexes
    Brief créa · Visuels validés · Grille claims · Facture

Fait à […], le […]
Signatures Annonceur / Créateur
```

### Annexe B — Convention affiliation / apport d’affaires soft

```
CONVENTION D’AFFILIATION / APPORT D’AFFAIRES (SOFT) — EverGreen

1. Parties : EverGreen […] / Affilié […]

2. Objet
   Apport de prospects (acheteurs, vendeurs, bailleurs, diaspora)
   vers l’agence EverGreen. L’affilié n’exerce pas l’activité d’agent
   immobilier réglementée ; pas de visite / négociation / mandat au nom d’EverGreen
   sans accord écrit séparé.

3. Process
   Intro via : lien UTM / WA dédié / formulaire
   Tag CRM source=affiliate · affiliate_id=[…]
   Qualif minimale : intent + zone + contact joignable

4. Commission
   Barème (cocher) :
   [ ] Lead quali + RDV tenu : [___] FCFA
   [ ] Mandat exclusif signé : [___] FCFA
   [ ] Closing : [___] % de la commission agence nette encaissée
   Déclencheur : [RDV / signature / encaissement]
   Paiement : sous [15] j après déclencheur + facture
   Protection post-intro : [6] mois sur le même client pour même projet

5. Exclusions (0 commission)
   - Lead déjà en CRM EverGreen < 90 j
   - Lead attribué canal paid/SEO prioritaire même fenêtre
   - Lead frauduleux / auto-référencé
   - Closing hors mandat EverGreen

6. Obligations affilié
   - Pas de claim papier interdit
   - Pas d’encaissement client (séquestre / Wave)
   - Disclosure si contenu public (« partenaire EverGreen »)

7. Durée : [12] mois tacite reconduction · résiliation [30] j
8. Non-sollicitation : pas détourner pour contourner commission
9. Droit applicable : […]

Signatures
```

### Annexe C — Ambassadeur (retainer léger) — option M7+

```
- Durée [3–6] mois
- Retainer [___] FCFA / mois + [n] contenus / mois
- Perf bonus : [___] / closing attribué
- Exclusivité soft : pas de collab concurrent agence curated Z1 pendant contrat
- Revue mensuelle KPI · kill si brand break
(+ clauses Annexe A mutatis mutandis)
```

### Checklist clauses FR (≥ 1 000 € HT)

Si créateur / campagne sous loi FR — vérifier avec avocat :

- [ ] Identités + résidence fiscale parties  
- [ ] Nature missions / plateformes / dates  
- [ ] Rémunération + avantages en nature valorisés  
- [ ] PI / cession / licence  
- [ ] Droit applicable / juridiction  
- [ ] Mentions article 8 loi 2023-451
