## 0. Synthèse

Nous vendons le métier d’**agence immobilière full-service** (pas des annonces). Quatre axes de transaction / gestion + des **packs** qui orchestrent outils digitaux et partenaires.

```
                    AGENCE + SITE
                         │
     ┌───────────┬───────┼───────┬───────────┐
     v           v       v       v           v
  AXE 1       AXE 2    AXE 3   AXE 4      PACKS
  Vente       Vente    Loc-    Location   Diaspora ·
  classique   étalée   vente   + gestion  Terrain→Maison ·
                                          Sécuriser · Confort
```

| Couche | Exemples | Qui paie |
| --- | --- | --- |
| **Cœur agence** | Mandats vente, location, gestion | Vendeur / bailleur / (part locataire) |
| **Accession** | Étalé, location-vente | Acquéreur (frais) + structure flux |
| **Packs** | Diaspora Secure, diligence, Terrain→Maison | Client forfait / % |
| **Outils** | Simulateurs, estimation, guides | **Gratuits** (lead magnets) |
| **Apports** | Constructeur, notaire, formalités… | Partenaire → commission hub |

## 2. Les 4 axes commerciaux

### Axe 1 — Vente classique

| | |
| --- | --- |
| **Quoi** | Mise en marché, visites, négociation, closing — terrains, maisons, appartements |
| **Client** | Vendeur (mandat) · acquéreur (accompagnement) |
| **Revenu** | Commission **% du prix** à la vente |
| **Cash** | One-shot au closing |
| **Différenciation** | Catalogue curated · type de papier affiché · exclusivité prioritaire · estimation vendeur gratuite |

**Sous-offres :**
- Mandat **exclusif** (cœur marge)  
- Mandat simple (exception, réseau / bien stratégique)  
- Recherche acquéreur sur-mesure (chasse)  
- Accompagnement jusqu’au notaire  

**Hors scope Y1 :** promotion / lotissement pour compte propre.

---

### Axe 2 — Vente étalée (terrains)

| | |
| --- | --- |
| **Quoi** | Structurer l’accession terrain (TF / bail) avec mensualités + solde |
| **Client** | Vendeur terrain · primo-accédant (Mamadou) |
| **Revenu** | Frais de dossier + **% sur flux / solde** |
| **Cash** | Mensuel léger + closing final |
| **Différenciation** | Simulateur mensualité · budget total · lecture papiers avant 1er paiement |

**Sous-offres :**
- Montage échéancier  
- Collecte / suivi paiements (process + partenaires)  
- Upsell Pack Terrain→Maison (construction)  

**Prérequis :** bien éligible (régime clair) — pas d’étalé sur pure occupation de fait.

---

### Axe 3 — Location-vente (bâti)

| | |
| --- | --- |
| **Quoi** | Accession progressive maison / appartement (redevances → propriété) |
| **Client** | Propriétaire cédant · accédant |
| **Revenu** | Frais dossier + **% sur redevances** |
| **Cash** | Mensuel long |
| **Différenciation** | Portail acquéreur (solde, % payé) · même rigueur papiers que vente |

**Sous-offres :**
- Montage contrat loc-vente (avec conseil juridique)  
- Suivi échéancier digital  
- Sortie anticipée / solde  

**Phasage :** densifier après Vague 1–2 (simus + confiance) ; volume Y1 limité.

---

### Axe 4 — Location + gestion

| | |
| --- | --- |
| **Quoi** | Trouver le locataire **et/ou** gérer le bien au fil des mois |
| **Client** | Bailleur · locataire |
| **Revenu** | **1 mois** à la mise en location + **% des loyers** en gestion |
| **Cash** | Entrée + **récurrent mensuel** (socle LTV) |
| **Différenciation** | Wave/OM · quittances · portail proprio/locataire · reporting diaspora |

**Sous-offres :**

| Offre | Contenu |
| --- | --- |
| **Mise en location seule** | Annonce, visites, sélection, bail, EDL entrée |
| **Gestion locative** | Encaissement, relances, quittances, interface bailleur/locataire, petit suivi |
| **Gestion + reporting diaspora** | Idem + reporting renforcé / forfait (§3 packs) |
| **Meublé / courte durée** | Plus tard (P2) — conciergerie légère |

**Règle commerciale :** toute mise en location pousse un **upsell gestion** (≥ 50 % cible `02` fiches).

## 3. Packs (orchestration)

Les packs **ne remplacent pas** les axes : ils **bundlent** services agence + add-ons + partenaires. Détail bundles par vague → `03`.

### 3.1 Pack Sécuriser (Vague 2)

| Élément | Rôle |
| --- | --- |
| **Pour qui** | Acheteur terrain / diaspora avant paiement |
| **Inclus** | Checklist papiers · orientation diligence · lead formalités / géomètre / notaire |
| **Monétisation** | Forfait hub **et/ou** commission apport partenaire |
| **Promesse** | *On lit avant que tu paies* |

### 3.2 Pack Terrain → Maison (Vague 1–2)

| Élément | Rôle |
| --- | --- |
| **Pour qui** | Mamadou post-terrain (ou pendant étalé) |
| **Inclus** | Simu construction + budget total · shortlist archi / constructeur · CTA permis |
| **Monétisation** | Apports BTP/archi (+ évent. forfait conseil) |
| **Promesse** | *Mensualité + coût maison visibles avant engagement* |

### 3.3 Pack Diaspora Secure (Vague 4)

| Élément | Rôle |
| --- | --- |
| **Pour qui** | Fatou (FR/EU/US) |
| **Inclus** | Inspection distancielle · diligence · protocole paiement (pas de Wave vendeur) · reporting |
| **Options** | Escrow/séquestre notaire · procuration · suivi chantier |
| **Monétisation** | Forfait **300–800 k** (+ pts gestion si bailleur) |
| **Promesse** | *On vérifie. On te prouve ensuite.* |

### 3.4 Pack Diaspora Full (stretch)

Inspection + diligence + escrow + suivi chantier + multi-devise — **après** traction Pack Secure.

### 3.5 Pack Confort / entrée-sortie (P2)

Clim, déménagement, ménage, assurance MRH/PNO — **commission partenaires**, hors cœur Y1.

### 3.6 Matrice Pack × Axe

| Pack | Axe 1 | Axe 2 | Axe 3 | Axe 4 |
| --- | :---: | :---: | :---: | :---: |
| Sécuriser | ● | ● | ● | ○ |
| Terrain→Maison | ○ | ●● | ○ | — |
| Diaspora Secure | ●● | ● | ● | ●● |
| Confort | ○ | — | ○ | ● |

## 6. Parcours client type (offre → offre)

```
Vendeur ──estimation──► Mandat exclusif (Axe 1) ──closing──► (fin)
                              │
Bailleur ──mise en loc──► Axe 4 entrée ──upsell──► Gestion récurrente
                              │
Primo ──simu──► Étalé (Axe 2) ──Pack Terrain→Maison──► Apport BTP
                              │
Diaspora ──Pack Secure──► Axe 1 ou 4 ──reporting──► LTV
```

**Double filet (exemple Mamadou) :** commission terrain + apport chantier constructeur — voir `01` BM §4.3.

## 8. Lien tarifs (aperçu — détail `02`)

| Prestation | Ordre de grandeur marché / hub |
| --- | --- |
| Vente exclusif | **5–7 %** |
| Vente simple | **4–5 %** |
| Mise en location | **1 mois** de loyer |
| Gestion | **~8 %** loyers encaissés |
| Frais dossier étalé / LV | **25–50 k** |
| Pack diaspora | **300–800 k** forfait |
| Outils digitaux | **0 FCFA** |

Honoraires **libres** au Sénégal (pas de barème légal unique) — fourchettes 5–10 % vente, ~1 mois location, 8–10 % gestion (CPI, Immoplus, pratique Dakar). Transparence mandat obligatoire.
