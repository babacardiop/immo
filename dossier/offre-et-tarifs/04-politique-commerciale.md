## 0. Synthèse — règles d’or

| # | Règle |
| --- | --- |
| **1** | **Exclusif d’abord** — cible **≥ 60 %** des mandats vente |
| **2** | Mandat **simple** = **exception** (pas le défaut commercial) |
| **3** | Remise = **contrepartie écrite** (durée, volume, exclusivité) — jamais gratuit |
| **4** | Planchers soft Y1 : exclusif **≥ 5 %** · gestion **≥ 7 %** · loc **≥ 0,75 mois** |
| **5** | Sous plancher → **A = gérant** uniquement |
| **6** | Pas de multi-mandat concurrent **sur le même bien** dans notre catalogue curated |
| **7** | Pas de dump pour gagner un mandat si CAC payant déjà engagé |

## 1. Philosophie commerciale

Le hub monétise la **confiance curated**, pas le volume d’annonces. Unit economics (`04`) : un mandat **simple** qui part chez un concurrent = CAC brûlé + 0 FCFA. D’où :

```
Priorité commerciale :
  1. Exclusif 5–7 %
  2. Gestion récurrente 8 %
  3. Packs / apports
  4. Simple 4–5 % (filet)
```

**Talk track vendeur (Marième) :**  
*« En exclusif, on investit estimation, photos, SEO, filtrage — un seul discours prix. En simple, on diffuse moins : le risque que le bien parte ailleurs sans nous est réel. »*

Bench international (SeLoger / Lamy) : l’exclusif concentre l’effort marketing et accélère souvent la vente — logique **transposable** même si le cadre SN n’est pas la loi Hoguet. Adapter les clauses au **droit OHADA / contrat SN** avec avocat.

## 2. Exclusivité — politique mandat vente

### 2.1 Définitions hub

| Type | Engagement vendeur | Engagement agence | Tarif cible |
| --- | --- | --- | ---: |
| **Exclusif** | Une seule agence pour commercialiser pendant la durée | Effort max (budget diffusion, reporting) | **6 %** (5–7 %) |
| **Simple** | Peut confier à d’autres / vendre seul* | Effort **limité** | **4,5 %** (4–5 %) |
| **Semi-exclusif** *(option)* | Une agence + vente directe proprio possible | Effort élevé ; honoraires si acheteur présenté par agence | Négocié (**5–6 %**) |

\*Si vente directe après présentation d’un acquéreur par l’agence → honoraires dus (clause à rédiger).

### 2.2 Cibles & KPI

| Indicateur | Cible |
| --- | ---: |
| % mandats vente **exclusifs** | **≥ 60 %** |
| Mandat → closing (12 mois) exclusifs | **50–70 %** |
| Durée exclusive initiale | **3 mois** recommandés (renouvelable écrit) |
| Reporting vendeur exclusif | **Bi-mensuel** min. (WA / PDF) |

### 2.3 Contreparties promises en exclusif (obligatoires)

À lister dans le mandat (caractères apparents) :

- [ ] Estimation écrite  
- [ ] Fiche catalogue curated (type de papier)  
- [ ] Diffusion site + canaux retenus  
- [ ] Nombre min. d’actions / mois (visites, relances)  
- [ ] Compte-rendu périodique  
- [ ] SLA réponse vendeur &lt; 24 h  

Sans ces engagements, **ne pas** signer d’exclusif « vide ».

### 2.4 Quand accepter un mandat simple

| GO simple | NO-GO |
| --- | --- |
| CAC ≈ **0** (réseau, referral) | Lead issu de **paid ads** |
| Bien **stratégique** (vitrine quartier) | Vendeur refuse exclusif **et** exige dump &lt; 4 % |
| Vendeur déjà multi-agence — on entre en **veille** | Agent signe simple pour « faire du volume » seul |
| Ticket très élevé + relation long terme | Pipeline déjà saturé d’exclusifs à traiter |

**Process :** agent propose exclusif → si refus, **fiche motif** CRM → gérant valide simple sous 48 h.

### 2.5 Durée, résiliation, clause pénale (trame)

*À faire valider par avocat SN — inspiration bonnes pratiques, pas copie Hoguet.*

| Clause | Proposition hub |
| --- | --- |
| Durée exclusive initiale | **3 mois** |
| Renouvellement | **Écrit** (pas tacite agressif) |
| Résiliation | Préavis écrit (ex. 15 j) après période initiale |
| Vente à un acquéreur présenté par l’agence | Honoraires dus même après fin de mandat (délai à fixer, ex. 6–12 mois) |
| Indemnité | Plafond ≤ honoraires prévus |

## 3. Multi-mandat & catalogue curated

### 3.1 Règle catalogue

| Situation | Politique |
| --- | --- |
| Même bien chez **nous** + classifieds proprio | OK si **exclusif** ou si on contrôle le discours prix |
| Même bien chez **nous** + **autre agence** | **Interdit** en exclusif ; en simple = accepter le risque de fuite |
| Double annonce prix différents | **Interdit** — un seul prix catalogue |
| Agent qui « livre » le mandat ailleurs | Faute grave (CRM société) |

**Curated =** nous publions ce que **nous** mandons. Pas d’open posting tiers.

### 3.2 Co-mandat / partage inter-agences

| Cas | Traitement |
| --- | --- |
| Apporteur externe (agence amie) | Split commission **écrit** (ex. 50/50 ou 60/40) — **A = gérant** |
| Réseau / franchise future | Hors Y1 |
| Mandat « semi » avec droit de diffusion partenaire | Convention partenaire, pas multi-mandat sauvage |

### 3.3 Location & gestion

| Règle | |
| --- | --- |
| Un bien = **un** mandat de gestion hub | Pas de double gestionnaire |
| Mise en loc seule puis gestion concurrente | OK si client refuse — noter CRM |
| Exclusivité gestion | Durée **12 mois** renouvelable recommandée |

## 4. Politique de remises

### 4.1 Planchers soft (Y1)

| Prestation | Cible | Plancher soft | Sous plancher |
| --- | ---: | ---: | --- |
| Vente exclusif | 6 % | **5 %** | Gérant + motif |
| Vente simple | 4,5 % | **4 %** | Gérant ; souvent **refuser** |
| Vente &gt; 100 M | 3–5 % | **3 %** | Gérant + associés si &lt; 3 % |
| Mise en location | 1 mois | **0,75 mois** | Gérant |
| Gestion | 8 % | **7 %** | Gérant ; si &lt; 7 % → stop |
| Packs forfait | Fourchette `02` | −20 % max | Gérant |

### 4.2 Remises **autorisées** (avec contrepartie)

| Remise typique | Contrepartie obligatoire |
| --- | --- |
| Exclusif **6 → 5,5 %** (−0,5 pt) | Durée exclusive **≥ 4 mois** + reporting OK |
| Exclusif **6 → 5 %** (−1 pt) | Exclusif **≥ 6 mois** **ou** 2ᵉ bien en mandat **ou** gestion jointe |
| Gestion **8 → 7 %** | **≥ 5 lots** même bailleur **ou** engagement 24 mois |
| Loc **1 → 0,75 mois** | Passage immédiat en **gestion 8 %** |
| Pack Diaspora −10–15 % | Paiement comptant + 2 biens / parrainage |
| Gros ticket &gt; 100 M | Grille dégressive `02` (déjà prévue) — pas « remise » libre |

*Bench : en exclusif, −0,5 à −1 pt est souvent négociable (Deal-Immo) — **contre exclusivité**, pas contre rien.*

### 4.3 Remises **interdites** Y1

| Interdit | Motif |
| --- | --- |
| Exclusif **&lt; 5 %** sans AGE/gérant + dossier | Destruction marge / signal dump |
| Simple **&lt; 4 %** | Pire économie unitaire |
| Gestion **&lt; 7 %** « pour gagner le lot » | LTV tuée ; churn |
| Remise sur **éthique** (skip diligence) | Culture `06` — faute |
| Remise agent **sans** accord gérant | RACI |
| « Gratuité » estimation + dump commission | Double cadeau |
| Alignement prix concurrent classifieds | On ne suit pas la guerre du % |

### 4.4 Matrice d’approbation remises

| Écart vs cible | Qui décide |
| --- | --- |
| Dans fourchette `02` (ex. exclusif 5,5–7 %) | **Agent** propose · gérant informé CRM |
| Plancher soft atteint (ex. 5 % exclusif) | **Gérant** (A) |
| Sous plancher | **Gérant** + note associés si récurrent / systémique |
| Remise packs / forfaits &gt; 20 % | **Gérant** |

### 4.5 Formalisation

Toute remise :
1. Motif CRM (texte)  
2. Contrepartie cochée  
3. Taux final sur **mandat signé**  
4. Pas de promesse WhatsApp orale seule

## 5. Cas particuliers

### 5.1 Vendeur qui « teste » 5 agences (multi-mandat externe)

| Action | |
| --- | --- |
| Pitch | Exclusif 3 mois essai avec engagements mesurables |
| Si refuse | Simple **uniquement** si GO §2.4 · sinon **passer** |
| Catalogue | Un prix ; pas de surenchère d’annonces |

### 5.2 Diaspora acquéreur exigeant remise pack

| Action | |
| --- | --- |
| Préférer | Tenir forfait · ajouter **preuve** (inspection) plutôt que −30 % |
| Remise max | −15 % si Secure + 2ᵉ service (gestion) |

### 5.3 Bailleur volume (10+ lots)

| Action | |
| --- | --- |
| Gestion | **7 %** OK si contrat 24 mois |
| Mise en loc | Poss. forfait dégressif sur volume — gérant |
| Reporting | Upsell diaspora 9 % si hors SN |

### 5.4 Paid ads déjà dépensé sur un lead vendeur

| Action | |
| --- | --- |
| Exiger | **Exclusif** — sinon abandon lead |
| Interdit | Simple après Meta/Google spend |

## 6. Argumentaire exclusif (aide-mémoire agent)

| Objection vendeur | Réponse |
| --- | --- |
| « Je veux plusieurs agences » | Multi = multi-prix, moins d’effort chacun ; chez nous exclusif = marketing + suivi |
| « C’est trop cher 6 % » | Contrepartie durée / reporting ; plancher 5 % si 6 mois exclusifs |
| « Mon cousin vend sans agence » | OK — mais pas de diffusion curated / filtrage / diligence packagée |
| « L’autre agence fait 3 % » | On ne match pas le dump ; on match la **preuve** et le closing |

---

## 7. Gouvernance & sanctions

| Manquement | Conséquence |
| --- | --- |
| Simple signé sans validation gérant | Avertissement · split gelé sur le deal |
| Remise sous plancher non autorisée | Deal repricé ou annulé · plan 30 j |
| Multi-prix catalogue | Retrait annonce · coaching |
| Fuite mandat / livre perso | Faute grave (`06` / RH) |

Revue **hebdo** commerciale : % exclusifs · remises accordées · simples en stock.

## 8. Checklist avant signature mandat

- [ ] Type : exclusif / simple / semi (motif si ≠ exclusif)  
- [ ] Taux & FAI (`02`)

- [ ] Remise ? → contrepartie + approbation

- [ ] CRM à jour  
- [ ] Pas de conflit multi-agence non géré
