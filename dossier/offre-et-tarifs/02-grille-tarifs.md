## 0. Synthèse — grille hub retenue

| Prestation | Tarif hub | Qui paie (défaut) |
| --- | --- | --- |
| Vente — mandat **exclusif** | **6 %** (fourchette **5–7 %**) | Vendeur *(ou FAI — §3)* |
| Vente — mandat **simple** | **4,5 %** (fourchette **4–5 %**) | Vendeur |
| Vente — ticket **&gt; 100 M** | **3–5 %** dégressif (écrit) | Vendeur |
| Mise en location | **1 mois** de loyer | Voir §4 (bailleur / partage) |
| Gestion locative | **8 %** des loyers **encaissés** | Bailleur |
| Gestion + reporting diaspora | **9–10 %** **ou** forfait | Bailleur |
| Frais dossier étalé / loc-vente | **25–50 000** | Acquéreur |
| Pack Diaspora Secure | **300–800 000** | Client diaspora |
| Pack Sécuriser / diligence hub | Forfait **150–400 000** + apports | Acquéreur |
| Estimation / simus / guides | **0** | — |

**Cadre légal SN :** honoraires d’agence **libres** (pas de barème unique type France) — loi 82-07 / décret 83-423 encadrent l’**exercice**, pas le % . Transparence écrite dans le **mandat** obligatoire (bonne pratique Immoplus / CPI).

## 1. Principes de pricing

| # | Principe | Application |
| --- | --- | --- |
| 1 | **Écrit** | Taux / forfait / FAI ou hors frais dans le mandat avant presta |
| 2 | **Pas de dump Y1** | Battre sur valeur (curated, SLA, papiers) — pas −2 pts gratuits |
| 3 | **Pousser l’exclusif** | Simple moins attractif pour l’agence → motiver le vendeur |
| 4 | **Outils gratuits** | Simus / estimation = lead ; cash = closing / gestion / pack |
| 5 | **Gestion = volume** | 8 % cible ; 7 % possible pour **≥ 5 lots** même proprio |
| 6 | **Wave/OM** | Frais paiement : **pass-through** bailleur ou inclus dans les 8 % (contrat) |

## 2. Commissions — vente (Axe 1)

### 2.1 Barème par type de mandat

| Mandat | Taux **cible** | Fourchette autorisée | Marché observé |
| --- | ---: | ---: | --- |
| **Exclusif** | **6 %** | 5–7 % (8 % standing exceptionnel) | Kolonell 5–7 % ; SN 5–10 % |
| **Simple** | **4,5 %** | 4–5 % | 3–5 % |
| Co-exclusif / partage réseau | À écrire | Split agences | Cas par cas |

### 2.2 Dégressivité par ticket

| Prix de vente net vendeur* | Taux indicatif exclusif |
| --- | ---: |
| &lt; 25 M | **6,5–7 %** |
| 25–50 M | **6 %** |
| 50–100 M | **5–6 %** |
| **&gt; 100 M** | **3–5 %** (négociation écrite) |

\*Prix hors honoraires si affichage **hors frais** ; si **FAI**, base de calcul = prix affiché − honoraires *(clarifier formule dans mandat — §3)*.

### 2.3 Exemples chiffrés (exclusif 6 %)

| Prix vente | Honoraires agence | Split agent 40 % (COGS) | Marge contribution approx. |
| --- | ---: | ---: | ---: |
| 25 M | **1 500 000** | 600 000 | ~900 k − CAC |
| 50 M | **3 000 000** | 1 200 000 | ~1,8 M − CAC |
| 80 M | **4 800 000** | 1 920 000 | Aligné ticket prévisionnel |
| 120 M @ 4 % | **4 800 000** | 1 920 000 | Gros ticket |

*Prévisionnel `05` : commission moyenne encaissée **~2,8 M** / closing.*

### 2.4 Prestations couvertes (vente)

Inclus dans la commission (sauf mention contraire) :
- Estimation · photos / fiche catalogue · diffusion curated  
- Visites · négociation · suivi dossier jusqu’à signature  
- Orientation notaire / diligence (hors forfaits packs)

**Non inclus :** frais notaire, droits d’enregistrement, géomètre, cautionnements — à la charge des parties selon usage / acte.

## 3. FAI — frais d’agence inclus (ou non)

### 3.1 Définition

| Mention catalogue | Signifie |
| --- | --- |
| **FAI** | Le prix affiché **inclut** les honoraires d’agence — l’acquéreur paie ce prix ; l’agence prélève sa commission avant reversement vendeur *(mécanique usuelle)* |
| **Hors frais** / honoraires charge vendeur | Prix + honoraires séparés ; vendeur règle l’agence sur le produit de la vente |
| **Hors frais** / charge acquéreur | Prix net vendeur + honoraires payés par l’acheteur en sus |

Réf. pratique SN : parties **conviennent** qui paie ; affichage **FAI ou exclus** pour éviter litige (Immoplus Sablux). Glossaire dossier : [`../etude-de-marche/07-glossaire-foncier.md`](../etude-de-marche/07-glossaire-foncier.md).

### 3.2 Règle hub (défaut)

| Cas | Affichage | Qui paie honoraires |
| --- | --- | --- |
| **Défaut Y1** | Prix **FAI** sur catalogue | Inclus dans prix affiché (vendeur « net » = prix − commission) |
| Mandat standing / demande vendeur | Hors frais possible | Vendeur, écrit |
| Diaspora acquéreur | Préférer **FAI** (1 chiffre clair) | Évite surprise |

### 3.3 Exemple FAI vs hors frais

Bien : vendeur veut **47 M nets** · commission **6 %**.

| Mode | Prix affiché | Calcul | Net vendeur | Agence |
| --- | ---: | --- | ---: | ---: |
| **Hors frais** (charge vendeur) | **47 000 000** | 47 M × 6 % | 47 M − 2,82 M = **44,18 M** | **2,82 M** |
| **FAI** (prix = ce que paie l’acheteur) | **P** tel que P − 6 %×P = 47 M → **P = 50 000 000** | 50 M × 6 % | **47 M** | **3 M** |

Toujours **écrire la formule** dans le mandat (base de calcul = prix acte / prix affiché).

### 3.4 Mentions obligatoires fiche / mandat

- [ ] Taux d’honoraires (%) ou forfait  
- [ ] **FAI** ou **hors frais**  
- [ ] Partie débitrice  
- [ ] Prestations incluses  
- [ ] Type de mandat (exclusif / simple)

## 4. Mise en location (Axe 4 — entrée)

### 4.1 Barème

| Prestation | Tarif hub | Notes |
| --- | --- | --- |
| **Mise en location** (entremise) | **1 mois** de loyer mensuel HC* | Standard marché SN / CPI |
| Loyer **≤ 500 000** | Part locataire souvent plafonnée / réduite selon **cadre décret loyers** (pratique citée : ~½ mois côté locataire) | Vérifier texte en vigueur + affichage ; le reste à charge **bailleur** |
| Loyer **&gt; 500 000** | 1 mois — répartition bailleur/locataire **à écrire** | Défaut : 100 % bailleur **ou** 50/50 si marché l’exige |

\*HC = hors charges locatives courantes.

### 4.2 Exemples

| Loyer / mois | Honoraires mise en loc (1 mois) |
| --- | ---: |
| 200 000 | **200 000** |
| 320 000 (moy. modèle) | **320 000** |
| 500 000 | **500 000** |
| 1 000 000 | **1 000 000** |

### 4.3 Inclus / exclus

**Inclus :** annonce curated · visites · sélection dossier · bail type · EDL entrée (process).  
**Exclus :** caution (au bailleur) · assurance · déménagement · packs confort partenaires.

## 5. Gestion locative (Axe 4 — récurrent)

### 5.1 Barème

| Formule | Taux | Quand |
| --- | ---: | --- |
| **Standard** | **8 %** des loyers **effectivement encaissés** | Défaut |
| Entrée volume | **7 %** | ≥ 5 lots même bailleur **ou** engagement 24 mois |
| **Diaspora reporting** | **9–10 %** | Reporting renforcé / Fuseau / preuves |
| Alternative diaspora | **8 %** + forfait **50–100 k**/mois / portefeuille | Si bailleur préfère taux bas + forfait |

Base = loyers **encaissés** (pas théoriques) — vacance = pas d’honoraires sur mois vide *(sauf clause contraire)*.

### 5.2 Exemple portefeuille

| Lots | Loyer unit. | Loyers / mois | Honoraires 8 % |
| --- | ---: | ---: | ---: |
| 1 | 320 000 | 320 000 | **25 600** |
| 10 | 320 000 | 3 200 000 | **256 000** |
| 40 | 320 000 | 12 800 000 | **1 024 000** |

*Aligné `05` : ~25,6 k / lot / mois @ 8 % × 320 k.*

### 5.3 Frais Wave / Orange Money

| Option | Traitement |
| --- | --- |
| **A — Pass-through** (retenu préféré) | Frais mobile money refacturés au bailleur ou déduits du reversement |
| **B — Inclus** | Absorbés dans les 8 % → viser honoraires **8–9 %** si volume petits loyers |

Ne jamais laisser les frais éroder la marge sans clause (`01` BM).

### 5.4 Prestations gestion (inclus 8 %)

Encaissement · relances amiables · quittances · interface WA/portail · reporting mensuel simple · coordination artisans 1er niveau.  
**Hors forfait :** contentieux judiciaire, gros travaux, syndic — devis séparé ou partenaire.

## 6. Forfaits — accession & packs

### 6.1 Vente étalée & location-vente (Axes 2–3)

| Poste | Tarif | Qui paie |
| --- | ---: | --- |
| Frais de dossier | **25 000 – 50 000** | Acquéreur (filtre) |
| Suivi / % sur flux mensuel | **1–3 %** des mensualités **ou** inclus négociation globale | À figer par dossier |
| Commission sur solde / levée d’option | Selon mandat vente associé | Vendeur / structure |

*Prévisionnel : frais dossier hyp. **40 k** (`05`).*

### 6.2 Packs client

| Pack | Forfait hub | Notes |
| --- | ---: | --- |
| **Sécuriser** (orchestration diligence) | **150 000 – 400 000** | + honoraires partenaires (formalités, géomètre) au réel |
| **Diaspora Secure** | **300 000 – 800 000** | Inspection + protocole + reporting de base |
| **Diaspora Full** | Sur devis (≥ 1 M typ.) | Escrow + chantier + multi-devise |
| **Terrain→Maison** (conseil) | **0 – 150 000** | Souvent **gratuit** si apport BTP ; sinon forfait léger |
| Procuration / assistance diaspora | Inclus pack ou **100–250 k** | |

### 6.3 Apports partenaires (revenu hub — pas facturé client final comme « tarif agence »)

| Partenaire | Take-rate hub typique |
| --- | --- |
| Constructeur | **2–5 %** du contrat travaux |
| Architecte | **10–20 %** honoraires **ou** 150–500 k |
| Notaire | Forfait intro **50–200 k** |
| Formalités | Forfait ou % cabinet |
| Géomètre | 10–15 % ou forfait |

Transparent côté client : « mis en relation ; le partenaire facture sa presta ; nous pouvons percevoir une commission d’apport ».

## 8. TVA / fiscalité (note)

| Sujet | Traitement modèle |
| --- | --- |
| Affichage | Montants **TTC** côté client (habitude SN services) |
| TVA sur commissions | Selon régime fiscal SARL / EC — **à confirmer** à l’immatriculation |
| Facturation | Facture agence à chaque closing / mois de gestion |

Ne pas improviser un taux TVA dans le mandat sans visa EC.
