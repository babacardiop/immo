## 0. Synthèse exécutive (1 page)

### Le projet

Créer et opérer une **agence immobilière full-service au Sénégal**, outillée d’une plateforme PropTech et d’un réseau de partenaires (BTP, architecte, notaire, formalités…), pour orchestrer le parcours client :

> *Décider → sécuriser (papiers) → closer → construire / gérer.*

Ce n’est **pas** un site d’annonces ouvert. Ce n’est **pas** un SaaS vendu aux autres agences. C’est une **agence curated** qui gagne sur commissions métier **et** commissions d’apport.

### Opportunité

| Signal | Ordre de grandeur | Source |
| --- | --- | --- |
| Déficit logements | **~320k–500k** unités | BM / Habitat III / discours État 2025–26 |
| Production formelle | Souvent **&lt; 5 000** / an vs besoins massifs | Ministère Urbanisme |
| Urbanisation | **54,7 %** ; Dakar ~22 % pop. / 0,3 % territoire | ANSD RGPH-5 |
| Locataires Dakar | **~56 %** des ménages | ANSD / étude secteur |
| Transferts diaspora | **~2 211 Mds FCFA** (2024, ~12 % PIB) ; ~1 860 Mds cités 2025 (FIDA) | BCEAO / presse |
| Crédit hypothécaire | **~4 %** d’adultes (faible pénétration) | CAHF / étude demande |
| ICAS services immo | **−15 %** cumul 2025 ; rebond signalé T1 2026 (+40 % CA agences selon presse) | ANSD / presse |

**Lecture :** besoin structurel énorme + liquidité diaspora + friction confiance/closing = espace pour une agence qui **industrialise la confiance** et monétise l’aval (chantier, gestion).

### Modèle économique (rappel)

```
CA = commissions vente/location
   + gestion locative récurrente (~8 %)
   + étalé / loc-vente
   + apport partenaires (BTP 2–5 %, etc.)
```

Asset-light : **pas de stock foncier** en propre au démarrage.

### Avantage concurrentiel

1. Catalogue **curated** (TF / bail / délibération explicites) vs classifieds.  
2. **Parcours complet** (outils + partenaires) vs agence WhatsApp.  
3. **Double filet** revenu (métier + apport) vs SaaS pur.  
4. **Gestion + portails** = LTV et cash récurrent.  
5. Contenu / Observatoire (lab) = autorité diaspora.

### Ambition 36 mois (directionnelle)

| Horizon | Jalons |
| --- | --- |
| **M6** | Site live, mandats curated, 3 partenaires P0 signés, 1ʳᵉ commission apport |
| **M12** | Gestion locative live, N unités sous mandat, mix CA débutant récurrent |
| **M24** | ≥ **35 %** CA récurrent cible ; marque diaspora établie ; Observatoire v1 |
| **M36** | Hub de référence Dakar / couronne ; réseau partenaires densifié ; unit economics positifs |

### Besoin de financement (ordre de grandeur — détail `08`)

Capex lean Vague 0–1 (site, conformité, BFR 6 mois) : typiquement **15–40 M FCFA** selon make/buy et taille d’équipe — **sans** acquisition foncière. Scénarios dans `08`–`10`.

## 1. Vision, mission, valeurs

### 1.1 Vision

> Devenir le **premier hub immobilier de confiance au Sénégal** : l’interlocuteur unique pour trouver, sécuriser, financer le parcours, notariser, construire et gérer — pour les locaux solvables et la diaspora.

### 1.2 Mission

Opérer une agence qui :

1. **Publie uniquement** des biens dont les papiers ont été lus et qualifiés.  
2. **Donne des chiffres** (mensualités, coût construire, frais) avant l’engagement.  
3. **Close** avec notaire / diligence — pas de Wave direct au vendeur pour la diaspora.  
4. **Gère** les loyers avec transparence (portails, Wave/OM).  
5. **Oriente** vers des partenaires contractualisés quand le client doit construire ou formaliser.

### 1.3 Valeurs opérationnelles

| Valeur | Traduction terrain |
| --- | --- |
| Preuve avant promesse | Facets papier, checklists, go/no-go documentés |
| Transparence honoraires | Mandats écrits, FAI clair |
| Séparation des rôles | Présentateur ≠ vérificateur ≠ détenteur des fonds |
| Focus | Vagues étroites (8–12 ouvertures max) — pas 52 add-ons d’un coup |
| Asset-light | Intermédiaire ; pas promoteur capitalistique Y1–Y2 |

## 3. Analyse de marché

### 3.1 Macro

- PIB : croissance **soutenue 2025** (~6–7 %, hydrocarbures) ; perspectives **2026** plus hétérogènes (AfDB ~5–6 % dans certains scénarios ; BM/FMI plus prudents selon publications — **à suivre**).  
- Inflation UEMOA / SN : retour vers **bas single digit** après pic 2022.  
- Dette / programme FMI : facteur de risque macro (austérité, liquidité) — impact possible sur BTP public et pouvoir d’achat.  
- **Implication BP :** marché immobilier **structurellement porteur** ; conjoncture **volatile** → sélectivité tickets + récurrence gestion.

### 3.2 Demande structurelle

```
Besoin habitat (déficit 320–500k)
    → Recherche (WA, FB, classifieds) — volume
        → Closing sécurisé — GOULOT
            → Après-vente (construire / louer / gérer) — SOUS-SERVI ← NOUS
```

| Segment solvable | Pourquoi on le vise |
| --- | --- |
| Classe moyenne accession (terrain 8–40 M) | Étalé + pack construire = double filet |
| Cadres / standing | Commission élevée, tickets clairs |
| Diaspora investisseur | Transferts **>~2 000 Mds**/an ; douleur arnaque = WTP confiance |
| Bailleurs multi-biens | Gestion 8 % = LTV |

**Non-priorité P&L :** file sociale 278k candidatures — orientation contenu seulement.

### 3.3 Offre & structure du secteur

| Caractéristique | Fait | Conséquence BP |
| --- | --- | --- |
| Auto-construction | **~62 %** | Simu construction + BTP = cœur Vague 1 |
| Achat promoteur | **~0,6 %** | Peu de concurrence VEFA sur volume ; co-com possible plus tard |
| Agences aux normes | **~100 / 466+** (CAHF) | Professionnalisation = différenciation |
| Classifieds | Volume élevé, confiance faible | Ne pas gagner au volume d’annonces |
| ICAS 2025 | Agences en tension | Process + confiance battent le « plus d’annonces » |

### 3.4 Conjoncture services vs construction (2025–2026)

Sources ANSD / presse :

- **2025 :** CA services immobiliers **en baisse** (~−15 % cumul) — attentisme closing.  
- **T1 2026 :** signal de **rebond fort** du CA agences (presse ~+40 % YoY) — à confirmer sur note ICAS PDF.  
- **T2 2026 :** construction **−22 %** CA (ICAC) alors que **services immo +26 %** — le marché transactionne / loue pendant que le neuf freine.

**Stratégie :** Y1 monétiser **transaction + gestion + formalités** ; apport BTP **sélectif** (clients qui construisent quand même) ; ne pas dépendre du boom promoteur.

### 3.5 Taille d’opportunité adressable (SAM / SOM — ordres de grandeur)

Pas de panel transactionnel public fiable → on raisonne **SOM réaliste** (part de mandats / unités gérées), pas TAM mondial.

| Couche | Définition | Lecture |
| --- | --- | --- |
| **TAM** | Ensemble transactions + loyers formels SN | Trop large ; informel dominant |
| **SAM** | Dakar + couronne + Petite Côte : vente/location/gestion **solvables** via agence | Notre théâtre |
| **SOM Y3** | Dizaines de mandats vente/an + dizaines–centaines d’unités gérées + apports | Objectif opérationnel — chiffré dans `05` |

Hypothèse de travail BP : capturer une **fraction** du marché formel dakarois via **qualité**, pas 1 % du déficit national.

## 5. Stratégie

### 5.1 Stratégie générique

**Différenciation focalisée** (Porter) : niche *confiance + parcours* sur Dakar/couronne/diaspora — pas leadership coût, pas volume classified.

### 5.2 Axes stratégiques 36 mois

| # | Axe | Actions | KPI |
| --- | --- | --- | --- |
| S1 | **Supply exclusif** | Mandats exclusifs 5–7 % ; site vendeur-first | % exclusifs ≥ 60 % |
| S2 | **Confiance** | Diligence, facets papier, glossaire, séquestre | % closings avec go/no-go |
| S3 | **Double filet** | 3 partenaires P0 + CRM commissions | CA apport / CA total |
| S4 | **Récurrence** | Gestion Vague 3 ; Wave+OM | Unités sous mandat ; % CA récurrent |
| S5 | **Marque diaspora** | Contenu FR, inspection, pas Wave vendeur | Leads diaspora ; NPS |
| S6 | **Autorité data** | Études PDF + Observatoire lab | Trafic / citations |

### 5.3 Roadmap produit = roadmap CA

| Vague | Parcours | CA qui s’allume |
| --- | --- | --- |
| **0** | Agence en ligne | Transaction |
| **1** | Acheteur terrain | + Apport BTP/archi/notaire |
| **2** | Sécuriser | + Forfaits diligence |
| **3** | Location/gestion | + **Récurrent** |
| **4** | Diaspora | Scale LTV |
| **5+** | Gros tickets / densifier | Success fees, réseau |

Règle anti-dispersion : **backlog ≠ build** — max ~8–12 ouvertures / vague (`hub-roadmap`).

### 5.4 Go-to-market

1. **Captation mandats** (vendeurs/bailleurs) via réseau + SEO estimation.  
2. **Demande** via catalogue + simulateurs + guides anti-arnaque.  
3. **Closing** WhatsApp + bureau + notaire.  
4. **Après-vente** partenaires + gestion.  
5. **Preuve sociale** (CRG, quittances, études) → boucle mandats.

## 16. Conclusion

Le Business Plan repose sur une thèse simple et défendable :

1. Le Sénégal a un **déficit structurel** et une **diaspora liquide**.  
2. Le marché formel souffre d’un **déficit de confiance et de closing**, pas d’un déficit d’annonces.  
3. Une **agence curated + outils + partenaires** capture la valeur là où les classifieds et le SaaS purs ne vont pas.  
4. La **gestion locative** transforme un métier cyclique en plateforme de cash récurrent.  
5. La discipline de **vagues étroites** protège la trésorerie et la qualité.

Prochaine brique chiffre : **unit economics** (`04`) puis **prévisionnel 36 mois** (`05`).
