## 3. FONGIP — garantie de crédit (voie principale option B)

### 3.1 Rôle

Le FONGIP **ne prête pas** directement dans le schéma classique : il **garantit** (partage de risque) un crédit accordé par une **banque partenaire** (SGBS, BHS, BICIS, Ecobank, FBNBank…). Quotité courante **50–70 %**, plafond théorique jusqu’à **~80 %**. Commission garantie indic. **1–1,5 % / an**.

| Paramètre | Indicatif 2025–26 |
| --- | --- |
| TPE — plafond garanti / opération | jusqu’à **~50 M** |
| PME | jusqu’à **~200 M** (selon dispositifs) |
| Capital | Siège SN + **≥ 50 %** capital nationaux (critère classique) |
| Secteurs cités | Agri, artisanat, tourisme, infrastructures, **habitat**, **TIC / téléservices**, etc. |

### 3.2 Process

```
1. Formaliser SARL + equity libérée
2. Déposer dossier crédit à la banque
3. Accord de principe / comité crédit banque
4. Banque introduit demande de garantie FONGIP
5. Instruction FONGIP (~15–30 j dossier complet)
6. Lettre d’octroi garantie → déblocage crédit
```

### 3.3 Pièces spécifiques FONGIP

- [ ] Demande de garantie **signée par la banque**
- [ ] Analyse / compte rendu du dossier de crédit (banque)
- [ ] Business plan
- [ ] Plan de décaissement + plan d’amortissement prévisionnel
- [ ] Statuts, CNI promoteurs
- [ ] RCCM, NINEA
- [ ] États financiers 3 exercices (si existante) **ou** prévisionnels création
- [ ] 3 derniers relevés bancaires (si existante)
- [ ] Infos patrimoniales / endettement client
- [ ] Engagement écrit à se faire accompagner par le FONGIP
- [ ] (Compléments) — FONGIP peut en demander

**Lien pack :** `03`+`06`+`07`+`08`+`09` + devis `08` §1.

### 3.4 Angle pitch FONGIP / banque

> Agence immobilière **asset-light** + plateforme digitale (catalogue, simus, partenaires) — pas d’achat de stock foncier. Emplois des fonds : **~45–50 % digital/conformité**, **~45–50 % BFR salarial**. Capacité de remboursement dès Y2 (EBE positif BASE). Garantie demandée sur crédit **10–15 M** (option B), equity **≥ 50–65 %**.

## 4. FOGARISE — garantie diaspora (FONGIP)

### 4.1 Pour qui

Sénégalais de l’extérieur co-investissant dans un projet productif au Sénégal (entité formalisée).

| Caractéristique | Valeur publiée |
| --- | --- |
| Garantie | **40–80 %** |
| Ticket projet | jusqu’à **500 M** |
| Durée | **12–60 mois** |
| Taux cible crédit | **&lt; 10 %** |
| Commission | **~1 % / an** |
| Co-garantie | Possible |
| Dépôt | [fongip.sn](https://www.fongip.com/) ou banque partenaire |

### 4.2 Pièces

- [ ] Entité formalisée (RCCM, NINEA, statuts)
- [ ] Documents juridiques à jour
- [ ] États financiers (si existante) / prévisionnels
- [ ] Business plan
- [ ] Factures / devis **pro forma**
- [ ] Preuve statut diaspora (passeport + résidence étrangère) du co-investisseur
- [ ] Montage equity diaspora ↔ société SN clair (CCA / capital)

**Usage EverGreen :** si love money diaspora dans option B → monter FOGARISE **en parallèle** du crédit banque.

## 5. BNDE — crédit de développement

### 5.1 Démarche officielle ([bnde.sn](https://www.bnde.sn/fr/node/22))

1. Élaborer business plan / étude de faisabilité  
2. Demande adressée au **Directeur général** + BP  
3. Éventuellement passer par **ADEPME** ou **FONGIP** pour accompagnement  
4. Entretien assistants projets + **visite de site**  
5. Instruction indic. **~21 jours** si dossier complet  

### 5.2 Pièces BNDE

- [ ] Lettre au DG BNDE
- [ ] Business plan ou étude de faisabilité
- [ ] Statuts
- [ ] Extrait RCCM
- [ ] Extrait de naissance + photocopie pièce d’identité
- [ ] CV dirigeant + équipe
- [ ] Devis / factures pro forma (équipements, travaux, etc.)
- [ ] États financiers 2–3 derniers exercices (si activité)
- [ ] Relevés de comptes bancaires
- [ ] État des droits réels / terrains proposés en garantie *(si demandé — pour nous : **nantissement matériel / caution / FONGIP** plutôt qu’hypothèque foncière)*
- [ ] Rapport d’expertise garanties (si applicable)

**Fit :** BNDE cite services, TIC, immobilier parmi secteurs éligibles (réf. offres PMI) — **cadrer** le projet comme investissement digital + création d’emplois, pas promotion foncière. Probabilité d’acceptation **cas par cas** ; utile surtout si ligne développement / jeunesse.

## 6. Banques commerciales (SGBS, BHS, Ecobank, BICIS, Atlantique…)

### 6.1 Ce que le chargé de crédit lit vraiment

1. **Capacité de remboursement** — trésorerie mensualisée où les **annuités** passent  
2. **Réalité de l’investissement** — chaque franc = **devis**  
3. **Couverture du risque** — equity + FONGIP + garanties  

### 6.2 Pièces typiques dossier crédit PME

- [ ] Demande de crédit (montant, durée, objet)
- [ ] Pack économique `03`–`10`
- [ ] Plan d’amortissement (simulation)
- [ ] Apports justifiés (virements capital / CCA)
- [ ] Garanties proposées (FONGIP, nantissement, caution perso)
- [ ] Ouverture compte + historique mouvements
- [ ] Contrats clients / partenaires (si existants)

**Montant EverGreen option B :** crédit investissement **10–15 M**, 3–5 ans, taux marché **~9–14 %** (souvent négociable &lt; 10 % avec FONGIP — Carrée 2026).

## 9. Levée equity / angels / incubateurs

### 9.1 Quand

Après **traction** (closings, lots, partenaires) — pas pour « survivre » (`10` / Réverbère 2025). Runway **9–12 mois** recommandé pendant une levée (SENAGORA).

### 9.2 Livrables investisseurs

| Document | Contenu |
| --- | --- |
| **Pitch deck** 10–15 slides | Problème → solution → marché → modèle → traction → go-to-market → équipe → finances → ask |
| BP + modèle financier | `03`–`10` |
| Cap table | Actionnaires, % , CCA |
| Data room | §10 |
| Term sheet (plus tard) | Valorisation, dilution, droits |

### 9.3 Outline pitch deck (EverGreen)

1. Titre / ask (**30–40 M** equity ou **10–15 M** dette)  
2. Problème marché SN (confiance, diaspora, closing)  
3. Solution hub (agence + digital + partenaires) — **pas classifieds**  
4. Marché & positionnement (`etude-de-marche`)  
5. Business model & unit economics (`01`/`04`)  
6. Traction / roadmap vagues  
7. Go-to-market & partenaires (24)  
8. Concurrence / barrières  
9. Équipe  
10. Finances 3 ans BASE + scénarios  
11. Usages des fonds (`08`)  
12. Ask & milestones 12 mois  

### 9.4 Structures d’appui (crédibilité, pas cash garanti)

CTIC Dakar, Impact Hub, Orange Fab, coaches ADEPME — utiles pour **réseau + labellisation** du dossier.

## 14. Risques & erreurs classiques

| Erreur | Conséquence | Fix |
| --- | --- | --- |
| Demander une subvention pour financer le burn Y1 | Rejet / dépendance | Equity d’abord |
| BP sans devis | Instruction bloquée | 1 devis / poste `08` |
| Chiffres incohérents CA ↔ trésorerie ↔ annuités | Perte confiance | Recoller `05`/`06`/`07` |
| Se présenter comme lotisseur | Mauvais guichet / risque | Asset-light, services+TIC |
| Dossier incomplet DER | Rejet automatique | Checklist §7 |
| Lever trop tôt sans traction | Dilution / refus angels | Attendre closings (`10`) |
| Oublier garantie financière métier | Non-conformité ouverture | Budget `08` |
