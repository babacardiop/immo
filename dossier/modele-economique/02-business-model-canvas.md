## Lecture rapide des 9 blocs

| # | Bloc | Essence hub |
| --- | --- | --- |
| **1** | Segments clients | Vendeurs/bailleurs (offre) + acquéreurs/locataires (demande) + partenaires qui reverse |
| **2** | Proposition de valeur | Agence qui sécurise et exécute le parcours complet — curated, pas classified |
| **3** | Canaux | Site + WA + bureau ; SEO ; partenaires ; syndication sélective |
| **4** | Relation client | Humain + portails ; reporting diaspora ; SLA |
| **5** | Flux de revenus | Commissions vente/location + gestion 8 % + étalé + apport partenaires |
| **6** | Ressources clés | Licence/RC, mandats exclusifs, équipe, plateforme, réseau partenaires |
| **7** | Activités clés | Mandats → diligence → closing → gestion → apport écosystème |
| **8** | Partenaires clés | BTP, archi, notaire, formalités, Wave/OM |
| **9** | Structure de coûts | Opex agence + digital ; var. agents & mobile money ; asset-light |

---

## Ce que le canvas **exclut** volontairement

| Hors modèle (v1) | Pourquoi |
| --- | --- |
| Marketplace open posting | Pas de marge confiance / qualité |
| SaaS vendu aux autres agences | Distraction avant PMF |
| Stock promoteur / lotisseur | Capex & risque bilan |
| RNPL / crédit loyer en propre | Régulation + risque crédit (phase 3+ éventuelle) |

## Alignement vagues → blocs revenus

| Vague | Bloc revenus qui s’allume |
| --- | --- |
| **0** | Vente / location (transaction) |

| **2** | + Forfaits diligence / formalités |
| **3** | + **Gestion récurrente** (ancre) |
| **4+** | Scale diaspora / densifier partenaires / Observatoire |
