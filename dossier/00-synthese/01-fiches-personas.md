## P1 — Aïssatou · Locataire dakaroise

| Attribut | Détail |
| --- | --- |
| Âge / situation | 28–38 ans, salariée/commerçante, 1–2 enfants |
| Zone | Parcelles, Grand Yoff, Liberté, Pikine |
| Budget | Loyer 150–350k FCFA ; avance + caution = barrière |
| Objectif | Logement décent proche travail/écoles ; rêve accession |
| Canaux | WhatsApp, Expat/CoinAfrique, bouche-à-oreille |
| Frustrations | Arnaques, bail verbal, dépôts excessifs, photos mensongères |
| JTBD | « Trouver un bail clair sans me faire plumer » |
| Message | Bail clair, logement réel, pas de surprise à l’entrée |
| Offre | Catalogue curated location, EDL, caution partenaire → upsell terrain |
| KPI | Délai placement ; taux locataire → prospect accession |

## P2 — Mamadou · Primo-accédant terrain

| Attribut | Détail |
| --- | --- |
| Âge / situation | 32–45 ans, revenu mixte, épargne irrégulière |
| Budget | Terrain 8–35 M (étalé 12–36 mois) ; construction progressive |
| Objectif | Terrain TF/bail puis construire petit à petit |
| Canaux | WA, visite week-end, compare prix/m² |
| Frustrations | Titre douteux, viabilisation, coût construction opaque |
| JTBD | « Savoir si je peux payer, et combien coûtera la maison » |
| Message | Mensualité + coût maison visibles ; papiers lus (TF/bail/délib) |
| Offre | Fiche + simus + constructeur/archi/notaire |
| KPI | `sim_complete` → visite → mandat / acompte |

## P3 — Fatou · Diaspora (FR / EU / US)

| Attribut | Détail |
| --- | --- |
| Âge / situation | 30–55 ans, permanente à l’étranger |
| Budget | 15–150 M+ ; transferts réguliers (~10 % PIB SN) |
| Objectif | Patrimoine / parents / locatif ; **zéro arnaque** |
| Canaux | Google, YouTube, FB groupes ; parent local |
| Frustrations | Distance, POA floue, multi-vente, chantier fantôme |
| JTBD | « Acheter / construire / gérer sans être sur place, avec preuves » |
| Message | *Avant de payer, on vérifie. Ensuite on gère.* |
| Offre | Diligence, inspection, séquestre, mandat gestion + reporting |
| KPI | Diligence payée ; mandat gestion signé |

## P5 — Ousmane · Bailleur / investisseur local

| Attribut | Détail |
| --- | --- |
| Situation | 1–5 biens, manque de temps |
| Objectif | Loyers réguliers, locataires solvables, moins de litiges |
| Canaux | Bouche-à-oreille ; passe à l’agence si impayés |
| Frustrations | Commission « chère », opacité, vacance |
