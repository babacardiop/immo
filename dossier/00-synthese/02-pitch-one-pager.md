## 1. Promesse

| Couche | Texte |
| --- | --- |
| **Master** | *Avant de payer, on vérifie. Ensuite on gère.* |
| **Position** | *Votre agence immobilière — vendre, louer, gérer.* |
| **Anti** | *Pas une marketplace. Une agence.* |
| **Creed** | *On ne vend pas un rêve WhatsApp — on sécurise un parcours.* |

**Une phrase métier :**  
EverGreen est une **agence immobilière full-service** au Sénégal (mandats, closing, gestion), outillée digitalement — catalogue curated, diligence papiers, partenaires pour construire / notariser — **sans** open posting.

## 2. Les 4 axes commerciaux

*Source : `docs/positioning.md` — toujours valides.*

| # | Axe | Offre | Revenu | Priorité Y1 |
| --- | --- | --- | --- | :---: |
| **1** | **Vente classique** | Terrains · maisons · appartements — mandat, visite, négociation, notaire | Commission **5–7 %** exclusif · **4–5 %** simple | ●●● |
| **2** | **Vente étalée** | Terrains TF / bail — mensualités structurées + suivi | Frais dossier + % sur flux | ●● |
| **3** | **Location-vente** | Accession bâti (maisons / apt) | Frais + % sur redevances | ● |
| **4** | **Location + gestion** | Mise en location + **encaissement loyers**, quittances, reporting | ~1 mois à la mise · **~8 %** loyer / mois | ●●● |

```
                    AGENCE + SITE
                         │
     ┌─────────┬─────────┼─────────┬─────────┐
     ▼         ▼         ▼         ▼
  Vente    Étalée    Loc-vente   Loc+Gestion
  (one-shot) (flux)   (accession)  ★ récurrent
```

**Sans l’axe 4**, on reste un broker de leads. **Avec** la gestion, on a l’**ancre LTV**.

*Add-on commercial (pas un 5ᵉ axe catalogue) :* commissions d’**apport partenaires** (BTP, archi, notaire, formalités) — double filet sur le même client.

## 3. Différenciation

### 3.1 On est / on n’est pas

| On est | On n’est pas |
| --- | --- |
| Agence curated (on publie sous mandat) | Expat-Dakar « en plus joli » |
| Hub parcours (décider → sécuriser → closer → gérer) | Blog conseil isolé |
| Digital **au service** du métier | SaaS pur sans terrain (≠ Noflaye) |
| Marketplace **fermée** de partenaires | Annuaire open posting |
| Confiance diaspora industrialisée | Courtier WhatsApp familial |

### 3.2 Carte concurrentielle (1 coup d’œil)

```
         CONFIANCE / PREUVES
                 ▲
   Yaweet ·      │     ★ EVERGREEN
   Agences top   │
 ───────────────┼──────────────► PARCOURS COMPLET
  Classifieds    │
  Courtiers WA   │     Noflaye (outil)
                 ▼
```

| Concurrent type | Eux | Nous |
| --- | --- | --- |
| Classifieds | Volume d’annonces | Qualité + closing |
| Agence papier | Confiance locale | + SEO, simus, portails, process diaspora |
| PropTech SaaS | Outils | On **opère** le mandat et l’encaissement |
| Diligence pure | Rapport | Parcours complet + gestion |

### 3.3 Preuves de promesse (non négociables)

- Pastille **TF / bail / délibération** sur chaque fiche  
- Disclaimer si ≠ TF  
- **Séquestre notaire** — jamais Wave vendeur  
- Partenaires **nommés seulement si live** (≥ 3 avant « écosystème »)  
- Reporting bailleur / vendeur (WA ou portail)

## 4. CTA (un par audience)

| Audience | CTA principal | Canal | Réponse |
| --- | --- | --- | --- |
| **Client** (vente / loc / gestion) | Demander une **estimation** ou une **visite** | WhatsApp Business | &lt; 24 h |
| **Vendeur / bailleur** | Prendre RDV mandat (exclusif préféré) | WA / site `/estimation` | J0–J2 |
| **Diaspora** | Pack **Secure** (vérif avant paiement) | WA + page process | &lt; 24 h |
| **Partenaire P0** | Signer **convention d’apport** | Mail GER + LOI | 15 j → convention |
| **Investisseur / love money** | Ouvrir **data room** + call 20 min | Mail · LinkedIn | Lien lecture seule |

### Textes CTA prêts à coller

**WhatsApp (bio / Status)**  
`EverGreen — Agence immo Dakar. Avant de payer, on vérifie. Ensuite on gère. Écrivez : vente · location · gestion · estimation.`

**Mail client**  
`Répondez à ce message ou WhatsApp [num] pour un créneau visite / estimation — on revient sous 24 h.`

**Mail investisseur**  
`Ask : 30 M FCFA equity (35–40 M confort). Data room : [lien]. Deck : PJ. Dispo call 20 min cette semaine.`

**Partenaire**  
`On qualifie, vous exécutez, commission d’apport à l’encaissement. LOI jointe → convention sous 15 j.`

**Règle :** **1 CTA** par support. Pas « visite + estimation + simu + blog » sur le même bloc.
