## 1. Problème

Le marché immobilier sénégalais est **tendu, opaque et sous-servi sur le closing** :

1. **Habiter / accéder coûte cher** — ~56 % des ménages dakarois locataires ; crédit rare ; parcours terrain→maison chaotique.  
2. **La confiance casse la conversion** — classifieds à volume (Expat-Dakar, CoinAfrique…) sans diligence ; arnaques Wave / faux titres, surtout **diaspora**.  
3. **L’après-vente est orphelin** — auto-construction ~62 % sans orchestration ; gestion locative peu industrialisée ; goulot = **closing sécurisé → chantier / gestion**.

Les acteurs existants couvrent **un bout** du parcours : volume d’annonces **ou** agence papier/WhatsApp **ou** outil SaaS sans terrain. Personne n’industrialise **agence curated + preuves + partenaires + récurrence**.

---

## 2. Solution

**EverGreen = hub agence :**

```
Agence full-service  +  Outils (catalogue, simus, portails)
                     +  Partenaires contractualisés (BTP, archi, notaire, formalités…)
        =  parcours décision → sécurisation → closing → chantier / gestion
        =  double revenu (commission métier + commission d’apport)
```

| Ce qu’on fait | Ce qu’on n’est pas |
| --- | --- |
| Mandats exclusifs / simples · visites · closing | Marketplace open posting |
| Pastilles TF / bail / délibération + diligence | « Photos = preuve » |
| Séquestre notaire · anti-Wave vendeur | Courtier familial WhatsApp |
| Gestion locative (Wave/OM, reporting) | SaaS vendu aux autres agences (Y1) |
| Intro partenaires (« on vous met en relation ») | Constructeur / notaire / banque |

**Différenciation :** confiance **industrialisée** (papiers nommés, process diaspora) + **parcours complet** — là où Yaweet vérifie, Noflaye outille, et les classifieds publient, nous **opérons**.

**SOM Y3 (BASE) :** dizaines de closings/an + ~95 lots sous gestion + apports partenaires — détail [`ME-05`](../modele-economique/05-previsionnel-36-mois.md).

**Conjoncture :** ICAS 2025 services immo ~**−15 %** (attentisme closing) ; signaux 2026 de rebond services — gagne qui **réduit la friction** et prouve avant paiement.

## 4. Modèle économique

### 4.1 Revenus (4+ axes)

| Axe | Monetisation | Rôle |
| --- | --- | --- |
| **Vente** | **5–7 %** exclusif · **4–5 %** simple | Volume Y1 |
| **Location** | ~1 mois de loyer à la mise | Entrée funnel gestion |
| **Gestion** | **~8 %** des loyers encaissés | **Ancre LTV** |
| **Apports** | BTP 2–5 % · archi · notaire forfait · formalités… | Double filet |
| Accession | Étalé / loc-vente (frais + % flux) | Montée V1+ |

Règle : **LTV:CAC ≥ 3:1** · paid marketing rampe 0 → 200k → 400k FCFA/mois.

### 4.2 Prévisionnel BASE (M FCFA)

| | **Y1** | **Y2** | **Y3** |
| --- | ---: | ---: | ---: |
| CA | **55,9** | **126,6** | **193,8** |
| EBITDA approx. | **~0** | **~+24** | **~+51** |
| Closings vente | 14 | 28 | 40 |
| Lots gestion (fin) | 20 | 55 | 95 |

Y1 = investissement (site, conformité, rampe). Y2 = bascule. Point mort cash Y1 ~**56 M** CA ≈ prévision — équilibre serré avec buffer **30 M**.

### 4.3 Unit economics (esprit)

Commission vente typique nette après split · gestion récurrente · apport moyen ~**0,9 M**/affaire — détail [`ME-04`](../modele-economique/04-unites-economiques.md).
