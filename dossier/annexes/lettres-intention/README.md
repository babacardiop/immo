## Process

```
Shortlist partenaire
  → LOI (ce dossier) signée ou accusée
  → Négociation taux / SLA
  → Convention apport `02` + Annexe A
  → GO leads CRM
```

**Règle hub :** zéro lead sans convention (LOI seule ≠ GO leads).
