## 2. Règles stock (si P2)

| Do | Don’t |
| --- | --- |
| Chercher photographes / tags **Senegal · Dakar · West Africa** | « Luxury villa Dubai » / Miami |
| Vérifier absence logo marque | Revendre le fichier tel quel |
| Noter URL + auteur + date DL dans registre | Hero site 100 % stock |
| Préférer atmosphère (ciel, texture) à « famille heureuse » générique | Impliquer que le stock = notre client |

**Quota soft :** ≤ **20 %** des images **publiques** brand peuvent être stock ; hero + équipe + 1ˢʳ listing = **owned**.

## 3. Consentements

| Sujet | Exigence |
| --- | --- |
| Employé / associé | Accusé écrit (mail OK) |
| Client / locataire / vendeur | Clause mandat **ou** release séparée |
| Figurant payé | Release + paiement tracé |
| Mineur | Interdit sans autorité parentale écrite |
| Façade privée identifiable (ads) | Accord proprio / mandat |

Sans consentement → **floutage** ou ne pas publier.

---

## 4. Listings vs brand

- Photos mandat : droits de **diffusion commerciale du bien** pour la durée du mandat (+ archive historique « vendu » si prévu).  
- Ne pas recycler une photo listing comme hero marque **si** le bien est identifiable et le mandat expiré — sauf accord.  
- Inspect / EDL photos = **dossier dossier**, pas feed public.
