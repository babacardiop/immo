- [ ] Validité datée (≥ 30–90 j)  
- [ ] Coordonnées bancaires (si acompte)  
- [ ] Aligné ligne `ME-08` (± 15 % ou justification)  

Stocker dans Drive `/05_Devis/` + cocher registre `DV-*`.

## 4. Buffer / BFR (pas « devis »)

Les **~14 M** buffer opex (`08`) se justifient par :

- Grille salariale / charges (`organisation/05`)  
- Plan trésorerie `ME-07`  
- Loyer mensuel  

Joindre **note 1 page** « couverture 3–6 mois de charges » plutôt qu’un faux devis salarial.
