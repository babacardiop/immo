## 2. P1 — Banque commerciale + FONGIP

### Banque (SGBS, BHS, Ecobank, BICIS, Atlantique, FBN…)

- [ ] Demande de crédit (montant, durée, objet)  
- [ ] Pack économique `03`–`10`  
- [ ] Plan d’amortissement (simulation)  
- [ ] Apports justifiés  
- [ ] Garanties proposées (FONGIP, nantissement, caution)  
- [ ] Compte + historique  
- [ ] Contrats / partenaires si existants  

**Ask EverGreen opt. B :** crédit **10–15 M**, 3–5 ans, taux marché ~**9–14 %** (souvent &lt; 10 % avec FONGIP).

### FONGIP (garantie — **via banque**, ne prête pas)

Process : SARL → dossier banque → accord principe → banque introduit FONGIP → instruction ~**15–30 j** → lettre garantie → déblocage.

- [ ] Demande de garantie **signée par la banque**  
- [ ] Analyse / CR dossier crédit banque  
- [ ] BP + plan décaissement + amortissement  
- [ ] Statuts, CNI, RCCM, NINEA  
- [ ] EF 3 exercices **ou** prévisionnels création  
- [ ] 3 relevés (si existante)  
- [ ] Infos patrimoniales / endettement  
- [ ] Engagement accompagnement FONGIP  

Quotité cible **50–70 %** (plafond théorique ~80 %). TPE garanti jusqu’à ~**50 M** / op.
