# Form — Republier un cycle (Listing)

**Sprint :** `S09-property-listing-cycles`  
**Prérequis :** Property existant · mandat actif  
**Frame :** [`layout.jpg`](./layout.jpg) *(à générer / alias)*

## Composition

1. Rappel Property (adresse · structure)
2. Mode : **Location classique** | **Courte durée**
3. Prix · période · caution / minStay
4. Media : réutiliser pins Property · **ajouter photos à jour**
5. Si courte : pack **offre incluse** (clim, wifi…)
6. CTA **Créer le nouveau cycle** (draft) / **Publier**

## Job

Remettre le même bien sur le marché sans recréer le Property.
