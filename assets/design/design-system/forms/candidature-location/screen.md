# Form — Dépôt candidature (candidat assigné)

**Sprint :** `S08-candidatures-location`  
**Prérequis :** `PropertyAssignment(role=candidate)` active  
**Frame :** [`layout.jpg`](./layout.jpg)

## Composition

1. Rappel bien + loyer (assigné)
2. **Bandeau confidentialité (obligatoire, non dismissible) :**
   > Vos documents (CNI, justificatifs de revenus, etc.) sont transmis **uniquement au personnel EverGreen**. Le propriétaire du bien **n’y a pas accès**.
3. Checkbox consentement notice (versionnée) — bloque submit si non cochée
4. Uploads dynamiques = exigences required
5. Barre complétude
6. CTA **Envoyer mon dossier**

## Anti

Pas de self-serve public sans compte + assignation candidat.  
Pas de partage docs vers le portail proprio.
